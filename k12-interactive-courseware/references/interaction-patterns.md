# 跨学段通用交互范式库

> 本文件是 `k12-interactive-courseware` 的核心装配手册。
> 所有学科共享这套范式。学科专属内容见 `references/subjects/*.md`，技术实现见 `references/tech-patterns.md`。
> 学科 reference 中出现的"范式 P07"即指本文件的编号。

## 使用方式

1. 通过三个澄清问题得到：**学段+学科 / 知识点 / 课件用途**
2. 用「课件用途 → 范式」映射表圈定候选范式
3. 加载该学科的 `references/subjects/<学科>.md`，用其知识地图确认该知识点的推荐范式
4. 从候选范式中选出 **1 个主范式 + 至多 2 个辅助范式**，不要堆砌
5. 按 `references/grade-adaptation.md` 调整交互复杂度与 UI 尺度

**装配铁律**：一个课件 = 一个主范式撑起骨架，辅助范式只做点缀。三个以上范式并存会让控制面板臃肿、课堂节奏散掉。

## 交互选择规则（硬约束）

1. **先确定学科思维，再选择交互**。禁止先选好动画或拖拽，再把教学内容套进去。
2. **每个主要交互对应至少一个教学目标**，说不出对应目标的交互直接删掉。
3. **每个交互产生可观察结果**：规律、解释、数据、作品或答案。
4. **不得用通用选择题代替学科核心活动**（如用选择题代替实验操作、代替作图、代替文本批注）。
5. **主要交互共 1～3 个**；简单课题可以只有 1 个。
6. **跨学科内容围绕同一个真实任务组织**，禁止把几个学科的内容机械拼接。
7. **现实实验只做安全模拟**，不提供危险操作指导。

## 二、课件用途 → 范式映射（第三问的直接产出）

第三问「用在课堂哪个环节」决定范式选型：

### 用途 A：导入激趣（5-8 分钟，目标：制造认知冲突或好奇）

| 优先级 | 推荐范式 | 设计要点 |
|--------|---------|---------|
| 首选 | P02 点击探查、P05 动画过程、P13 3D观察、P27 尺度缩放 | 开场 3 秒必须有视觉冲击，不要空白等待 |
| 次选 | P20 情境分支、P06 对比并列 | 抛出一个反常现象或两难情境 |
| 避免 | P07/P11/P21 练习类范式 | 导入环节不该出现计分与对错判定 |

**设计要点**：不追求完整知识覆盖，只求"Wow"与"为什么"。结尾留一个悬念句，指向新知环节。

### 用途 B：新知探究（15-25 分钟，目标：让学生自己发现规律）

| 优先级 | 推荐范式 | 设计要点 |
|--------|---------|---------|
| 首选 | P03 参数滑块、P04 分步演示、P12 2D图形操作、P15 模拟实验 | 学生"动手改变 → 观察结果 → 归纳规律" |
| 次选 | P13 3D观察、P14 剖切展开、P16 虚拟测量、P17 图表数据 | 提供证据与量化 |
| 辅助 | P23 标注批注 | 让学生记录发现 |

**设计要点**：这是互动课件的**主战场**。必须满足「操作—观察—归纳」三段式：先给可操作的初始状态（有引导性，不能空白），学生每操作一次都有视觉+数值反馈，最终在面板上呈现可归纳的规律（公式卡片/结论卡/数据表）。**必须内置重置按钮**，方便反复演示。

### 用途 C：巩固练习（10-15 分钟，目标：熟练与纠错）

| 优先级 | 推荐范式 | 设计要点 |
|--------|---------|---------|
| 首选 | P01 拖拽、P07 选择判断、P08 配对连线、P09 排序、P10 分类 | 即时判定 + 错误解析 |
| 次选 | P11 填空、P22 拼图、P26 随机抽题 | 增加练习量 |
| 辅助 | P21 闯关计分 | 提供动机 |

**设计要点**：**必须给错误解析**，只判"错"不给原因等于无效练习。错题要能回看。支持一键再来一组。

### 用途 D：复习测评（15-40 分钟，目标：诊断与查漏）

| 优先级 | 推荐范式 | 设计要点 |
|--------|---------|---------|
| 首选 | P21 闯关计分、P07 选择判断、P11 填空、P26 随机抽题 | 计分、计时、错题本 |
| 次选 | P17 图表数据（生成学情图）、P19 时间轴（知识梳理） | 结果可视化 |
| 辅助 | P06 对比并列（正误对比） | 易错点集中突破 |

**设计要点**：结束页必须给出**结果总览**（得分、正确率、错题清单、知识点归因）。数据存在内存即可，无需持久化。

## 三、范式的标准结构

每个范式在生成 HTML 时都应包含以下四层。缺少任一层都会导致"看起来能玩但教学无效"。

```
┌─ 初始状态层：页面打开即刻可见的引导性内容（不能是空白画布）
├─ 操作层：学生可交互的控件与热区（触摸热区 ≥44px）
├─ 反馈层：操作后的视觉变化 + 数值变化 + 文字提示（≤0.3s 内响应）
└─ 归纳层：面板上的结论卡 / 公式卡 / 数据表 / 得分单
```

### 反馈设计的三条硬要求

1. **即时性**：任何操作必须在 300ms 内产生可见反馈，拖拽需跟手无延迟。
2. **双重编码**：视觉变化（颜色/位置/动画）必须与数值或文字变化同时出现，不能只有其一。
3. **可撤销**：所有不可逆操作都要有重置入口；标注类操作要支持撤销与清空。

## 四、范式组合禁忌

| 不要这样组合 | 原因 |
|-------------|------|
| P07 选择判断 + P21 闯关计分，出现在本该是新知探究的课件里 | 把探究变成刷题，学生只猜答案不观察 |
| P03 参数滑块 与 P05 动画过程 同时控制同一变量 | 两套时间轴互相打架，状态不可预测 |
| P13 3D观察 与 P12 2D图形操作 混在同一画布 | 坐标系与交互模型冲突，拖拽行为无法定义 |
| P23 标注批注 与学生操作层不分层 | 批注会被图形重绘覆盖 |
| 超过 4 个范式同屏 | 控制面板超过 320px 宽度的承载极限，课堂节奏散 |

## 五、从范式到页面布局

不同范式对应不同的页面骨架，不要一律用"左画布右面板"：

| 范式类型 | 推荐布局 |
|---------|---------|
| P03/P04/P05/P12/P13/P14/P15/P16/P27 | 左侧画布（占满剩余宽度）+ 右侧固定 320px 控制面板 |
| P07/P08/P09/P10/P11/P21/P26 | 居中卡片式题面 + 底部固定操作条 + 顶部进度/计分条 |
| P01/P22 | 上方目标区 + 下方待拖对象池 |
| P02/P19/P27 | 全屏沉浸画布 + 浮层式信息卡（点击时出现，可关闭） |
| P17/P18 | 图表/地图占主区 + 右侧图例与图层开关 |
| P24/P25 | 顶部情境图 + 中部对话/文本区 + 底部控制条 |

**响应式**：控制面板在 ≤1024px 宽度时移到底部变为可折叠抽屉；一体机/大屏（≥1920px）保持右栏并放大字号。
