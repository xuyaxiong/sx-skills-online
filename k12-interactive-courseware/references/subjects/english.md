## 一、学科定位与课件价值

英语最难靠口头讲清的是**发音动作与语法结构的双重不可见性**。语音层面，舌位、气流、连读、失去爆破、重音与语调都是口腔内部的动作，教师说"舌尖抵上齿龈"，学生看不见自己的舌尖在哪；语法层面，时态、语态、从句语序是抽象的形式系统，且与汉语的语序习惯冲突，靠中文翻译讲解只会强化母语负迁移。词汇层面，一个词的搭配范围与语域（正式/非正式）也无法穷举口述。

互动课件在三类点上无可替代。第一类是**发音动作的可视化**：口型剖面图配合音标播放，把"看不见的动作"变成可对照的图示，再加录音回放对比，学生第一次能听见自己的错误。第二类是**句子结构的可操作化**：把主语、谓语、宾语、状语做成可拖动的词块，学生亲手拼装才发现英语语序与汉语不同，这种"拼错了才知道"的体验无法靠讲解替代。第三类是**情境语用的安全试错**：在购物、就医、面试情境中选择应答，选错了只影响虚拟角色，不影响真实关系，学生愿意开口。

英语课件最容易做砸的地方有四：一是全程中文讲解，语言课变成关于语言的课；二是把机器合成音当标准范本却不标注，学生模仿了错误的重音；三是语法做成纯选择题，学生背规则却写不出句子；四是录音功能在教室一体机上无麦克风或权限被拒，页面直接白屏或按钮失效。此外中英混排不加空格、英文句子里混入中文全角标点，是英语课件最常见的低级错误。

### 本学科核心思维

**核心思维**：语境、语篇结构、交际功能、形义对应

- **学习结果**：在情境中完成可理解的意义表达与语用判断
- **思维落地检查**：生成课件前自问——本课的交互是否让学生在做语境、语篇结构、交际功能、形义对应这件事？若交互只是"看点东西/选个答案"，说明交互选错了，必须换成能承载该学科思维的活动。

## 三、学科专属交互范式

### 范式 S1：四线三格字母书写

- **适用**：小学三至四年级字母书写，初中书写规范纠正
- **交互**：点击字母播放书写动画（带笔顺方向箭头），再在四线三格上按笔顺描红或拖拽笔画块排序
- **视觉**：四线三格 SVG（顶线、上中线、基线、底线），上中线与基线加粗；已写笔画主蓝、当前笔珊瑚红、未写笔画浅灰虚线
- **反馈**：起笔位置错误时抖动并提示规则（从上到下、先左后右、一笔完成不回描）；面板显示第 n 笔 / 共 N 笔与用时
- **教学要点**：字母名与字母音必须分开示范，避免把 /biː/ 当 /b/ 教拼读；大小写对应位置要一起呈现

### 范式 S2：音标与口型探查

- **适用**：小学自然拼读、初中 48 个国际音标与易混音辨析
- **交互**：点击音标播放发音，切换正面与侧面口型图，查看发音部位标注；成对易混音并排对比后可录音跟读
- **视觉**：SVG 口腔剖面（上颚、舌、齿、唇），气流方向用橙色箭头动画表示，声带振动用波纹表示；易混音左右并排
- **反馈**：高亮当前音标并给出部位说明（如"舌尖抵上齿龈，气流从舌侧流出"）；录音后显示波形与示范波形并排及相似度条
- **教学要点**：一对易混音一次只讲一个区别特征（清浊、舌位前后或圆唇与否）；无麦克风时隐藏录音按钮，保留播放与跟读

### 范式 S3：句型成分拼装

- **适用**：小学描述句型、初中五种基本句型与从句、高中长难句拆解
- **交互**：把主语、谓语、宾语、定语、状语等词块拖入句子槽位，系统朗读成句并判定语序与搭配
- **视觉**：句子槽为虚线框并标注成分名，词块带词性色标（名词/动词/形容词/副词/介词），成句后整句高亮朗读
- **反馈**：语序错误提示"英语主语在前、状语常置句末"并给出正确句；正确则播放整句并显示中文对照与可替换词块列表
- **教学要点**：先给完整句再拆成词块，不要让学生从零拼装；一次只训练一个句型，避免多句型混合干扰

### 范式 S4：时态时间轴对照

- **适用**：初中时态体系入门、高中时态综合运用与辨析
- **交互**：在时间轴上拖动事件点位置，切换时态看动词形式与整句变化，可并列打开 2-3 个时态对照
- **视觉**：横向时间轴按过去/现在/将来分区着色，事件点可拖，下方动词变形卡与结构式卡（如 was/were + doing）
- **反馈**：显示该时态结构式、典型时间状语词云与"与另一时态的区别"一句话提示；错误搭配时高亮动词变形位置
- **教学要点**：同时并列不超过 3 个时态，超过则相互干扰；强调时间轴上的"时间点/时间段/完成/持续"四类语义

### 范式 S5：情境对话分支

- **适用**：小学情景对话、初中口语交际、高中话题陈述与跨文化语用
- **交互**：在购物、就医、面试等情境中选择应答句，对话按选择分支推进，走完可回退重选另一条路径
- **视觉**：对话气泡左右分列标明角色，当前轮次高亮描边，候选应答在底部操作条；情境插画置于顶部
- **反馈**：得体应答变绿并继续，不当应答变红并给出语用提示（正式/非正式、语气强弱、文化背景差异）
- **教学要点**：不判唯一对错，多个得体应答都应能走通并呈现不同后果；重点讲"对谁说、在什么场合说"

### 范式 S6：词汇语义网络

- **适用**：小学主题词汇、初中词汇策略、高中话题词汇与写作词汇准备
- **交互**：以一个核心词为中心，把近义词、反义词、固定搭配、派生词拖入对应分支；点击任一节点听发音并出例句
- **视觉**：中心词卡片加放射状分支线，分支按类别分色（近义/反义/搭配/派生），搭配以短语卡显示
- **反馈**：显示已收集搭配数与例句数；拖错分支时提示该词的实际关系并允许改放
- **教学要点**：一次只扩展一个中心词，网络层级不超过两层；例句必须来自或贴近教材语境，不生造搭配

## 四、内容规范与易错点

### 书写与排版规范

- **四线三格**：四条线用主蓝，上中线与基线加粗；字母占格按规范（a/c/e 占中格，b/d/h/k/l 占上中格，g/p/q/y 占中下格，f 跨三格，j 占三格）
- **音标呈现**：必须用国际音标字符并置于 /…/ 内，使用等宽或 IPA 字体；严禁以英文字母替代（如用 sh 代替 /ʃ/）
- **重音与语流**：主重音 ˈ、次重音 ˌ 置于重读音节前；连读用 ‿、失去爆破用括号标出该音、升调用 ↗ 降调用 ↘
- **中英混排**：中文与英文/数字之间加一个半角空格；英文标点后加空格再接英文；中文全角标点不用于英文句子内部
- **正文排版**：英文左对齐，段落顶格或首行缩进全篇二选一；行高 1.6，字号 16-18px；例句英文原句在上、中文译文在下且小一号、用次文字色
- **标点与缩写**：所有格与缩写用右单引号 '，不得写成中文引号或反引号
- **大小写**：人名、地名、月份、星期、语种、国籍首字母大写；标题实词大写，冠词、短介词与连词小写
- **词表排版**：单词列左、音标列中、释义列右，三列对齐；派生与搭配缩进二级显示
- **英美变体**：拼写、用词、音标三者择一（英式或美式），全篇统一并在页脚注明所选变体

### 科学性易错点清单

- 字母名与字母音混淆（把字母 A 的名称 /eɪ/ 当成拼读中的 /æ/）
- 音标字符用错或混用（/æ/ 与 /ɑː/、/ɪ/ 与 /iː/、/ʃ/ 与 /ʒ/、/θ/ 与 /s/）
- 单词重音位置标错，或未区分同形词的重音差异（record 作名词与动词重音不同）
- 复数与第三人称单数 -s 的发音规则讲错（/s/ /z/ /ɪz/ 的判定条件）
- 时态与体态概念混淆（把现在完成时讲成"过去发生的事"）
- 冠词 a/an 判定按字母而非音素（an hour、a university、an honest boy）
- 可数与不可数名词判定错误（advice / information / equipment / furniture 不可数）
- 定语从句关系词选择规则讲错（that / which / who / whose 的适用与省略条件）
- 虚拟语气三种时间形式与 if 主从句搭配张冠李戴
- 非谓语动词逻辑主语判定错误（悬垂分词与独立主格的混淆）
- 中文式直译表达（open/close the light 应为 turn on/off the light）
- 英美拼写与用词混用（colour 与 color、autumn 与 fall 同篇出现）
- 文化习俗表述刻板化（把某一群体的习惯说成全体国民的普遍行为）
- 中文全角标点混入英文句子，或英文标点后漏空格
- 教材版本差异未核对（人教版 PEP、外研版、译林版的单元顺序与词汇表不同）

### 数据与准确性要求

- 例句与课文原文以使用者教材版本为准，专有名词与译名全篇统一
- 音标采用国际音标现行符号；英音标注 UK、美音标注 US，两者不混排并说明所选口音
- 音频默认 Web Speech API（en-US 或 en-GB 择一并明示），须注明机器语音仅示范节奏与重音
- 录音对比须做权限失败兜底：无麦克风或授权被拒时隐藏录音按钮，保留播放与跟读，不得出现空白页面
- 词汇须标注课标级别（二级/三级/高考词汇），超纲词附中文释义

语文与英语的朗读一律使用浏览器原生 Web Speech API（`window.speechSynthesis`），零外部依赖：中文 `lang='zh-CN'`、英文 `lang='en-US'`，支持语速调节与逐句高亮同步。不得引入任何外部音频或 TTS 库。

## 七、跨学科接口

英语常作为其他学科内容的语言载体，语言课件与其他学科联合时，重点是把学科概念的表达方式（术语、图表描述、说明顺序）作为训练对象，而不是把学科知识重新教一遍。

- 节日与历法 × 地理/历史：时区、历法渊源与节日地理分布（P18 P19）
- 环保话题阅读 × 地理/生物：气候变化语料与数据图描述（P17）
- 科普类说明文 × 物理/化学：科技术语与说明顺序（P04 P23）
- 图表描述 × 数学：趋势、比例与数据比较的句型（P17 P28）
- 体育与健康单元 × 体育：规则说明与指令语表达（P25 P04）
