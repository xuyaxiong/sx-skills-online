# 学科互动课件参考：小学科学

> 本文件由主 skill `k12-interactive-courseware` 在确定学科后按需加载。
> 统一视觉系统见主 SKILL.md，交互范式总库见 `../interaction-patterns.md`，技术实现见 `../tech-patterns.md`，本文件不得重复这些内容。

## 一、学科定位与课件价值

小学科学最难靠口头讲清的是"现象背后的机制"：学生看得见水结成冰、听得到声音、能让小灯泡亮起来，但说不出水分子怎么排列、振动怎么变成声音、电流走了哪条路。这些机制要么发生在看不见的微观尺度，要么发生得太快或太慢（声音的振动、月相的变化、种子的萌发），课堂上的实物演示往往只能给出片段，学生把"看到的现象"和"要说的原因"分成两件事来记。

互动课件在三类点上无可替代：一是尺度与速度的转换，把微观放大、把长周期压缩、把瞬时过程放慢，让不可见与不可用肉眼观察的过程进入课堂；二是可控的对照实验，一次只改变一个变量，其余条件锁定，数据自动记录成表格与图表，让"控制变量"从口号变成操作；三是可试错的动手搭建，学生会连错电路、搭错装置，系统给出具体原因，纠正发生在课堂上而不是作业本上。

小学科学课件最容易做砸的地方有三：把科学课做成科普动画，学生看完只记得画面；用中学的语言与符号讲小学内容（出现化学式、矢量、公式），超出认知负担；数据编造或示意失真——太阳系按"看起来好看"的比例绘制却不加说明，学生会把它当成真实比例记住。

### 本学科核心思维

**核心思维**：观察提问、猜想假设、实证取证、解释建模

- **学习结果**：用证据支持自己的解释，形成可检验的结论
- **思维落地检查**：生成课件前自问——本课的交互是否让学生在做观察提问、猜想假设、实证取证、解释建模这件事？若交互只是"看点东西/选个答案"，说明交互选错了，必须换成能承载该学科思维的活动。

## 三、学科专属交互范式

### 范式 S1：观察—记录式探查

- **适用**：认识植物与动物、物体与材料的特征、微小世界的观察；全学段，低年级为主。
- **交互**：点击对象上的热区查看名称与特征；拖动放大镜或放大滑块改变观察尺度；在观察记录卡上勾选特征、填写发现。
- **视觉**：对象以写实或简化轮廓呈现，热区用可辨识的圆点标记；放大时视野范围同步缩小并给出放大倍数；观察记录卡常驻画布一侧。
- **反馈**：点击后弹出图文说明卡并朗读式高亮关键词；勾选特征正确时给出绿色确认；记录卡自动汇总已观察项与未观察项。
- **教学要点**：热区边长不小于 44px，低年级界面文字配图标；不要一次性铺满所有说明，先观察后揭示；记录卡要能被保存或复述。

### 范式 S2：动手搭建型实验

- **适用**：点亮小灯泡、简单电路、简单机械的组装、生态瓶的制作；中高年级。
- **交互**：从器材库拖拽元件到画布；点击端点完成连接；拨动开关或施加作用力触发实验；一键清空重试。
- **视觉**：器材用标准符号或简化实物图；导线横平竖直；成功时电路发光、灯泡点亮、机械运动；失败处用警示色标出。
- **反馈**：立即给出成败结果与具体原因（"导线未接到灯泡的螺纹侧""开关断开，电路不通"）；完成后给出原理结论卡。
- **教学要点**：先让学生连错一次再纠错，纠错环节比正确演示更有价值；器材数量要略多于所需，制造选择；必须给清空与重置入口。

### 范式 S3：变量控制对照实验

- **适用**：怎样加快溶解、种子萌发的条件、铁钉生锈的条件、摆的快慢、影响浮力大小的因素；中高年级。
- **交互**：选择要研究的变量并锁定其余条件；设置对照组与实验组；启动实验并观察；重复实验累积数据。
- **视觉**：两组（或多组）装置并排呈现，差异条件用标签标出；共同条件统一显示；现象以动画同步推进。
- **反馈**：若同时改变两个变量则提示"无法确定是哪个条件起作用"；数据自动填入表格并生成柱状图或折线图；给出结论句框架供学生补全。
- **教学要点**：变量面板必须把"改变的条件""相同的条件""观察到的现象"分三栏呈现；实验前先让学生预测；结论要由学生填，系统只给句式支架。

### 范式 S4：分类与配对

- **适用**：材料的分类、动物的分类、导体与绝缘体、物理变化与化学变化、食物链角色；全学段。
- **交互**：拖拽卡片到分类筐；或用连线把特征与对象配对；翻转卡片查看判定依据；一键换一组。
- **视觉**：分类筐带图标与名称，落区吸附高亮；卡片正反面可翻转；正确与错误分别给出反馈色。
- **反馈**：分类正确时卡片落位并给出该类的共同特征；错误时提示判断依据（如"木头不导电，属于绝缘体"）；结束后给出分类结果表与错题回顾。
- **教学要点**：分类标准必须先明确，避免多标准混用；错题必须在结束后可回看；低年级用图形卡片，高年级用文字卡片。

### 范式 S5：长周期过程动画

- **适用**：水的三态变化与水循环、月相变化、四季与昼夜、植物的生长、蚕的一生、食物在体内的旅行；全学段。
- **交互**：拖动时间轴或滑块定位到任意时刻；播放/暂停；切换季节或阶段；点击关键节点查看说明。
- **视觉**：主场景随进度重绘；阶段名称与箭头标注常驻；过程方向用箭头链表示；可叠加粒子示意（水分子、气流）。
- **反馈**：当前阶段名称与文字说明同步更新；关键节点的数值（温度、日期、天数）实时显示；循环类过程可无缝回到起点。
- **教学要点**：时间压缩必须注明（如"月相变化已加速，实际约 29.5 天一轮"）；每个阶段都要有独立说明，不能只在结尾总结；低年级阶段数控制在 3~5 个。

### 范式 S6：工程设计与测试迭代

- **适用**：造一艘小船、设计与制作小车、搭一座桥、制作保温箱、制作生态瓶；高年级与 STEM 项目。
- **交互**：选择材料与结构方案；在画布上搭建或拼装；施加测试条件（载重、风力、水温）；读取测试结果并修改方案。
- **视觉**：结构模型三维可旋转；测试过程给出受力形变或性能变化；不同方案可并排对比。
- **反馈**：给出量化结果（承重克数、行驶距离、保温时长）与评分；失败时指出薄弱处；每次修改记录为一次迭代版本。
- **教学要点**：必须保留"设计—测试—改进"的完整循环，不允许一次成功；迭代版本要可回看与对比；材料选择要有成本约束，制造权衡。

## 四、内容规范与易错点

### 书写与排版规范

- 计量单位使用规范符号：长度 cm、mm、m，体积 mL、L，质量 g、kg，温度 ℃，力 N，电流 A，电压 V；大小写严格（mL 不写 ml，L 大写，℃ 不写 C）。
- 读数表述规范：量筒读数时视线与凹液面最低处相平；温度计读数时液泡不得离开被测液体，不得俯视或仰视；刻度尺从 0 刻度起量并估读到分度值下一位。
- 数据记录：记录表格至少含"次数—测量值—单位"三列并给出平均值；异常数据保留并标注，不得直接删除。
- 图示规范：光线画实线并带箭头；电路导线横平竖直，元件用标准符号，开关断开表示断路；磁铁标注 N、S 极（N 涂红、S 涂蓝）；地图与场景图给出方向标（北在上）。
- 术语区分：溶解与熔化、蒸发与沸腾、天气与气候、重量与质量在小学阶段的表述要固定，不得混用；现象描述用"看到/听到/摸到"，结论用"说明……因为……"。
- 界面文字：一次只给一个指令；按钮文字具体（"开始实验""再加一勺"优于"确定""下一步"）；低年级关键文字配图标，字号不小于 16px。

### 科学性易错点清单

- 溶解与熔化混为一谈：溶解是溶质分散到溶剂中，熔化是固体受热变成液体
- 把水描述为"白色的液体"：应为无色、无味、透明的液体
- 认为空气没有质量：空气有质量，可用天平与气球验证
- 认为蒸发只在沸腾时发生：蒸发在任何温度下都能进行，且只在液体表面发生
- 把冰融化成水、玻璃破碎判为化学变化：均为物理变化
- 把短路当成正常通路；开关断开时仍认为电路中有电流
- 磁铁同极相斥异极相吸记反；磁铁断成两段后认为一段只剩一个磁极
- 月相变化的成因说成地球影子遮挡（那是月食）；上弦月与下弦月的亮面方向画反
- 四季成因说成地球离太阳远近：成因是地轴倾斜且空间指向不变
- 光的反射实验中把入射角按与镜面的夹角测量：应与法线的夹角
- 日食与月食时太阳、地球、月球三者的位置关系画错
- 食物链箭头方向画反；把分解者写进食物链
- 种子萌发的条件写成需要阳光和土壤：需要水、空气和适宜的温度
- 认为物体的沉浮只与轻重有关：还与排开的水量、物体体积和液体密度有关
- 材料性质实验未控制变量：同时改变厚度与材料，无法得出可靠结论
- 温度计读数时液泡离开被测液体，或俯视、仰视读数
- 把影子当成"黑色的物体"：影子是光被阻挡形成的暗区，随光源位置变化

### 数据与准确性要求

- 小学阶段数值取整数或保留一位小数，一律带单位；温度用 ℃，水量用 mL，质量用 g。
- 测量类课件要求三次测量取平均，面板上同时显示三次读数与平均值。
- 图表刻度均匀且从 0 起，柱状图柱宽一致，折线图按等时间间隔取点。
- 常用常量固定：标准大气压下水的冰点 0 ℃、沸点 100 ℃；空气中氮气约 78%、氧气约 21%。
- 所有示意图必须注明"示意图，非真实比例"：太阳系行星大小与距离、地球内部圈层厚度、细胞与微生物的放大倍数。
- 动画中的时间压缩必须说明实际时长（月相一轮约 29.5 天、地球公转一年、蚕的一生约 50 天），防止学生建立错误的时间尺度。

## 五、典型选题清单

### 小学

- 点亮小灯泡 → 拖拽电池、导线、灯泡连接回路并即时判定（P15 + P07）
- 怎样加快溶解 → 搅拌、水温、颗粒大小三变量的对照实验（P15 + P06）
- 声音是怎样产生的 → 振动可视化与频率、振幅双滑块联动（P05 + P03）
- 光是怎样传播的 → 三孔挡板对齐与影子形成的光路演示（P12 + P15）
- 物体在水中是沉还是浮 → 改变物体材料与液体，观察浮沉与浮力（P03 + P15）
- 杠杆的科学 → 支点位置与力臂长短拖拽，省力费力判定（P12 + P03）
- 月相变化 → 沿轨道拖动月球位置并同步显示相位（P19 + P13）
- 铁钉生锈了 → 三支试管的条件对照与结论归纳（P06 + P17）
- 放大镜下的世界 → 放大倍数滑块与视野同步变化（P27 + P02）
- 食物链和食物网 → 拖拽生物连线并判定箭头方向（P08 + P07）

### 初中

## 七、跨学科接口

小学科学是理科各学科的共同上游：本文件的交互骨架（对照实验、动手搭建、过程动画、尺度缩放）可直接迁移到初高中的物理、化学、生物课件，只是变量从"水温、颗粒大小"换成"电压、浓度、种群密度"。反过来，高年级的科学课件应主动按初中分科课程的语言与规范铺垫，避免学生在升入初中后重新建立概念。

- 物质与变化 → 物理变化与化学变化、溶解与溶液，升入初中后承接 `chemistry.md`
- 力、光、声、电 → 简单电路、浮力、光的传播，升入初中后承接 `physics.md`
- 生命与生态 → 细胞、食物网、人体系统，升入初中后承接 `biology.md`
- 测量与图表 → 数据记录、柱状图与折线图，与 `math.md` 的统计与图表素养对接
- 地球与宇宙 → 月相、四季、太阳系尺度，与地理的地图与空间素养对接
