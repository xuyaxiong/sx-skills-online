## 一、学科定位与课件价值

语文最难靠口头讲清的是**语言形式的不可见性**。语序、停顿、节奏、意象组合、情感层次都是"看不见的结构"，教师在黑板上只能写出结论，无法把结构本身展示出来；书写则相反，是**时间性的动作**，笔顺、笔势、间架靠静态范字讲不清楚，学生照着描也只能模仿结果，看不到过程。文本的情感与意境还依赖个体想象，教师讲解过度容易替代学生的体验，讲得越透，学生越没有自己的感受。

互动课件在三类点上无可替代。第一类是**书写过程的时序可视化**：笔顺动画把"写一横"这个动作拆成起笔、行笔、收笔三段，学生看到的是动作而不是成品。第二类是**文本的逐层探查**：点击一个词才展开它的字面义、手法、情感，既不破坏文本整体，又支持不同学生按不同节奏深入，避免一次性把赏析答案砸给学生。第三类是**变式并置**：原句与变换句左右并列、差异词高亮，让"表达效果"从一句评语变成可比较的直观差异。

语文课件最容易做砸的地方有四：一是做成"电子课本加选择题"，互动只剩翻页与勾选；二是赏析预设唯一标准答案，点哪句都弹出同一个"正确答案"标签，把阅读课变成背诵课；三是朗读用机器合成音却不标节奏，学生跟着机器学会了错误的停顿；四是动画过度，意境画面越精美，学生越不看文字。此外课文版本不核对、注释张冠李戴，是语文课件最致命的硬伤。

### 本学科核心思维

**核心思维**：语境、文本证据、结构、表达

- **学习结果**：引用文本证据完成解释或表达
- **思维落地检查**：生成课件前自问——本课的交互是否让学生在做语境、文本证据、结构、表达这件事？若交互只是"看点东西/选个答案"，说明交互选错了，必须换成能承载该学科思维的活动。

## 三、学科专属交互范式

### 范式 S1：笔顺时序描红

- **适用**：小学一至三年级识字写字，初中易错笔顺纠正
- **交互**：点"播放笔顺"看逐笔生成，再在田字格上按笔顺拖拽笔画块或手指描红；可暂停逐笔查看起收笔位置
- **视觉**：田字格（横竖中线虚线、对角线更浅）居中，已写笔画主蓝、当前笔珊瑚红带方向箭头、未写笔画浅灰虚线；右侧面板列出笔顺规则名
- **反馈**：笔序错误时该笔抖动回弹并弹出规则提示（先横后竖、先撇后捺、从上到下、从左到右、先外后内再封口）；面板实时显示"第 n 笔 / 共 N 笔""用时"
- **教学要点**：一次只教 3-5 个字，每个字必须喊出笔顺规则名；描红判定只校验顺序不校验笔迹美观度，避免挫败

### 范式 S2：诗文分层探查

- **适用**：小学高段古诗、初高中古诗文与现代散文精读
- **交互**：点击诗句中任意词语，从浮层里逐层展开字面义、手法、情感/意境三层；可把探查过的词收进"意象卡"
- **视觉**：原文居中卡片（宋体大字、行高 1.8），被点词加珊瑚红虚下划线，浮层贴边出现、可关闭、不遮挡原句
- **反馈**：已探查词数进度条与意象卡收集数；未探查的词保持常态色，形成"还有多少没读出来"的可视化
- **教学要点**：浮层必须留"我的理解"输入位，鼠标离开不自动清空；不要预设唯一答案，同一词可并存两三种合理阐释

### 范式 S3：朗读节奏与断句

- **适用**：文言文断句、古诗节奏、现代散文朗读（小学高段至高中）
- **交互**：先点播放听整句示范并同步高亮，再让学生把"/"标记拖到自认为应停顿的位置，提交后与示范节奏比对
- **视觉**：诗文大字配 ruby 注音层，停顿符橙色、延长符长横、重音字下加着重号，三者样式严格区分
- **反馈**：断句位置正确变绿并按该节奏重播，错误给出"按意义单位划分，不要读破句"的提示而非直接给答案；面板显示本句已掌握数
- **教学要点**：先听示范再让学生标，不要反过来；界面须明示"示范为机器合成语音，仅示意节奏与停顿"

### 范式 S4：句式变换对照

- **适用**：小学修辞与句型、初中病句修改、高中语言文字运用
- **交互**：选中原句后一键切换变式（把字句↔被字句、陈述句↔反问句、长句↔短句、主动↔被动），可手动增删修饰语看句子变化
- **视觉**：左右两栏并列，左原句右变句，差异词珊瑚红高亮并用箭头连接；底部一条"表达效果差异"文字卡
- **反馈**：显示变换前后的语气强弱、侧重点、适用语境三条对比；非规范变换时给"搭配不当/成分残缺"的类型标记
- **教学要点**：结论必须是"没有优劣，只有是否适配语境"，严禁给出"反问句更好"这类绝对判断

### 范式 S5：写作脚手架

- **适用**：小学高段记叙文、初中各类文体、高中议论文与任务驱动型作文
- **交互**：按"审题—选材—列纲—片段—评改"分步推进，每步从左侧素材池拖卡片入结构区并输入自己的内容
- **视觉**：居中卡片加底部操作条，左侧素材池、中部结构区、右侧成文区实时拼装
- **反馈**：字数统计、要素完整性检查（记叙文六要素 / 议论文论点论据 / 审题要素覆盖）、缺项高亮提示
- **教学要点**：只给框架不给范文代写，素材池不提供整段现成文字；必须留复制与导出按钮，方便粘贴到作文本

### 范式 S6：人物关系图谱

- **适用**：初高中名著导读、小说单元（人物众多、关系复杂的篇目）
- **交互**：点击人物节点展开身份、关键事件、性格关键词；点击关系边显示关系词与该关系的原文依据句
- **视觉**：SVG 分层或放射状关系图，节点主蓝、关系边标注关系词、中心人物放大；可按"章节/回目"筛选显示范围
- **反馈**：点边弹出原文依据句并高亮；面板显示已探查人物数与"尚未出场人物"灰显状态
- **教学要点**：必须先读片段再看图谱，避免用图谱替代阅读；剧透范围按当前教学进度裁剪

## 四、内容规范与易错点

### 书写与排版规范

- **田字格**：200×200 viewBox，横竖中线用 #E2E8F0 虚线，对角线更浅；字居中占格约 80%，教学展示不小于 160px 等效字号
- **拼音四线格**：拼音走 ruby 层，字号为汉字的 0.5 倍，声调符号不得被行高裁切；ü 与 j/q/x 相拼去两点须按规则显示
- **古诗排版**：全篇统一横排左起或居中二者择一，不得混用；句末标点必占格；若用竖排则从右向左列、行内字序不变、只加句读不加现代标点
- **断句与节奏**：停顿用「/」、延长用「——」、重音用字下着重号，三种符号样式区分，不可互换
- **多音字与通假**：多音字在字下小字标注"此处读×"；通假字统一写"×通×"，古今字写"×，后作×"
- **书名号与引号**：《》用于作品名，〈〉用于篇名中的次级篇名；引号内再用引号时外双内单
- **注释编号**：用①②③上标，与下方注释区编号一致；一篇内连续编号，不分页重置
- **作者与朝代**：作者名前冠朝代用括号，如（唐）杜甫；跨朝代人物按主要活动朝代标注并加注
- **中西混排**：中文与英文/数字之间加一个半角空格；英文标点不用于中文句子内部

### 科学性易错点清单

- 古诗平仄与押韵标注错误（尤其入声字与现代普通话读音不同，如"斜"旧读 xiá）
- 作家朝代张冠李戴（如把《岳阳楼记》列为唐宋八大家作品、把李清照整体归入南宋）
- 通假字方向写反（"说"通"悦"误写为"悦"通"说"）
- 词牌名与题目混淆（《念奴娇·赤壁怀古》中"念奴娇"是词牌，"赤壁怀古"是题目）
- 文言虚词"之"用法误判（取消句子独立性、结构助词"的"、代词三者混为一谈）
- 古今异义按今义翻译（妻子、交通、无论、烈士、牺牲）
- 修辞判断错误（互文当对偶、借代当比喻、通感当拟人）
- 说明方法与论证方法混用（"举例子"与"举例论证"不可互换）
- 课文版本与教材不一致（统编版与人教版在篇目、段落、注释上存在差异）
- 拼音标调位置错误（i u 并列标在后、轻声不标调、儿化音拼写不规范）
- 笔顺与《现代汉语通用字笔顺规范》冲突（"火""方""乃""里"等高频易错字）
- 汉字结构与部首判定错误（"冒"上部不是"曰"、"肺"右边不是"市"）
- 字号、谥号与名混用（把"东坡居士"当名、把"文忠"当字号）
- 文学常识绝对化（"第一部……""最伟大的……"判断写错或夸大）
- 意象象征义讲成固定公式（月=思乡，忽略具体语境中的变体）

### 数据与准确性要求

- 课文原文以使用者指定版本教材为准并逐字核对；不确定处标注"据××版教材"
- 古诗文引文繁简体全文统一；异文用"一作×"标注，不擅自择一而不说明
- 作者生卒年、作品创作年份只写到年，不确定者加"约"
- 外国作家与作品名采用通行译名，全篇一致（首现可括注原文）
- 朗读默认用 Web Speech API（zh-CN），界面须明示机器语音仅示范节奏与停顿

## 六、学科色规范

> 基础配色：主蓝 `#3B8DBD`、珊瑚红 `#E76F6F`、橙 `#F4A442`、绿 `#5CB85C`、深字 `#2C3E50`、次字 `#6C757D`、边框 `#E2E8F0`、浅灰虚线 `#B0BEC5`。
> 下表为本学科的语义色约定，2D 与 3D 图形一致执行；不需区分时优先主蓝/珊瑚红/橙。

| 对象 | 颜色 |
|------|------|
| 标题与正文 | 深字 `#2C3E50` |
| 重点字词高亮 | 珊瑚红 `#E76F6F` 或主蓝 `#3B8DBD` |
| 朗读进度 / 当前句 | 橙 `#F4A442` 下划线或背景 |
| 判定：正确 | 绿 `#5CB85C` |
| 判定：错误 | 珊瑚红 `#E76F6F` |
| 卡片与分区背景 | 浅蓝 `#E8F4FC` 或白 `#FFFFFF` |

语文与英语的朗读一律使用浏览器原生 Web Speech API（`window.speechSynthesis`），零外部依赖：中文 `lang='zh-CN'`、英文 `lang='en-US'`，支持语速调节与逐句高亮同步。不得引入任何外部音频或 TTS 库。

## 七、跨学科接口

语文课件天然承接其他学科的阅读材料与表达输出：理科的概念需要语言才能说清，文科的史料需要文本才能读懂，因此语文类互动课件常作为跨学科项目的"表达层"。

- 《中国石拱桥》 × 物理：拱形受力示意与结构稳定性（P02 P15）
- 《三峡》《大自然的语言》 × 地理/生物：河谷地貌、物候与气候图表（P18 P17）
- 《苏州园林》 × 美术：空间布局、框景与借景（P18 P06）
- 《出师表》《过秦论》 × 历史：时代背景时间轴与史料互证（P19 P06）
- 《昆虫记》《蝉》 × 生物：观察记录与说明性文字的写法（P02 P23）
