## 一、学科定位与课件价值

综合实践、跨学科主题学习、劳动、心理健康、安全教育与班会，共同的认知难点是**知识与行动之间的断裂**。这类课程的目标不是"知道"，而是"能做、愿做、会判断"。教师讲"过马路要看信号灯""遇到欺凌要告诉老师""番茄炒蛋先炒蛋"，学生都能复述，但真实情境中依然做不出正确反应——因为程序性知识与价值判断无法靠听讲内化，必须在模拟情境里练过一遍。

互动课件在三类点上无可替代。第一类是**情境的安全演练**：火灾逃生、陌生人搭话、网络信息甄别这类无法在真实中试错的场景，课件提供可反复试错的分支情境，错了给后果演绎而不是批评。第二类是**流程的可视推进**：劳动步骤、项目阶段、急救顺序都是"顺序即正确性"的知识，排序与分步演示能直接暴露学生的顺序错误。第三类是**共识的可视化生成**：班级公约、小组分工、评价量规这类需要集体建构的内容，课件提供共创与投票载体，把口头讨论变成可留存的结构化成果。

这类课件最容易做砸的地方有三。其一是**说教化**：整屏都是"我们要珍爱生命""劳动最光荣"的口号，互动只是一个"我知道了"按钮，学生点完即走。其二是**量化越界**：心理自评量表给分数、排名次、贴标签，把自我觉察工具变成评价工具，这是必须避免的伦理红线。其三是**假跨学科**：把语文、数学、科学的知识点拼在一屏上各自出题，缺少一个真实问题把它们串起来，跨学科主题学习的核心是真问题驱动，不是学科拼盘。

### 本学科核心思维

**核心思维**：真实问题驱动、跨学科整合、方案设计与迭代、反思评价

- **学习结果**：围绕真实问题产出可执行方案并说明改进依据
- **思维落地检查**：生成课件前自问——本课的交互是否让学生在做真实问题驱动、跨学科整合、方案设计与迭代、反思评价这件事？若交互只是"看点东西/选个答案"，说明交互选错了，必须换成能承载该学科思维的活动。

## 三、学科专属交互范式

### 范式 S1：项目式学习阶段推进器

- **适用**：跨学科主题学习、综合实践活动的项目推进，小学中年级至高中。
- **交互**：页面顶部为五个阶段的横向进度条（入项—探究—创作—展示—反思），学生点选当前阶段，主区切换为该阶段的任务卡；每个阶段需完成勾选式任务清单才能解锁下一阶段；提供"项目日历"把各阶段落到时间节点。
- **视觉**：进度条上已完成阶段用实心节点、当前阶段用脉冲高亮、未解锁阶段用灰显并加锁标记；任务卡为卡片流，含任务描述、产出物要求与完成状态；右上角显示整体完成度百分比。
- **反馈**：勾选任务后完成度实时更新并给出该阶段的产出物清单；全部阶段完成时生成一张项目小结卡，含项目名、阶段耗时、产出物列表与一句反思提示。
- **教学要点**：任务清单要具体可核查（"完成 3 次测量记录"而非"认真测量"），不可用主观词；解锁机制要保留"教师强制解锁"入口，避免个别组卡死；项目总周期建议 2-4 周，课件负责跟踪而非替代线下活动。

### 范式 S2：问题链与任务拆解

- **适用**：跨学科主题的选题与问题拆解，小学高年级至高中。
- **交互**：从一个驱动性问题出发，学生点击"为什么"逐层拆解出 3-5 个子问题，再为每个子问题绑定学科工具（观察、测量、访谈、实验、查阅、建模）；拆解完成后系统生成一张问题—方法对照表。
- **视觉**：中央为驱动性问题卡片，子问题以树状分支向两侧展开，每个节点下方挂学科工具标签（不同底色）；未绑定方法的节点用虚线描边提示。
- **反馈**：每生成一个子问题即时校验表述是否为疑问句且可探究（含"是不是""好不好"的封闭式表述给出修改提示）；全部绑定后生成可导出的研究方案框架。
- **教学要点**：驱动性问题必须来自真实情境且与学段经验相关，避免宏大空泛；教师需在拆解前给出一个示范子问题；强调"每个子问题都要有可操作的获取答案的方法"。

### 范式 S3：劳动步骤排序与安全标注

- **适用**：烹饪、种植、手工、清洁、家电使用等劳动任务，小学低年级至高中。
- **交互**：给出打乱的 6-10 张步骤卡，学生拖动排序；关键步骤处设有"安全提示"按钮，点击后弹出该步骤的风险与防护要求；排序提交后播放标准流程动画。
- **视觉**：步骤卡含序号位、简笔图示与动宾短语；涉及用火、用电、用刀、登高、热水的步骤卡带统一的警示角标；排序区下方为"我的排序"与"标准流程"两栏对比。
- **反馈**：提交后逐条判定，错误条目标出正确位置；漏掉安全步骤（如"关火后再离开"）单独提示；全部正确后显示完整流程图与一次安全要点回顾清单。
- **教学要点**：安全提示用"必须／不得"的明确句式，不写"建议小心"；涉及火、电、刀具、热水的任务必须在页面首行标注"需在教师或家长指导下实际操作"；小学阶段步骤精简到 5-6 步。

### 范式 S4：安全与交往情境分支

- **适用**：交通安全、消防、防溺水、防欺凌、网络交往、陌生人应对，小学全学段至高中。
- **交互**：给出一段情境描述与情境插画，学生从 2-4 个应对选项中作出选择，系统播放该选择的后果演绎；可返回上一节点重选，最终走到安全或不安全的结局；结局页给出应对要点复盘。
- **视觉**：情境用统一风格的简笔插画，选项为卡片式按钮；已走过的路径在侧栏以节点链呈现，当前节点高亮；不安全结局用中性色警示而非刺激性画面。
- **反馈**：每次选择后给出"发生了什么"的后果描述与一句要点提示；走到不安全结局时提示"回到上一步，换一种做法试试"，不做批评性评判；完成全部路径后显示"你已演练过 N 种情况"与要点清单。
- **教学要点**：情境设计避免恐怖化与真实伤害细节；每个情境至少有一条正确路径与两条错误路径，错误路径的后果要真实可感但不渲染；答案允许多种合理应对，重点是原则（如"不接受、不隐瞒、及时求助"）而非唯一选项。

### 范式 S5：心理自评量表与情绪温度计

- **适用**：情绪认知、压力评估、学习状态自查，小学中年级至高中。
- **交互**：5-10 道自评题，采用李克特五点计分（从"完全不符合"到"完全符合"）；作答后显示各维度的得分条与对应的描述语；另有"情绪温度计"模式，学生拖动刻度标注当前情绪强度并可选情绪标签。
- **视觉**：题目卡片单题呈现，配进度条；结果页为横向刻度条，各维度分档用不同底色区间，指针落在区间内；描述语用第一人称陈述句（如"最近你可能感到有些紧张"）。
- **反馈**：每题作答后即时进入下一题，不判对错；结果页给出描述语、一条可自行尝试的调节建议与求助途径提示；页面底部固定一行声明"本量表仅用于自我觉察，不能作为诊断依据"。
- **教学要点**：结果不得排名、不得公开、不得写入评语；不出现"心理有问题""异常"等标签化表述；必须给出求助途径（学校心理教师、心理援助热线按当地实际填写，不确定时写"学校心理教师或班主任"）；教师不索要学生的作答结果。

### 范式 S6：班级共识共创与成果画廊

- **适用**：班级公约制定、小组分工、主题班会成果、项目作品展示，小学中年级至高中。
- **交互**：学生用输入框提交一条提议（如一条班级公约），提交后进入候选池；全班对候选条目进行赞成/反对表态，得票高的条目进入公约区；最终成果以画廊形式平铺展示，可导出为图片。
- **视觉**：候选池为卡片流，每张卡片显示条目文字与表态计数；公约区为一块"公约板"，条目按得票排列；画廊模式为等宽网格，作品卡片含作品名与署名，不含分数与排名。
- **反馈**：提交即时校验字数与表述（含命令式、否定式表述时提示改写为正向表述，如把"不准打闹"改写为"课间轻声慢行"）；表态后计数实时更新；导出时生成一张成果卡，含班级、日期与条目清单。
- **教学要点**：公约条目控制在 5-8 条，过多无法执行；正向表述训练本身就是教育过程，不要代替学生改写；展示环节一律平铺不评奖，避免把共创变成竞赛。

## 四、内容规范与易错点

### 书写与排版规范

- 活动流程一律用"阶段—任务—产出物"三层结构表述，每层一句话；任务描述用可核查的动宾结构（"完成 3 次水温测量并记录"），不用"认真""积极"等主观词。
- 劳动步骤用"1. 2. 3."编号，每步一句话、动宾结构（"洗净黄瓜并切成小段"）；安全提示单独成行，用"必须／不得"句式。
- 评价量规按"维度—等级—描述语"三列表述，等级不超过 3-4 档，每档必须有描述语，不能只有分数；描述语用第二人称客观陈述。
- 心理自评题项用第一人称陈述句（"我最近睡不好"），选项用五点李克特；不得出现"你是否心理健康"这类直接判断句。
- 情绪词使用标准表述：喜、怒、哀、惧为基本情绪，焦虑、嫉妒、羞耻等为复杂情绪，二者在页面中分开归类。
- 安全情境中的报警与求助方式按国内通用口径表述（火警 119、救护 120、报警 110），页面需提示"以教材与当地实际为准"。
- 垃圾分类、急救流程等存在地域与版本差异的内容，须在页面注明"以当地现行标准为准"。
- 引用心理学理论须标注提出者（如成长型思维——德韦克；乔哈里窗——Luft 与 Ingham），不标注的理论一律不写入课件。
- 学生作品与署名使用昵称或学号后两位，不得出现真实姓名、照片与联系方式；所有输入数据注明"仅在本页使用，不保存、不上传"。

### 科学性易错点清单

- 心理自评量表被写成"心理测试""心理诊断"，或给出"正常／异常""健康／不健康"的结论标签。
- 量表结果被排名、上墙、计入评语，或教师要求学生公开作答结果。
- 情绪分类错误：把焦虑、嫉妒写成基本情绪，或把基本情绪写成六种以上。
- 结论写成"负面情绪必须消除"，正确表述是情绪本身无好坏，需要区分的是情绪与行为表达方式。
- 安全教育数值与流程错误：心肺复苏按压频率、按压深度、按压通气比写错；逃生姿势（弯腰低姿、捂口鼻）表述错误。
- 防溺水"六不准"条目内容与条数不准，或把"会游泳即可下水施救"写成正确做法（正确为不盲目下水，呼叫成人并使用器材）。
- 情境分支只设唯一"标准答案"，学生的其他合理应对被判为错误，导致原则学习变成选项背诵。
- 劳动步骤顺序错误，或关键安全步骤缺失（如用火后未关火、使用电器前未检查手部干燥）。
- 食品安全概念混淆：把"保质期"写成"保存期"，或把过期一天说成"绝对不能食用"这类绝对化结论而不说明语境。
- 垃圾分类标准照搬某一地口径，未注明"以当地标准为准"（各地名称与细分不同）。
- 跨学科主题做成学科拼盘：一屏上并列各学科题目，缺少真实问题驱动与核心任务。
- 项目式学习缺少成果产出与反思环节，只做到"查资料、做手抄报"。
- 评价量规维度与活动目标不对齐，或只有分数没有描述语。
- 引用理论不注出处，或把未经验证的网传说法（如"左右脑分工""学习风格类型"）当作科学结论呈现。
- 班会课件变成单向说教：整屏口号加一个"我知道了"按钮，没有学生表达与共创出口。
- 涉及外出的志愿服务与社区活动，未提示必须由学校或家长组织，给人以"学生自行前往"的误导。

### 数据与准确性要求

- 自评量表题量控制在 5-10 题，采用统一五点计分（1-5 分），维度得分按题项求和或取均值，页面须注明计分口径。
- 量表结果一律以描述语呈现，分档不超过 3 档且每档配一句第一人称描述；百分比取整，得分保留一位小数或不显示具体数值而只显示区间位置。
- 时间与频次类数据（活动时长、每日运动时间、劳动周期）须与教材或权威机构口径一致，无法确认时改为"由教师按实际情况填写"的可编辑字段。
- 热量与营养数据若涉及，按权威食物成分表参考值并标注"参考值"，保留整数。
- 急救与报警类数值须与页面标注的口径一致，同一页面不得出现两套相互矛盾的数值。
- 涉及地图与地域的内容须符合地图使用规范，使用合规底图与完整版图，不出现争议性边界画法。
- 所有学生输入（姓名、作答、提议）仅存于内存，刷新即清空，页面须明确标注这一点。

## 七、跨学科接口

综合实践类课件天然是学科知识的汇聚场，设计时应把"真问题"放在中心，让各学科工具围绕它被调用。与数学结合最紧密：调查类主题必然用到数据收集、整理、统计与图表解读，把统计做成项目的数据底座；与科学（物理、化学、生物）结合可做实验测量与工程搭建，如水质检测、结构承重、种植观察；与语文结合可做调查报告撰写、倡议书与成果表达，把写作落到真实读者与真实用途上；与美术与信息科技结合可做成果的可视化呈现（信息图、海报、数据看板、短视频脚本）；与道德与法治结合可做规则、责任与公共参与的价值讨论，把体验升华为判断。

---

**兜底策略：课题不在任何学科文件覆盖范围时的处理**

当用户给出的学科在 `subjects/` 下没有对应文件（如校本课程、地方课程、特殊教育、外语小语种、书法、棋类、生涯规划等），按以下流程处理：

1. **先反推交互形态，再考虑内容**：从课题名或知识点表述中提取特征词，按下表确定主范式，不要因为没有学科 reference 就退化成纯图文讲解。

| 课题／知识点特征 | 反推的交互形态 | 主范式 |
|-----------------|--------------|--------|
| 含"认识／初识／了解" + 实物或结构 | 点击探查、结构拆解 | P02 / P13 |
| 含"过程／变化／形成／演变／发展" | 动画过程、时间轴 | P05 / P19 |
| 含"比较／异同／区别／对比" | 并置对比、差异高亮 | P06 / P10 |
| 含"原理／机制／为什么／影响因素" | 参数滑块、分步演示 | P03 / P04 |
| 含"计算／换算／公式／定律／数据" | 参数联动、图表、填空 | P03 / P17 / P11 |
| 含"步骤／流程／顺序／方法／制作" | 排序、分步演示 | P09 / P04 |
| 含"分类／归类／体系／类型" | 分类归位、配对连线 | P10 / P08 |
| 含"位置／分布／区域／路线／地图" | 地图与空间标注 | P18 |
| 含"实验／探究／观察／测量" | 模拟实验、虚拟测量 | P15 / P16 |
| 含"设计／创作／表达／作品" | 创作输出 | P28 |
| 含"判断／辨析／情境／应对／选择" | 情境分支、选择判断 | P20 / P07 |
| 含"复习／检测／测评／巩固" | 闯关计分、随机抽题 | P21 / P26 |

2. **只加载通用文件**：加载主 SKILL.md、`interaction-patterns.md`、`tech-patterns.md`，跳过 `subjects/` 下所有学科文件；若课题涉及多学段，再加载 `grade-adaptation.md`。
3. **回问一句但不停工**：在生成前用一句话确认学科归属（如"该课题是否更接近某具体学科？若有对应学科文件可换用更精确的参考"），同时先按通用方案产出可用版本。若课题明显属于已有学科文件（语文、数学、英语、物理、化学、生物、历史、地理、道德与法治、音乐、美术、体育与健康、信息科技），直接切换，不要走兜底。
4. **内容只取通识表述**：使用多版本教材共有、无争议的知识点；不确定的数值设为学生可自行输入的开放参数，不硬编码"标准答案"；专业性强的术语在页面首次出现时给一句通俗解释。
5. **沿用本文件的规范**：排版、易错点与数据要求按本文件第四节执行；涉及心理、安全、个人数据的部分一律遵守匿名、不诊断、不排名、不上传四条底线。
6. **输出标注**：文件命名沿用"学科+课题+用途"，课件页脚保留一行"本课件按通用交互方案生成，内容以所用教材为准"。
