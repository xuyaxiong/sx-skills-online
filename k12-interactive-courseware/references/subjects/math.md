## 一、学科定位与课件价值

数学最难靠口头讲清的是"图形之间的位置关系与数量关系如何随条件变化"，尤其集中在三类：立体与平面的互译（展开图怎样折回立体、三视图怎样还原堆叠体）、空间中不接触元素的关系（两条直线既不相交也不平行、二面角的平面角在哪里）、参数变化对图象的整体影响（a 变一点，整条曲线怎么走）。这些内容依赖动态的空间想象，静态板画只能呈现某一个瞬间，学生看不到"变化中的不变"。

互动课件在三个点上无可替代：一是可拖拽顶点带来的动态测量，学生把图形拖到极端情况，定理关系依然成立，规律是被"发现"的而不是被"告知"的；二是立体与平面的连续互译，展开、折叠、剖切、旋转成体的过程本身承载了核心思想（化立体为平面）；三是参数与图象的同步联动，滑块一动方程与曲线同变，抽象系数获得直观意义。

数学课件最容易做砸的地方有三：把课件做成自动播放的动画，学生只观看不动手；图形失真——平行四边形画得像矩形、3D 透视让平行线相交、角度与边长比例失真，学生会据此建立错误的直观；只演示不归纳，画面精彩却在结论卡片上缺失"变的是什么、不变的是什么"。

### 本学科核心思维

**核心思维**：抽象、推理、规律、多重表征

- **学习结果**：发现规律并说明依据
- **思维落地检查**：生成课件前自问——本课的交互是否让学生在做抽象、推理、规律、多重表征这件事？若交互只是"看点东西/选个答案"，说明交互选错了，必须换成能承载该学科思维的活动。

## 三、学科专属交互范式

### 范式 S1：立体—平面互译台（展开与折叠）

- **适用**：长方体和正方体的展开图、圆柱与圆锥的侧面展开、直棱柱侧面展开；小学五年级至初中。
- **交互**：滑块控制展开程度 0%→100%，可停在任意角度；点击展开图上的任一面，立体上对应面高亮；切换不同剪开棱的方式，展开图形状随之改变。
- **视觉**：立体与展开图同屏并排或一键切换，对应面同色；展开沿棱旋转，棱线全程可见；折叠后颜色归位，遮挡面用半透明轮廓。
- **反馈**：实时显示各面面积与总表面积；切换展开方式时列出多种展开图的边长与面积对比表；折叠回立体后给出"对应关系正确/错误"判定并指出错面。
- **教学要点**：先让学生猜再展开，不要直接播放；同一立体必须演示至少两种剪开方式；圆锥展开必须同时标出母线长与底面周长，防止学生用高代替母线。

### 范式 S2：可拖拽顶点的动态测量

- **适用**：三角形内角和、三边关系、圆周角定理、平行四边形与梯形的性质、三角形面积；小学四年级至高中。
- **交互**：拖拽顶点或圆周上的动点改变图形；可锁定某个量（如周长或外接圆半径），其余量联动；切换"显示/隐藏"辅助线与测量标注。
- **视觉**：角度用扇形填充，相等角用同色；边长数值标注在线段旁；控制面板列出内角和、面积、周长、对角关系等指标卡。
- **反馈**：所有数值随拖拽实时刷新；当图形退化为极端情况（三点共线、边长越界）立即提示；恒定不变的关系量用绿色高亮并给出文字结论。
- **教学要点**：图形不得失真，任意三角形不能被画成近似等腰；拖拽热区边长不小于 44px 便于一体机触摸；每轮拖拽后必须追问"变的是什么、不变的是什么"。

### 范式 S3：参数—图象双联动

- **适用**：一次函数与二次函数、y=Asin(ωx+φ)、圆锥曲线、导数与切线；初中至高中。
- **交互**：每个系数配独立滑块（a、b、c 或 A、ω、φ、p、e）；可拖拽曲线上的点读取坐标；切换标准式/顶点式/交点式与方程同步。
- **视觉**：坐标系网格固定，曲线随滑块连续重绘；对称轴、顶点、焦点、准线、渐近线用不同线型区分；支持叠加多条曲线做对比。
- **反馈**：方程与图象同步更新；面板给出顶点坐标、对称轴、判别式、单调区间、离心率等；提供"还原"按钮回到初始参数。
- **教学要点**：滑块量程必须跨越符号变化（如 a 从 -3 到 3），否则学生看不到开口方向翻转；变换顺序（先平移后伸缩 vs 反之）必须用对比模式呈现；坐标轴刻度等距并标注单位。

### 范式 S4：三视图与堆叠还原

- **适用**：观察物体、由三视图还原几何体、小正方体计数与表面积；小学至高中。
- **交互**：在网格上点击增删小正方体；或按给定三视图"盲搭"；在正视/侧视/俯视/等轴测之间切换视角。
- **视觉**：三视图面板与立体视图同屏；被遮挡的方块用半透明轮廓表示；网格线与坐标轴保持正交，不得用透视歪曲。
- **反馈**：三视图随堆叠实时更新；显示方块总数、表面积、体积；盲搭模式下判定与目标三视图是否一致并高亮差异格。
- **教学要点**：始终强调"长对正、高平齐、宽相等"；先让学生搭再看视图，再反过来由视图搭；透视图中不得让平行棱看起来相交。

### 范式 S5：分步解题与辅助线作图

- **适用**：几何证明、复合大题（多问题干）、构造类与轨迹类问题；初中至高中。
- **交互**：上一步/下一步推进解题阶段；画笔与尺规工具添加辅助线（平行线、垂线、角平分线、圆）；切换"我的作图 / 参考答案"图层。
- **视觉**：当前步骤相关对象高亮，其余淡化；辅助线用与主图形不同的线型与颜色；学生批注与几何对象分层，不被重绘覆盖。
- **反馈**：每步配文字卡片（已知条件、结论、依据定理）；关键量（边长、角度、相似比、面积）实时计算；错误步骤给出指向性提示而非直接答案。
- **教学要点**：不得一次显示完整解答；辅助线必须支持撤销与清空；批注层必须在图形层之上且可整体隐藏。

## 四、内容规范与易错点

### 书写与排版规范

- 分式一律用上下结构（分子在上、分母在下，分数线横跨整体），不得写成 `a/b`；根号用 √ 并在被开方数上方加横线，覆盖到根号内最后一个字符。
- 变量用斜体（x、y、a、A），常量与单位用正体（π、e、cm、°）；下标表示序号或初始值（x₀、v₀、A₁B₁C₁）；多重括号按 `[( )]` 顺序嵌套。
- 几何标注：顶点用大写拉丁字母，同名多点加下标（A₁、A₂）；角必须写成 ∠ABC 或 ∠B，不得只写 ∠；线段长度 AB 与线段 AB（图形）在文字中明确区分；全等、相似符号的顶点顺序必须对应（△ABC ≌ △DEF）。
- 单位与数值：角度用 °，弧度不写单位；面积、体积单位写成 cm²、cm³；π 默认保留符号，题目要求取近似时才写 3.14 并注明。
- 图象规范：坐标轴标注名称与单位，刻度等距；实线表示包含端点，虚线表示不含；连续函数的图象不得出现断点或折角。
- 结论呈现：公式卡片中先用文字叙述关系，再给符号表达式；涉及方向的结论（如平移向量、相似比）必须给出方向或顺序说明。

### 科学性易错点清单

- 展开图与立体的对应关系错：把相对面画成相邻面，或折叠后出现面重叠、面缺失
- 圆锥侧面展开图用高代替母线长；扇形弧长误算为与底面直径相关的量
- 圆柱侧面展开图的一边写成底面直径（应为底面周长），导致侧面积公式错
- 三视图违反"长对正、高平齐、宽相等"，或漏画被遮挡结构的轮廓线
- 三角形三边关系写成 a+b≥c（应为 a+b>c），忽略"任意两边之和大于第三边"
- 相似比、面积比、体积比混淆：面积比等于相似比的平方，体积比等于相似比的立方
- 圆周角定理漏掉"一半"：同弧所对圆周角等于该弧所对圆心角的一半
- 二次函数顶点式符号错：y=a(x-h)²+k 的顶点误写为 (-h, k)
- 函数图象变换顺序错：先伸缩后平移时平移量应为 φ/ω 而非 φ
- 立体几何判定定理漏条件：如"垂直于同一平面的两条直线平行"未说明两线共面的前提
- 空间向量求二面角时未判断法向量方向，导致锐角与钝角取反
- 勾股定理用于非直角三角形，或把斜边当直角边代入
- 弧长公式与扇形面积公式混用：l=nπr/180，S=nπr²/360=lr/2
- 古典概型基本事件数错：同时掷两枚骰子为 36 种等可能结果而非 21 种
- 垂径定理误用：平分弦（非直径）的直径垂直于弦，漏掉"该弦不是直径"的条件

### 数据与准确性要求

- 几何量默认保留一位或两位小数；角度保留到整数度，需精确时写成度分秒；不出现无意义的超长小数。
- 含 π 与根号的计算同时给出精确值栏与近似值栏，近似值统一取 π≈3.14、√2≈1.41。
- 图形严格按比例绘制：网格刻度一致，平行四边形不得画成矩形，圆不得画成椭圆（3D 透视场景中的圆除外）。
- 3D 透视不得破坏平行关系与共线关系；棱长比例与标注数值一致；角度不因透视而失真。
- 随机抽题生成的参数必须保证结果简洁（可开尽的平方数、整数解、整点坐标），避免 3.9721 之类的无意义输出。
- 滑块量程与步长必须覆盖临界值（0、1、90°、e=1 等），并在临界值处给出刻度标注与文字提示。

## 五、典型选题清单

### 小学

- 圆的面积 → 等分拼成近似长方形，滑块控制等份数的拼接动画（P05 + P14）
- 长方体和正方体的展开图 → 选择正确展开图并折回立体验证（P14 + P07）
- 圆柱的体积 → 底面半径与高双滑块，剖切演示 V=Sh（P03 + P14）
- 三角形的内角和 → 拖拽三个顶点，剪拼动画验证 180°（P12 + P22）
- 平行四边形的面积 → 割补成长方形，底与高实时标注联动（P12 + P14）
- 轴对称图形 → 指定对称轴，镜像实时生成并判断（P12 + P07）
- 观察物体（三视图）→ 小正方体堆叠与三视图对照（P13 + P22）
- 图形的放大与缩小 → 位似比滑块，边长比与面积比对照（P03 + P06）

### 初中

- 勾股定理的验证 → 四个全等直角三角形拼图，面积关系分步推导（P22 + P04）
- 全等三角形的判定 → 逐项给定条件，判定三角形是否唯一确定（P06 + P07）
- 圆周角定理 → 拖动圆周上的动点，圆心角与圆周角实时对照（P12 + P03）
- 二次函数 y=ax²+bx+c 的图象 → a/b/c 三滑块，顶点与对称轴联动（P03 + P17）
- 相似三角形的性质 → 相似比滑块，周长比与面积比同屏对照（P03 + P06）
- 最短路径问题（将军饮马）→ 拖拽起点终点，对称点作图与路径长度对比（P12 + P23）
- 由三视图还原几何体 → 三视图网格填涂，立体实时生成（P14 + P22）
- 解直角三角形的应用 → 仰角俯角滑块，测量高度的分步计算（P03 + P16）

### 高中

- 圆锥曲线的定义 → 焦点与定长滑块，轨迹实时生成（P03 + P12）
- 空间几何体的外接球 → 3D 旋转与剖切，补形法分步演示（P13 + P14）
- 二面角的向量求法 → 法向量可视化，锐角钝角判定对比（P13 + P06）
- y=Asin(ωx+φ) 的图象变换 → 四参数滑块，两种变换顺序对比（P03 + P06）
- 导数的几何意义 → 割线逼近切线的动画，斜率数值收敛显示（P05 + P03）

## 七、跨学科接口

数学课件的骨架（参数—图象联动、动态测量、立体—平面互译）可以直接迁移到理科各科：物理图象、化学曲线、生物种群曲线共用同一套图表与滑块机制，只是坐标轴换成了物理量、浓度或种群数量。生成跨学科课件时，以本文件确定交互骨架，以对应学科的 reference 确定内容规范。

- 函数图象与运动学 v-t、x-t 图 → 共用 P03 参数滑块与 P17 图表，内容规范加载 `physics.md`
- 比例尺、方向与太阳高度角 → 共用 P18 地图与空间，与地理坐标和方位知识联合
- 实验数据的整理与呈现 → 共用 P17 图表与数据，与物理、化学、生物实验课联合
- 对称、密铺与结构设计 → 共用 P28 创作输出与 P22 拼图组装，与通用技术和美术联合
- 概率与统计 → 共用 P26 随机抽题与 P17 图表，与生物的遗传概率、地理的人口统计联合
