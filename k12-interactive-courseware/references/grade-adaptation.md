# 学段适配规范

> 主 skill `k12-interactive-courseware` 在阶段三（视觉设计）前必读。
> 三个澄清问题的第一问（学段）直接决定本文件的哪一档生效。

## 使用方式

按第一问答案定位到对应学段档位，取用其中的 **UI 尺度参数**（直接写进 CSS）、
**交互复杂度上限**、**反馈粒度** 与 **语言风格**，再与学科 reference 的内容规范合并执行。

**跨档原则**：相邻档位可跨界取用。例如小学高段的科普课件可以用初中的"数值+文字"反馈，
但绝不能反过来——高中课件用小学低段的夸张音效反馈会显得幼稚。

---

## 认知水平总表（先于尺度参数生效）

学段适配必须控制**知识深度、术语、信息量、推理步骤、操作复杂度和题目难度**，
不能只改变字号和按钮。

| 学段 | 内容结构 | 主要认知活动 | 操作与支架 |
|------|---------|-------------|-----------|
| 小学 | 具体情境 → 实物或图示 → 简单符号 | 观察、分类、匹配、比较、1～2 步应用 | 一次一个主要操作；短句、示范、逐步提示和即时鼓励 |
| 初中 | 现象 → 假设 → 操作 → 证据 → 结论 | 变量关系、记录、比较、归纳和简单论证 | 一次引入少量变量；允许重试，逐步减少提示 |
| 高中 | 问题 → 模型 → 证据 → 推导 → 限制 → 迁移 | 多重表征、多变量分析、证据评价和开放探究 | 说明变量、依据和模型边界；支持方案比较与反思 |

### 生成时必须确认的五条

1. 首次出现的术语有解释，难度不超出目标学段
2. 一屏信息量、推理步骤和计算难度符合年级
3. 题目认知层级与教学目标一致
4. 提示既能提供支架，又不直接泄露答案
5. **如果材料难度与教师指定年级不一致，保留教师指定年级**，并在设计说明中指出内容跨度，
   不得擅自改年级

## 档位一：小学低段（1-2 年级）

### 认知特征
- 以形象思维为主，抽象概念必须落在可见、可摸的具体对象上
- 注意力持续 10-15 分钟，单次任务链条不宜超过 2 步
- 识字量有限，**界面文字必须能读得懂或干脆不用文字**
- 手指控制精度低，需要大热区与"吸附"容错

### UI 尺度参数

| 项目 | 取值 |
|------|------|
| 正文最小字号 | 20px |
| 按钮文字 | 22px，字重 700 |
| 可点击热区 | ≥64px × 64px |
| 元素间距 | ≥20px |
| 控制面板控件数 | ≤3 个 |
| 画布占屏比 | ≥70% |
| 同屏信息组数 | ≤3 组 |

### 交互复杂度
- 单一动作即可获得反馈：点一下、拖一下就出结果
- 一次只呈现一个待操作对象，不要多目标并列
- 拖拽必须**自动吸附**到目标区（容错半径 ≥30px），不要求精确落点
- 不出现输入框、不要求键盘输入

### 反馈粒度
- 立即反馈，延迟 ≤200ms
- 视觉反馈要夸张：放大 1.2 倍、弹跳、闪光、颜色高饱和变化
- 正确时给出明确正反馈（对勾动画、星星、可选轻音效）
- 错误时**不批评**，只做温和重定向（摇一摇 + 提示"再试试"）
- 反馈信息一次只给一条

### 语言风格
- 句子 ≤10 字，用口语（"把它拖进来""数一数有几个"）
- 全拼音标注仅限一年级上学期的识字类内容
- 不用术语、不用缩写、不用被动句

### 颜色使用
- 提高饱和度与明度对比，主色占比更高
- 同一画面颜色种类 ≤5 种
- 用颜色区分对象类别时，必须同时用形状或图标区分（照顾色觉障碍学生）

### 推荐范式
P01 拖拽操作、P02 点击探查、P07 选择判断（图形化选项）、P21 闯关计分（简化版）、
P22 拼图组装、P26 随机抽题（图形题）

### 典型失败案例
- 界面出现大段文字说明
- 要求学生精确对齐才能得分
- 一次给出 4 个以上待操作对象
- 错误反馈使用红色叉号加"错误"字样

## 档位二：小学中高段（3-6 年级）

### 认知特征
- 从形象思维向抽象思维过渡，需要"具体→半抽象"的脚手架
- 能完成 2-3 步的操作链，能理解简单的因果关系
- 已具备基本读写能力，可读短句与简单术语
- 开始有竞争意识与成就感需求，适度游戏化有效

### UI 尺度参数

| 项目 | 取值 |
|------|------|
| 正文最小字号 | 18px |
| 按钮文字 | 18px，字重 600 |
| 可点击热区 | ≥48px × 48px |
| 元素间距 | ≥16px |
| 控制面板控件数 | ≤5 个 |
| 画布占屏比 | ≥65% |
| 同屏信息组数 | ≤5 组 |

### 交互复杂度
- 支持 2-3 步操作链：选择 → 操作 → 确认
- 可以出现简单参数调节（滑块刻度粗、档位少，3-5 档）
- 可以出现多目标并列（≤4 个）
- 允许简单文本输入（如填数字、填单个词语）

### 反馈粒度
- 延迟 ≤250ms
- 视觉反馈明确但不夸张
- 正确时给结果 + 一句原因（"对了，因为三角形有三条边"）
- 错误时指出错在哪 + 提示方向（不直接给答案）
- 允许出现简单数值面板（计数、得分、进度）

### 语言风格
- 句子 ≤25 字，可用学科术语但首次出现要解释
- 指令明确具体（"拖动滑块改变边长，观察面积怎么变"）
- 可出现简单的归纳性提问

### 颜色使用
- 主色 + 2-3 个辅助色
- 开始用颜色编码表示状态（正确/错误/待完成）
- 数据可视化可用（柱状图、饼图，类别 ≤5）

### 推荐范式
P01 拖拽、P03 参数滑块、P05 动画过程、P08 配对连线、P09 排序、P10 分类归位、
P14 剖切与展开、P15 模拟实验（简化变量）、P21 闯关计分、P22 拼图

### 典型失败案例
- 一次要求完成 4 步以上操作
- 滑块刻度过密（>10 档）
- 直接抛出抽象定义再让学生操作（顺序反了）
- 错误反馈只说"错了"不说原因

## 档位三：初中（7-9 年级）

### 认知特征
- 抽象逻辑思维占主导，能理解变量关系与符号化表达
- 能设计对照、控制变量，能进行简单推理
- 有自主探究意愿，反感被"喂答案"
- 同伴影响增强，小组竞争与合作机制有效

### UI 尺度参数

| 项目 | 取值 |
|------|------|
| 正文最小字号 | 16px |
| 按钮文字 | 15px，字重 500 |
| 可点击热区 | ≥44px × 44px |
| 元素间距 | ≥12px |
| 控制面板控件数 | ≤7 个 |
| 画布占屏比 | ≥60% |
| 同屏信息组数 | ≤7 组 |

### 交互复杂度
- 支持多步探究流程与"试错—修正"循环
- 支持**多变量控制**（2-3 个自变量滑块 + 对照组切换）
- 支持精确数值输入与单位切换
- 支持分步演示与步骤回跳

### 反馈粒度
- 延迟 ≤300ms
- **双重编码**：视觉变化 + 数值变化 + 文字解释，三者同现
- 出现公式卡片、数据表、结论卡
- 错误时给诊断（错在哪一步、为什么）+ 引导性问题
- 支持"再试一次"与"查看提示"分级提示

### 语言风格
- 完整句子，术语直接使用
- 可用符号、公式、单位、图表
- 可提出开放性问题与预测性问题（"猜猜会怎样？再动手验证"）

### 颜色使用
- 主色 + 辅助色，颜色开始承载语义（矢量方向、变量类别、状态）
- 数据可视化可用折线图、散点图、对照柱状图
- 仍需保证后排可读性，避免浅色细线

### 推荐范式
P03 参数滑块、P04 分步演示、P06 对比并列、P12 二维图形操作、P13 三维观察、
P15 模拟实验、P16 虚拟测量、P17 图表与数据、P19 时间轴、P23 标注批注

### 典型失败案例
- 只演示不让学生改变量
- 反馈只给"对/错"不给数值与过程
- 用小学化的夸张动画（学生会觉得幼稚）
- 一次呈现超过 3 个自变量

## 档位四：高中（10-12 年级）

### 认知特征
- 能进行形式运算与抽象推理，处理多变量系统与符号体系
- 追求严谨性，对"不精确的可视化"敏感
- 自主性强，可长时间探究，需要深度而非装饰
- 关注考试与能力迁移，重视方法归纳

### UI 尺度参数

| 项目 | 取值 |
|------|------|
| 正文最小字号 | 15px |
| 按钮文字 | 14px，字重 500 |
| 可点击热区 | ≥44px × 44px（触摸设备仍要保证） |
| 元素间距 | ≥10px |
| 控制面板控件数 | ≤9 个（可用折叠分组） |
| 画布占屏比 | ≥58% |
| 同屏信息组数 | 可超过 7 组，但需分组折叠 |

### 交互复杂度
- 支持精确数值输入、方程系数编辑、多对象开关
- 支持多步骤推导与步骤跳转
- 支持作图工具（辅助线、标注、坐标系操作）
- 支持多对象同屏对比与图层显隐

### 反馈粒度
- 延迟 ≤300ms
- 以**数据、公式、推导过程**为主要反馈，视觉动画只做辅助
- 出现方程显示、参数表、过程卡片、误差提示
- 错误时给完整诊断 + 相关知识点归因
- 可出现"参考答案"对比与自我检查清单

### 语言风格
- 严谨表述，符号与规范术语
- 可用长句与复合句
- 可出现方法论提示（"这类问题的通法是……"）

### 颜色使用
- 颜色承载语义为主，装饰为辅
- 语义色要稳定（同一变量全程同色）
- 支持多曲线、多对象配色区分（≤8 色，保证可辨）

### 推荐范式
P03 参数滑块、P04 分步演示、P06 对比并列、P12 二维图形操作、P13 三维观察、
P17 图表与数据、P23 标注批注、P27 尺度缩放

### 典型失败案例
- 为了可视化牺牲数学/科学严谨性（图形失真、比例不对）
- 用游戏化包装掩盖内容深度不足
- 数值精度不够（该给 3 位有效数字只给 1 位）
- 反馈缺推导过程，只有结论

## 通用尺度补充

### 教室大屏可读性底线（所有学段）
- 正文字号不低于上表最小值，投影/一体机场景建议再上调 10%
- 文字与背景对比度 ≥4.5:1
- 关键线条宽度 ≥2px，不要用 1px 细线表达重要结构
- 关键数据要有独立的指标卡，不要埋在图形里

### 触摸与鼠标双通道（所有学段）
- 统一使用 Pointer Events，不要只用 mouse 事件
- 拖拽元素在 `touch-action: none` 的容器内
- 长按不触发系统菜单（`-webkit-touch-callout: none`）
- 双击不触发页面缩放（`user-scalable=no` 或在容器上禁用手势）

### 学段不匹配的兜底
若用户给出的学段不在四档内（如学前教育、中职、大学），按**认知负荷**就近取档：
学前教育 → 小学低段档；中职/大学 → 高中档，并在生成时说明采用的档位。
