# 教案模版 / 版式严格遵从规范（Template Fidelity）

> 本文件规定：当调用方传入模版参数（学校模版、个人模版，或教师上传的**参考教案**）时，如何判定、如何提取版式骨架、如何把备课内容回填进骨架、以及输出前如何做结构校验。
> **本文件规则的优先级高于默认十模块结构，也高于一切内容级写作规范。** 所有学科通用。

---

## 1. 总则

### 1.1 优先级铁律（P0）

**版式骨架 ＞ 内容规范 ＞ 默认结构。**

1. **有模版时，默认十模块整表作废。** 默认十模块（教学内容 / 课标分析 / 学情分析 / 教学目标 / 教学重难点 / 教学准备 / 教学过程 / 评价设计 / 板书设计 / 教学反思预设）**仅作为"内容语义映射源"内部使用**，其模块名称一律不得出现在输出中——除非模版里本身就有同名模块。
2. **内容规范不得反客为主。** `core-design.md` 的备课要求、`math-spec.md` 的公式规则、学科规范、70 项自检，都是"内容怎么写"的规则，只能在**不破坏版式**的前提下执行。若某项内容规范与版式要求冲突（例如模版要求"教学目标"写成单行一段、而规范要求分条），**保版式、改表达**：仍写成模版要求的形态，把规范要求的信息用最贴近的方式塞进该形态，绝不为满足内容规范去新增标题、改造表格、拆分模块。
3. **版式是硬指标，内容是软填充。** 骨架一旦固化，内容只能"灌进去"，不能"撑开骨架"。

### 1.2 模版参数的有效性判定（先判定，再使用）

对入参 `备课模版` 与 `参考教案` 逐个判定：

| 判定 | 条件 | 处理 |
|---|---|---|
| **有效** | 含至少 2 个可识别的结构元素（标题行 / 字段名 / 表格表头 / 固定编号项） | 必须走本文件全流程，骨架即输出结构 |
| **需先读取** | 参数是一个文件路径、文档标识或需要识别的图片/文档，本身不含结构文本 | 先在内部读取／识别该文档拿到文本（读取动作不得向用户描述），拿到后重新按本表判定 |
| **无效** | 空值、`null`、`无`、`未提供`、`-`、`略`、`（无）`、纯占位符、只有一句无结构的说明文字；**或仅为模版名称 / 编号 / 关键词（如"表格式教案""标准教案模版A"）而没有结构文本，且读取不到内容** | 视为**无模版**，按默认十模块输出；**不追问、不提示、不在教案中说明、不得凭名称臆造模块结构** |

判定必须在动笔前完成，且只判定一次，中途不得因"模版不好用""模版太复杂"而回退到默认结构，也不得在内容写完后追加、删减、重命名模块。

### 1.3 三种形态，同一种待遇

入参可能以三种形态到达，**处理方式完全相同：只取版式，不取内容。**

| 形态 | 典型特征 | 处理 |
|---|---|---|
| ① 空白模版 | 只有标题、表格空行、字段名、下划线留白 | 直接按 §2 提取骨架 |
| ② **已填写的参考教案** | 有完整的一课时教案正文，各模块都填了具体教学内容 | **先按 §3 剥离全部内容，再按 §2 提取骨架**；内容一律当作噪声 |
| ③ 模块清单 / 大纲 | 只有模块名列表，如"教学目标、教学重难点、教学过程、板书" | 按出现顺序作为模块序列，版式细节缺省时按 §4.6 处理 |

> **关键认知**：教师上传的参考教案，其价值**只在版式**（有哪些模块、什么顺序、是不是表格、有没有基本信息表、用几级编号），**不在内容**。参考教案讲的是哪一课、用什么例子、写了什么提问，与本次要备的课无关，一律不得带入。

### 1.4 模版来源冲突时的仲裁

- `备课模版` 与 `参考教案` 同时有值 → **以 `备课模版` 为骨架来源**，`参考教案` 只在 `备课模版` 无效时顶上。
- 用户在对话中另外指定了模块结构 → 以用户当轮明确指令为准，但仍不得破坏已固化骨架的版式元素（表格、字段、编号）。
- 模版与用户提供的教材/课时信息冲突（如模版是 2 课时的表、本次只要 1 课时）→ 保留模版全部结构，按本次课时填写；空着的字段写"—"或按语义留白，**不得删模块**。

## 2. 六步骨架提取法（S1–S6）

**执行时机：必须在内部深度备课（教材分析、目标设计等）之前完成。** 先有骨架，再做内容，最后灌入。顺序反了必然漂移。

### S1 分层——识别所有结构行

逐行扫描模版原文，标出所有"结构行"，包括：

- Markdown 标题行（`#` / `##` / `###`……）
- 中文序号标题：`一、教学目标`（一级）、`（一）教材分析`（二级）、`1. 导入新课`（三级）、`（1）……`（四级）
- 方括号 / 书名号标记：`【教学目标】`、`［教学过程］`
- 顶格短行（长度 ≤ 20 字且下文另起段落的行，多为空模版里的模块名）
- 表格表头行与分隔行（`| 教学环节 | 教师活动 | …… |`）
- 字段标签行：`课题：`、`授课教师：`、`教学目标：`、`时间分配：____`

同时把**非结构行**标为内容行（正文、例句、题目、板书文字、具体环节描述等）。

### S2 定型——判定层级与编号样式

对每个结构行记录 4 项属性：

1. **层级**：按 Markdown 井号数；无井号时按序号层级判定（`一、` ＞ `（一）` ＞ `1.` ＞ `（1）` ＞ `•`）；再不行按缩进量。
2. **编号样式**：中文序号 / 阿拉伯序号 / 括号序号 / 无序号 / 方括号包裹。
3. **标题文字**：**逐字照抄**，包括标点、空格、括号全半角。
4. **书写形态**：是否带 `#`、是否加粗（模版中的加粗在骨架里记为"标题加粗标记"，输出时按 `output-format.md` §1.2 第 5 条整体不加粗，故忽略加粗但保留层级与文字）。

### S3 抽骨——删除内容，只留结构残留

把 S1 标为"内容行"的**全部删除**。仅保留以下**结构性残留**：

- 标题行本身
- 表格的**表头行 + 分隔行**（数据行全删，行数在回填时按需增加）
- 字段标签及其后的留白符：`课题：____`、`授课教师：`、`时间：______`
- 固定落款 / 页脚：`第 页`、`教研组：`、`检查签字：`
- 括号内的**填写说明**：`（可另附页）`、`（不少于 300 字）`、`（课后填写）`
- 表内固定提示语：`注：本栏由教师课后填写`

### S4 记元——记录每个模块的版式元素类型

给骨架中每个模块标注它要求的**承载形态**：

| 类型代号 | 形态 | 回填要求 |
|---|---|---|
| P | 纯段落 | 写成一段或几段自然段，不另设小标题 |
| L | 无序列表 | 用 `-` 起行 |
| O | 有序列表 | 按模版编号样式（中文/阿拉伯）起行 |
| T(n) | 表格，n 列 | **必须输出表格**，列数、表头文字与模版完全一致，行数按需增加 |
| F | 字段式（`标签：值`） | 逐字段填写，字段名原样保留 |
| B | 留白填空（`____`） | 用反引号包裹的下划线占位或填写实际内容，占位符形态与模版一致 |

### S5 定序——按原文顺序编号

把提取出的模块按**在模版中出现的先后顺序**编号，`M1、M2、M3……`，形成有序序列。模版里先出现的先输出，后出现的后输出，**顺序不得调整**。

### S6 出表——生成「版式骨架表」（内部使用，严禁输出给用户）

骨架表是一张内部清单，形如：

| 序 | 层级 | 标题原文 | 版式元素 | 关键残留 | 内容来源（内部映射） |
|---|---|---|---|---|---|
| M1 | H2 | 一、教材分析 | P | 无 | 教学内容 + 课标分析（合并段） |
| M2 | H2 | 二、学情分析 | P | （300 字以内） | 学情分析（单段） |
| M3 | H2 | 三、教学目标 | T(3) | 表头：`维度 / 目标描述 / 评价方式` | 教学目标（按素养分条） |
| M4 | H2 | 四、教学重难点 | F | `重点：` `难点：` | 教学重难点 + 突破策略 |
| M5 | H2 | 五、教学过程 | T(4) | 表头：`环节 / 教师活动 / 学生活动 / 设计意图`，括号提示`（含时间分配）` | 六环节全过程 |
| …… | | | | | |

**骨架表一旦生成即冻结**：后续所有内容设计都围绕它展开，不得在内容写完后回头改骨架。

## 3. 内容剥离红线（针对"已填写的参考教案"）

当模版参数是**一份写满内容的参考教案**时，以下内容**必须全部丢弃**，且不得在新教案中以任何形式复现（包括改写、仿写、套用句式、沿用例子）：

1. **具体学科内容**：课文原文、例题、算式、单词、实验步骤、具体知识点结论。
2. **具体教学活动的细节**：参考教案里的提问原话、教师引导语、预设的学生回答、小组讨论的分组方式。
3. **具体内容型素材**：它用的情境、故事、视频、图片、生活案例。
4. **板书的具体文字与图形**：只保留"板书位置与呈现形态"（如居中、分左右两栏、用箭头连接）。
5. **作业与检测的具体题目**：只保留"作业分几层、每层几题、有无时间要求"这类结构信息。
6. **它的课题、年级、学科、版本信息**：不得因为参考教案是三年级语文，就把本次教案写成三年级语文的口吻或难度；一切以本次入参（学科/学段/教材版本/册别/章节名称/课时安排）为准。

**保留的只有**：模块名与顺序、层级与编号样式、表格结构与表头、字段标签、留白符、填写说明、页眉页脚落款、以及"每个模块大致写多长/写几行"的体量感。

> 校验口径：把参考教案的正文全部遮住只看骨架，若仍能还原出"这是一份几模块的教案、哪个模块是表格、有没有基本信息表"，说明剥离合格。

## 4. 回填映射规则

### 4.1 语义映射表（默认内容 → 模版模块）

按语义把内部备课成果投到骨架模块上，**是"内容找模块"，不是"模块找内容"**：

| 内部备课成果 | 优先落位（按模版里存在的模块名匹配） |
|---|---|
| 教学内容 / 教材分析 | 教材分析、教学内容、教材与学情、本课教材地位、文本解读、教材简析 |
| 课标分析 | 课标分析、课程标准、课标要求、指导思想、理论依据、设计理念 |
| 学情分析 | 学情分析、学情、学生情况、学情研判 |
| 教学目标 | 教学目标、学习目标、学习目标与重难点、教学目的、学习目标定位 |
| 教学重难点 | 教学重难点、重难点、重点难点、关键问题、教学重难点及突破 |
| 教学准备 | 教学准备、教具准备、课前准备、教学具、资源与准备 |
| 教学过程 | 教学过程、教学流程、教学活动、教学程序、课堂实录（设计稿）、教学设计过程、师生活动 |
| 评价设计 | 评价设计、教学评价、评价任务、检测与评价、学习评价、当堂检测 |
| 板书设计 | 板书设计、板书、板书安排 |
| 教学反思预设 | 教学反思、教后反思、课后反思、反思预设、教学后记 |
| 作业 | 作业设计、作业布置、课后作业、练习与作业、作业与延伸 |

**匹配方法**：取模版模块名，与上表右侧候选词做语义比对，命中即落位；一个模版模块可能承接多项成果（如"教材与学情"同时承接教学内容与学情分析），此时在该模块内分段写，仍须遵守 `core-design.md` §5.0 的三模块边界（教材事实与学情判断不串写）。

### 4.2 就近并入——严禁新增模块（P0）

**模版里没有的模块，绝不新建。** 按以下顺序就近并入：

1. 有语义最接近的模块 → 并入该模块（在模块内以自然段落或列表项呈现，**不得另起标题**）。
2. 无接近模块 → 并入"教学过程"类模块（作为环节内的要素，如评价要点、检测环节）。
3. 仍无处安放 → 并入标题最靠前的相关模块，用一句过渡语带过。

常见并入示例（**这些都是错误做法的正确改法**）：

| 模版缺失 | 错误做法 | 正确做法 |
|---|---|---|
| 无「评价设计」 | 新增 `## 评价设计` | 写进教学过程各环节的"评价要点"栏；若模版有「作业/检测」模块，当堂检测并入该模块 |
| 无「板书设计」 | 新增 `## 板书设计` | 并入「教学过程」总结提升环节末尾，或并入「教具准备」后的空白位；若模版末尾有留白区则填入 |
| 无「教学反思预设」 | 新增 `## 教学反思预设` | 并入模版最后一个模块（多为「课后反思/作业」），或写在全文末尾无标题的一段 |
| 无「教学准备」 | 新增 `## 教学准备` | 教具学具并入「教学过程」首次使用时说明，或并入有"资源/教具"字样的模块 |

### 4.3 表格模块回填（最易漂移，重点执行）

学校模版大量使用表格（尤其是"教学过程"四栏表）。规则：

1. **必须保留表格**，不得改写成标题 + 段落。
2. **表头文字、列数、列顺序与模版完全一致**，一个字不改、一列不增不减。
3. **行数按需增加**：教学环节有几个就填几行；表格里若模版只有 1 行示例行，可复制到 N 行。
4. **单元格内容按列语义填**：如"教师活动"列只写教师行为，"学生活动"列只写学生行为，不串列。
5. **不新增列**：需要表达的评价要点、时间分配、分层设计等，写进对应单元格内部（可用分号或换行分隔），不得加列。
6. 表格内若模版有"（含时间分配）"之类提示，时间写进对应单元格。
7. 表格前后强制空行、每行顶格以 `|` 开头（遵守 `output-format.md` §1.1 第 7 条）。

### 4.4 基本信息表回填（最易丢失，重点执行）

很多模版开头有**基本信息表**或字段区（课题 / 年级 / 学科 / 册别 / 课时 / 课型 / 授课教师 / 时间 / 班级 / 教学目标……）。

1. **必须原样保留该表/该字段区**，一个字段都不能丢。
2. 字段值按本次入参填写：课题取 `章节名称`、年级取 `学段与年级`、学科取 `学科`、册别取 `册别`、课时取 `课时安排`、教材版本取 `教材版本`。
3. 入参里没有的字段（如授课教师、班级、日期）→ 保留字段，值留空占位（如 `______`）或写"—"，**不得删字段、不得编造具体姓名与日期**。
4. 若该表列位是"教学目标/重难点"的简写栏，写浓缩版一句话，正文仍在对应模块展开。

### 4.5 留白与"课后填写"模块

- 模版标注"（课后填写）""（上课后补写）"的模块 → **保留模块标题**，写入简短的"教学反思预设"要点（1–3 条），不得删除该模块，也不得留完全空白。
- 模版的纯留白区（如末尾的"教研组意见""检查记录"）→ 保留标签，值留空占位。

### 4.6 模版未明确的细节

- 模版只给模块名、没规定内部形态 → 按 `core-design.md` 对应模块的写作规范写（如教学目标按素养分条、学情分析单段 ≤300 字）。
- 模版模块名与默认名不同但语义相同 → 用**模版的名**，按**默认的内容规范**写。
- 模版中意思不明的模块（如"教学构想""设计说明"）→ 按字面语义就近承接内容（教学构想＝教学主线与组织逻辑；设计说明＝设计理念与课标依据），不追问、不跳过、不删。

## 5. 输出前结构校验（8 查，P0，内部完成不输出）

输出前逐项比对"成品 vs 骨架表"，**任一项不过就必须改到过为止**：

1. **模块数量一致**：成品的模块数 = 骨架表模块数，不多不少。
2. **模块名称逐字一致**：成品每个模块标题与骨架表"标题原文"逐字比对（含标点、括号、序号）。
3. **模块顺序一致**：M1→Mn 的出现顺序与骨架表完全一致。
4. **层级一致**：骨架是 H2 就输出 H2，是"（一）"就输出"（一）"，不得升级或降级。
5. **版式元素一致**：骨架标 T(n) 的必须成表且列数相同；标 F 的必须字段式；标 O/L 的必须列表；标 P 的不得擅自分条加小标题。
6. **结构残留齐全**：基本信息表各字段、留白符、填写说明、落款页脚，模版有的成品都有。
7. **无外来模块**：成品中不得出现骨架表以外的任何模块标题（默认十模块名、自拟模块名一律视为外来）。
8. **无内容污染**：成品中不得出现参考教案的具体内容痕迹（它的课题、原文、例子、提问原话、板书文字）。

**补充**：以上 8 查与 `core-design.md` §5.13 的内容自检并行执行；当内容自检的结论要求改动结构时，以结构校验为准（见 §1.1）。

## 6. 常见漂移现象与纠正对照

| 漂移现象 | 为什么会漂 | 强制纠正 |
|---|---|---|
| 用了模版，却输出默认十模块 | 默认结构记忆更强 | 有模版即作废默认表；输出前按 §5 第 7 查扫一遍外来模块名 |
| 保留模版模块顺序，但把"教学目标"改叫"学习目标" | 顺手规范化 | 逐字照抄模版模块名，一个标点都不改 |
| 模版的表格被写成标题段落 | 表格写起来麻烦 | 骨架标 T(n) 必须成表，见 §4.3 |
| 开头的课题/年级/教师信息表不见了 | 以为是装饰 | 见 §4.4，字段一个不能丢 |
| 模版没有"评价设计"，自己加了一个 | 内容规范要求评价闭环 | 见 §4.2，就近并入，绝不新增 |
| 参考教案的提问原话、情境例子被复用 | 误当内容参考 | 见 §3 六条红线，全部剥离 |
| 参考教案是哪个年级，写出来的口吻就是那个年级 | 被样本带跑 | 一切以本次入参为准 |
| 模版里"（课后填写）"的反思栏被删掉 | 觉得没内容可写 | 保留标题，写预设反思要点 |
| 骨架里是"（一）（二）"，输出成了"1. 2." | 顺手改编号 | 编号样式照抄模版 |
| 内容太多撑破了表格，于是加了一列 | 想多放信息 | 塞进单元格内，绝不增列 |

## 7. 示例（参考教案 → 骨架 → 回填）

**输入（教师上传的参考教案，节选）：**

```text
课题：《小蝌蚪找妈妈》　　年级：二年级　　学科：语文　　课时：第1课时

一、教材分析
　　本文是一篇童话，讲述小蝌蚪找妈妈的过程……

二、学情分析
　　二年级学生已经学过《乌鸦喝水》……

三、教学目标
　　1. 认识"塘、脑"等 8 个生字……
　　2. 能正确流利朗读课文……

四、教学过程
| 教学环节 | 教师活动 | 学生活动 |
| --- | --- | --- |
| 导入 | 出示青蛙图片，问：这是谁？ | 看图回答 |

五、板书设计
　　　　　小蝌蚪 → 长出后腿 → 长出前腿 → 尾巴变短 → 青蛙

六、教学反思（课后填写）
```

**剥离内容后得到的骨架（内部）：**

| 序 | 层级 | 标题原文 | 版式元素 | 关键残留 |
|---|---|---|---|---|
| M0 | 表头区 | `课题：` `年级：` `学科：` `课时：` | F | 四个字段 + 全角空格分隔 |
| M1 | H2 | 一、教材分析 | P | 中文序号"一、" |
| M2 | H2 | 二、学情分析 | P | — |
| M3 | H2 | 三、教学目标 | O | 阿拉伯序号列表 |
| M4 | H2 | 四、教学过程 | T(3) | 表头：`教学环节 / 教师活动 / 学生活动`（**3 列，无设计意图列**） |
| M5 | H2 | 五、板书设计 | P | 居中排布 |
| M6 | H2 | 六、教学反思（课后填写） | P | 括号说明保留 |

**回填要点（本次要备的是四年级语文《白桦》第 1 课时）：**

- 表头区字段保留四个，值换成《白桦》/ 四年级 / 语文 / 第 1 课时；不新增"教材版本""授课教师"等字段。
- 教材分析、学情分析照写本次内容，**不得出现小蝌蚪、乌鸦喝水等参考教案的任何痕迹**。
- 教学目标用**阿拉伯序号列表**（照抄模版编号样式），不改成"一、二、三"。
- 教学过程**必须是 3 列表格**；本课的"设计意图""评价要点"没有列可放 → 写进"教师活动"单元格内，用分号分隔，**不得加第四列**。
- 板书设计居中排布，写《白桦》的板书。
- "六、教学反思（课后填写）"标题与括号说明原样保留，写入本次的反思预设要点。
