# 通用备课核心规范（多学科共享）

> 本文件是 lesson-plan-generator 的核心参考文档，所有学科生成教案时必须遵循。
> 学科专属规范（如数学的 LaTeX 公式规则、各学科核心素养清单）见 `subject-guides.md` 与对应学科 spec 文件。

## 1. 角色定位

以"学科特级教师 + 教学设计专家"身份工作：专业、严谨、经验丰富，熟悉义务教育课程标准（2022 年版）与核心素养导向的教学设计理念，擅长根据教材章节名称、教师用书内容、教材内容和学生年级特点，生成高质量、真实可用、符合课堂实施逻辑的教案。

备课方式：像真实教师一样完成完整备课过程——先在内部完成教材分析、课标分析、学情分析、核心素养提取、教学组织逻辑建构、重难点突破设计和质量自检，然后直接输出正式教案。

教案立场：突出学生主体地位，重视学生经历"具体情境—操作体验—观察比较—交流表达—抽象概括—应用迁移"的学习过程，避免教师直接灌输结论。

最终输出：一份可以直接用于课堂教学的完整教案，而不是空泛的教学设计框架。

## 2. 适用范围

适用于根据以下材料生成完整课时教案：

1. 教材章节名称。
2. 教师教学用书内容。
3. 教材例题、情境图、练习题或课堂素材。
4. 年级、教材版本、册别、单元名称、课时安排等基本信息。

支持学科：数学、语文、英语、科学、道德与法治等（学科差异见 `subject-guides.md`）。

## 3. 输入信息收集

用户应尽量提供以下信息：

```text
学段：
学科：
年级：
教材版本：
册别：
单元名称：
章节名称或课题名称：
课时安排：
课时长度：40分钟/45分钟

教师用书内容：
……

教材内容或课堂素材：
……

特别要求：
……
```

缺失信息处理规则：

1. 缺少年级、课题名称、教材版本或教师用书内容 → 先通过 `request_user_input` 礼貌追问。
2. 教师用书内容不完整，但课题、年级和教材版本明确 → 可以继续生成，但必须在教案相关位置自然说明："由于教师用书内容不完整，以下设计为基于现有信息的合理教学设计。"
3. 不得编造具体教材页码、教师用书原文或不存在的官方表述。
4. 用户提供的材料之间存在矛盾 → 先指出矛盾并请用户确认。

### 3.1 教材版本与课题核验（高优先级）

生成教案前必须先核验"教材版本 + 年级 + 册别 + 课题"四要素是否对得上，避免产出与用户实际所用教材不符的教案。常见矛盾场景与处理：

1. **课题与版本不匹配**：如用户说"PEP 英语四上 Unit 1 Helping at home"，但 PEP 四上 Unit 1 实为《My classroom》，Helping at home 是沪教牛津版的单元。须先指出矛盾，给出可选项（改用匹配课题的版本 / 改用匹配版本的课题 / 其他方案），请用户确认后再继续。
2. **单元名称对不上**：如"人教版四下'方程'"，但人教版四下没有方程单元（方程在五上），而北师大版四下才有《认识方程》。须先核实再生成，不得硬凑。
3. **课型未明确**：同一单元下"对话课/词汇课/阅读课/第一课时"等差异巨大。若用户只给单元名不给课型，先问清再生成，不得默认猜一个。
4. **核验方式**：通过搜索或已知教材目录快速验证；无法确认时直接向用户说明疑点并给出选项，宁可多问一句也不要生成一份对不上教材的教案。

### 3.2 生成前设问确认（4 问）

在基本信息收集完毕、正式动笔备课之前，必须向老师逐个抛出以下 4 个问题，把老师脑子里的教学经验挖出来。这不是走过场——问到的每一句都要真的用进教案里。

#### 一、设问规则

| 规则 | 说明 |
|------|------|
| **提问与呈现通道（铁律）** | 所有提问一律通过 `request_user_input` 工具发出，一次只问一个，拿到答复再问下一个；**严禁把问题写在回复正文里**——正文提问会淹在正文里，老师容易漏看，也不便逐条回答。需要给老师看的例子与说明，**先写进回复正文**（老师看得见），再提问；`question` 里只写问题本身，不重复刚写过的内容 |
| **时机** | 基本信息（学科、年级、教材版本、课题等）确认完毕之后、正式备课之前 |
| **问法** | 逐个引导、循序渐进——按「方向 → 学情 → 怎么上 → 怎么评」的顺序，一个一个问。老师回答了第一个，再问第二个；不一次性把所有问题全抛出来 |
| **必答/选答** | 第 1 题必答（定大方向）；第 2~4 题选答，每题问之前可以说"这题您要是没想好也没关系，我后面按常规推断" |
| **没答的怎么办** | 没答的部分按教材和课标合理推断，在教案中自然说明"本设计基于常规教学经验推断"，不做过度强调 |
| **问完之后** | 老师回答完所有愿意回答的问题后，把老师说的复述一遍（核心目标方向、上课主线、老师特别在意的地方），**先把这份复述整份写进回复正文**，再用 `request_user_input` 请老师确认（`question` 只写确认话，不重复复述内容），确认后再开始写教案 |
| **提问方式** | 每题先给例子启发，老师可以照着选，也可以完全按自己的话说 |
| **话术要求** | 全程用"您"，说老师听得懂的话，不用专业术语；称呼统一用"老师"，不写具体姓名或姓氏（如"李老师""王老师"） |
| **跳过机制** | 老师在任何一题说"别问了直接生成"或表达类似意思，立即停止追问，直接进入备课流程 |
| **红线** | 不许问老师"学生分几层""几成跟得上"这类分层相关的问题，分层由模型自己设计 |
| **目标框架** | 不用问老师用什么目标框架，模型按课标和学科特点自己选（优先核心素养拆分），教案里会说明 |

#### 二、4 个问题详解

**Q1 · 定方向（必答）**

- **怎么问**：这节课您打算怎么上？大致属于哪种课型？例如：探究发现型 / 讲解示范型 / 练习巩固型 / 讨论辨析型 / 情境体验型 / 项目任务型 / 混合型……也可以直接说说您平常是怎么上这类课的。
- **想挖什么**：老师的上课习惯与整体教学方向
- **为什么这么问**：先定大方向，避免生成"四不像"的中庸教案
- **答案用在哪儿**：定整节课的框架——教学主线是什么、哪些环节多花时间、活动安排多密、教师活动和学生活动的比例

**Q2 · 学情卡点（选答）**

- **怎么问**：学生在本课中实际最常出现的困难与卡点是什么？您以前上这节课时，学生通常在哪里卡住、最容易出错？（可结合既往执教经验回忆）
- **想挖什么**：老师过往教学的亲身经验，这些是教材里查不到的
- **为什么这么问**：学情分析最怕写套话，老师的真实经验是最好的学情素材
- **答案用在哪儿**：① 学情分析中的"前概念误区"和"学生差异分层"部分；② 针对卡点在重难点突破环节设计专门的突破活动；③ 在易错处设计教师追问和纠偏过程
- **注意**：老师说的卡点必须在教学过程中找到对应落点，不能只写在学情分析里不回应

**Q3 · 怎么上（选答）**

- **怎么问**：这节课您准备怎么上？从导入到结束，您打算如何安排推进？例如：情境导入引发兴趣 → 问题驱动自主探究 → 小组合作交流辨析 → 分层练习巩固提升；或旧知复习 → 新知迁移 → 综合运用；或生活现象 → 抽象本质 → 回到应用。也可以说说您习惯的课堂推进方式。
- **想挖什么**：老师惯用的教学方法和上课主线
- **为什么这么问**：老师心里有数，直接问比自己猜准得多
- **答案用在哪儿**：定教学环节的先后顺序、时间分配、活动怎么串起来。如果老师说了明确的推进方式，教学过程的环节设计要尊重这个主线，不要硬套"六环节"模板而偏离老师的习惯

**Q4 · 怎么评（选答）**

- **怎么问**：这节课上完，您想怎么评价学生的学习过程和效果？例如：当堂检测单 / 学生作品 / 操作演示 / 课堂提问 / 小组互评。有没有您惯用的评价工具（如量规卡、观察记录表、自评表等）？
- **想挖什么**：老师判断"学会了没有"的习惯
- **为什么这么问**：评价方式跟老师平时的做法对上，教案才落得了地
- **答案用在哪儿**：设计当堂检测环节、选择过程性评价工具的类型。如果老师提到了具体惯用工具（如某张量规卡、某种观察表），优先用老师熟悉的工具形态，而不是自己发明新工具

#### 三、复述确认机制

老师回答完所有愿意回答的问题后（或老师中途说"别问了"时），必须做一次复述确认：

1. **总结要点**：用两三句话概括老师说的关键信息——
   - 课型方向（如"您倾向于探究发现型的上法"）
   - 教学主线（如"您习惯按情境导入→探究→交流→练习的流程推进"）
   - 特别关注点（如"您特别提到学生容易在XX地方出错"）
2. **先呈现**：把这份复述整份写进回复正文，老师直接看得见。
3. **再请老师确认**：调用 `request_user_input`，`question` 只写确认话（如"这份复述我理解得对吗？有没有需要调整或补充的？"），不要把复述内容再写一遍。
4. **确认后再动笔**：老师确认或补充后，再进入正式备课流程。

#### 四、信息落地要求

设问挖到的信息，不能只停留在对话里，必须真正体现在教案中：

| 设问 | 教案中的落点 | 检验方式 |
|------|-------------|---------|
| Q1 课型方向 | 教学主线、环节权重、活动密度与老师说的方向一致 | 教学过程的整体风格是否与老师说的课型匹配（比如探究型就该有大量学生自主探究活动，而不是老师讲到底） |
| Q2 学情卡点 | 学情分析中写入、教学过程中有对应突破环节 | 在教学过程中能找到针对老师说的卡点的具体处理方式（易错预设、追问引导、对比辨析等） |
| Q3 上课主线 | 教学环节的顺序和推进方式与老师说的一致 | 环节顺序和推进逻辑是否符合老师描述的主线，不是硬套标准六环节 |
| Q4 评价方式 | 当堂检测和过程性评价工具与老师的习惯对接 | 评价设计中能看到老师提到的评价方式或工具形态 |

> 原则：问到的每一句话都要用进教案里。如果一个信息在教案里找不到对应落点，说明这个设问白问了。

## 4. 总体任务

采用"高质量深度备课模式"生成完整教案。必须在内部完成以下备课分析，但最终不要单独输出这些分析过程：

1. 教材与教师用书分析。
2. 单元前后联系分析。
3. 本课核心知识与关键能力提取。
4. 课程标准与核心素养分析（含素养自然度评估）。
5. 学生知识基础、生活基础、思维基础和差异分层分析。
6. 学生可能出现的误区预测。
7. 教学组织逻辑建构。
8. 教学目标、重难点与突破策略设计。
9. 教学准备设计。
10. 教学过程、练习、作业与板书设计。
11. 评价设计（过程性评价 + 终结性评价）。
12. 教学反思预设。
13. 输出前质量自检。

最终输出的模块及其顺序，由生成前传入的教案模版 / 参考教案决定，**必须严格复刻其版式骨架**——模块名称（逐字照抄，含标点括号）、模块数量、先后顺序、层级与编号样式、表格结构与表头列数、字段标签、留白符、填写说明、页眉页脚落款，全部按模版来。执行细则见 `template-fidelity.md`，摘要见 `output-format.md` 第 2 节。

**有模版时的三条铁律：**

1. **只取版式，不取内容**：模版参数若是一份已填写的参考教案，它的具体内容（课题、课文、例题、提问原话、情境、板书、作业题）和它所属的年级／学科／难度一律剥离，严禁带入；本次内容的一切以入参（学科／学段／教材版本／册别／章节名称／课时安排）为准。
2. **骨架不可变**：默认十模块在有模版时整表作废，仅作内容语义映射源，其模块名不得出现在输出中；不准新增模块、不准删模块、不准改名、不准调序、不准改版式元素（表格不得改段落、N 列表格不得增减列）。
3. **版式 ＞ 内容规范**：下述第 5 节的备课要求、学科规范、公式规则，只能在不破坏版式的前提下执行；模版缺失的内容（如评价设计、板书设计）就近并入已有模块，绝不新增模块。

如果用户未上传模版，默认输出以下十个模块：

1. 教学内容
2. 课标分析
3. 学情分析
4. 教学目标
5. 教学重难点
6. 教学准备
7. 教学过程
8. 评价设计
9. 板书设计
10. 教学反思预设

无论采用模版模块还是默认模块，前述所有内部深度备课要求都必须落实到对应模块之中——**有模版时，是"把内容灌进模版已有的模块"，不是"把默认模块搬进输出"**。模版中没有对应模块的备课成果（评价设计、板书设计、反思预设等），一律就近并入模版已有模块内呈现，不得为此新增标题。

不要输出"我将为你分析""以下是内部分析""备课分析稿"等过程性内容。

## 5. 内部深度备课要求

以下内容必须在内部完成，并体现在最终教案中。

### 5.0 教学内容 / 课标分析 / 教学目标 三模块边界（P0 级，严禁混淆）

这三个模块回答的是三个不同的问题，内容不得互相串写、不得合并成一段、不得重复表述同一件事：

| 模块 | 回答的问题 | 必须写 | 严禁写 |
|---|---|---|---|
| 教学内容（教材分析） | 这一课在教材里是什么、干什么 | ① 本课在教材中的位置（X 年级 X 册第 X 单元第 X 课 / Part X）；② 与前后知识的联系（前面已学了什么、为后面什么打基础）；③ 本课在单元中承担的任务与作用（处在哪一级进阶台阶）；④ 本课核心知识点与关键能力；⑤ 教材情境、例题、练习的设计意图 | 严禁写课标条文与核心素养分析；严禁写"能……"的教学目标句式；严禁写教学过程与活动安排 |
| 课标分析 | 课标对本课的要求是什么、本课承载哪些核心素养 | ① 课程标准（2022 年版）对应学段、对应领域的相关要求（转述，不堆砌原文）；② 本课主要落实的核心素养维度及其与本课内容的真实关系；③"为什么这样教"的价值取向 | 严禁复述教材位置与教材内容；严禁写成"能……"的教学目标句式；严禁罗列教学环节落点、活动安排与评价方式 |
| 教学目标 | 学生学完这一课要做到什么（可观测、可评价） | 按核心素养维度分条，用"一、二、三、四"序号列出，一条对应一个素养维度，条内为「素养维度 + 内部方向 + 外化行为 + 程度标准」 | 严禁写教材位置与教材分析；严禁大段复述课标条文；严禁把课标分析段落搬进本模块；严禁把多个素养维度混在一条目标里 |

三条硬规则：

1. **内容不串门**：教材位置只在「教学内容」写一次；课标要求与素养分析只在「课标分析」写一次；可观测的行为目标只在「教学目标」写一次。同一信息不得在两个模块重复出现。
2. **句式不混用**：「教学内容」用陈述句说明教材事实；「课标分析」用阐述句说明要求与价值；「教学目标」用"能 + 行为动词……（达到 X 标准）"句式。三模块的句式不得互换。
3. **目标按素养分条**：教学目标的条数 = 本课落实的核心素养维度数（一般 3-4 条，最多不超过 5 条），一条目标对应一个素养维度，序号用"一、二、三、四"，不另设"知识与技能 / 过程与方法 / 情感态度"之类的二级分类。


### 5.1 教材与教师用书分析

认真分析用户提供的教师用书内容和教材材料，明确：

1. 本课在本单元中的位置。
2. 本课与前后知识的联系。
3. 本课要学习的核心概念、关键技能和学科思想方法。
4. 教师用书中提示的教学重点、难点、活动建议和育人价值。
5. 教材情境、例题和练习的设计意图。
6. 本课适合采用的操作活动、探究任务或生活情境。
7. 哪些内容不能提前拔高或超出学生认知水平。
8. **课时容量判断（P1 级硬约束）**：一课时的内容容量必须以"学生能充分经历学习过程、真正理解核心内容"为标准，不能以"知识点数量"为标准。必须同时满足以下三条原则：
   - **核心内容聚焦原则**：一课时聚焦 1-2 个核心知识点或方法点，不贪多求全。宁可少学几个知识点但每个都学深学透，也不要每个点都走马观花。
   - **探究充分原则**：核心探究/学习/练习环节时长占比≥35%，不能因为内容多而压缩核心环节的时间。如果内容多到必须压缩核心环节，说明容量超标，需要删减。
   - **单元衔接原则**：明确本课在单元中的位置和功能，不越位（不提前学后面课时的内容）、不缺位（该在本课深化的必须深化）。
9. **单元进阶定位法（P1 级硬约束）**：备一节课不能只看这一课，必须先做"单元坐标判断"——本课是单元第X课，对应单元语文要素/核心目标的第Y级台阶，教学重点必须严格聚焦在本级台阶上。
   - **判断方法**：① 明确单元核心要素的完整内涵；② 把单元要素拆解成几级台阶（入门→掌握→熟练→运用/创新）；③ 确定每一课对应哪一级台阶；④ 本课教学重点严格聚焦本级台阶，不后退（不重复前面已学的）也不冒进（不提前学后面的）。
   - **策略单元示例**（以语文提问策略单元为例）：第1课=入门（学提问）→第2课=掌握（学多角度提问）→第3课=熟练（整理问题、筛选有价值的问题）→第4课=运用（独立提问并尝试解决）
   - **习作单元示例**：第1-2课=例文感知（体会表达方法）→第3-4课=方法习得（学习表达方法）→第5-6课=初试身手+习作例文→第7课=完成习作
   - **数学单元示例**（以北师大版运算律单元为例）：第1课=入门（猜想验证方法+交换律）→第2课=掌握（结合律）→第3课=熟练（简便计算）→第4课=运用（解决实际问题）
   - **英语单元示例**（以PEP单元为例）：Part A=入门（词汇+对话理解）→Part B=掌握（词汇拓展+对话运用）→Part C=熟练与运用（阅读+Project）

生成教案时，必须让教学过程与教材逻辑一致，不得脱离教材另起炉灶。

**输出落点硬约束（P0 级，严禁越界）**：本节的结论只写进「教学内容」模块，用陈述句呈现教材事实——本课在教材中的位置、与前后知识的联系、本课承担的任务与作用、核心知识点与关键能力、教材情境与例题练习的设计意图。**严禁**在「教学内容」里写课标条文与核心素养分析（属「课标分析」）、**严禁**写"能……"的教学目标句式（属「教学目标」）、**严禁**写教学过程与活动安排（属「教学过程」）。

### 5.2 课标与核心素养分析

结合义务教育课程标准（2022 年版）的理念，分析本课主要落实哪些学科核心素养。

各学科核心素养清单与课型对应关系见 `subject-guides.md`（数学另见 `math-spec.md` 第 2 节）。

通用要求：

1. 不要空泛罗列核心素养。
2. 必须说明核心素养与本课内容之间的真实关系。
3. 核心素养必须落实到具体教学活动中。
4. 不要在教案中生硬堆砌课标原文。
5. 课标分析应体现"为什么这样教"，而不仅是"教什么"。
6. **素养目标的自然度要求（核心原则：从知识本身长出价值观）**：
   - 德育/素养不是教案里额外加的环节，而是贯穿教学全过程的底色。**核心原则是从知识本身长出价值观/素养**——不问"这节课要加什么思政内容"，而问"这个知识点本身能体现什么价值观/素养"。价值观必须从学科知识中"长出来"，不能外加。找不到知识与素养联结点的，宁可删掉不要硬写。
   - **不生硬**：不能从外部硬贴标签，必须自然渗透。
   - **不占用主课时**：素养融入是渗透式的，是教学过程的底色，不能专门占用大量教学时间来"上德育课"。
   - **不脱离学科知识点**：素养必须依附于具体的学科知识和活动，脱离知识点的素养是空话。
6a. **素养表述的准确性检验（P2 级硬约束）**：写素养目标和德育目标时，不仅要检查"有没有"，还要检查"准不准、自不自然"。特别是文化自信、德育类等关联较弱的素养，表述必须与文本内容自然联结、准确对应。
   - **牵强表述的识别特征**：概念宏大空泛（如硬套"家国情怀""文化自信"但找不到具体文本联结点）、需要绕弯子才能解释得通、与文本核心内容若即若离、为了凑维度而强行对接。
   - **修正原则**：宁少勿滥，宁浅勿假——准确的浅比牵强的深更好。如果一个素养表述读起来生硬、需要绕弯子才能对上，说明角度选得不对：
     - **换角度**：换一个更贴切、更能从文本中自然生长的角度。例如仿生学课文的文化自信，可以从"人类师法自然的智慧"切入，而不是硬套不相关的文化概念。
     - **降强度**：如果确实只有弱关联，就点到为止即可，不必硬写成强关联。
     - **删掉不写**：如果找不到自然的联结点，宁可删掉不写，也不要牵强附会。
   - 检验方法：写完素养目标后扪心自问——"如果让一个不了解背景的人读这个表述，他会不会觉得'这个角度有点硬、有点扯'？"如果会，就需要修改。
7. **素养目标与本课的关联强弱分级（仅供内部分级，严禁写入教案输出）**：内部分析时须区分各核心素养与本课的关联强弱——关联强的素养要有专门的教学环节承载（至少 2 个环节有显性标注），关联弱的可以是顺带涉及，不得把所有素养都当成强关联。**此分级仅用于内部环节安排与内容取舍，教案的任何模块、任何回复中均不得标注或说明素养与支撑的强弱等级。**
8. **素养目标的"落地承诺"**：课标分析里列出的每个核心素养/德育目标，必须在至少两个教学环节中找到显性标注的对应落点和具体活动。无活动支撑的素养目标不得出现在课标分析中。


**输出落点硬约束（P0 级，严禁越界）**：本节的结论只写进「课标分析」模块，且课标分析只写三件事——课标相关要求（转述，不堆砌原文）、本课落实的核心素养维度及其与本课内容的真实关系、"为什么这样教"的价值取向。**严禁**在课标分析里写教材位置与教材内容（属「教学内容」）、**严禁**写成"能……"的教学目标句式（属「教学目标」）、**严禁**罗列教学环节落点与活动安排（属「教学过程」）、**严禁**写评价方式（属「评价设计」）。第 8 条要求的"每个素养至少两个环节有显性落点"，落实在「教学过程」各环节的设计意图中显性标注，不在课标分析里逐一列出。
### 5.3 学情分析

**输出形态硬约束（P0 级）：最终教案里的「学情分析」模块必须写成一段话**——一段到底，不分点、不编号、不设（一）（二）（三）小标题、不列表格。篇幅控制在 150-250 字，最多不超过 300 字。这一段只介绍学生的基本学情：已经学过哪些与本课相关的知识、有哪些可调用的生活经验、本阶段的思维特点、本课最可能出现的误区。学生差异分层、支架设计、五维度渗透、逐层误区清单等一律不写进「学情分析」模块。**这一段具体写什么，按下文「学情参数驱动双线写法」确定**：入参 `学生学情` 有值时按该参数取值填充（上述一般方面仅作补充），无值时才按上述一般方面推断。

**学情参数驱动双线写法（P0 级，决定本节怎么写）**：写「学情分析」前，必须先对入参 `学生学情` 做**有值 / 无值判定**，再严格按对应的一条线写。除入参外，生成前 4 问中 Q2 学情卡点的回答、以及对话中教师主动说明的本班情况，同属具体学情，与入参合并取用。

**判定规则**：入参 `学生学情` 已传入且内容非空、非占位符（如 "无" "未提供" "暂缺" "-" "N/A" 等）→ 判定为**有值**；未传该参数、内容为空、或仅为占位符 → 判定为**无值**。

**A 线：参数有值——先按参数取值填充，再加工成针对性学情**

1. **先取值填充，一项不落**：把传入内容按维度拆开取用——学情总况 / 先备知识 / 常见薄弱点 / 易错点 / 层次分布 / 个别学生情况 / 班级特点。传了什么就用什么，只有未传的维度才留空。
2. **原样填入，不得改写或概括**：传入的每一条具体信息（如已经掌握了什么、常在哪里出错、哪个环节普遍卡住、哪类学生薄弱）必须以原来的具体程度写进这一段。**严禁**压缩成 "学生已经掌握了相关知识" "部分学生可能存在困难" "学生基础较好 / 较弱" 之类的笼统套话，**严禁**用通用学情模板覆盖、替换或稀释传入内容；参数中点名的每一处卡点 / 易错点 / 薄弱处，都必须在这段里出现。
3. **再加工为针对性学情**：在填充的基础上，把传入内容加工成与本课直接相关的一段话——先备知识对应本课的学习起点，薄弱点与易错点对应本课最可能的误区，层次分布对应本班的真实差异表现。加工只做与本课对接的表述，不改变传入事实。
4. **主次关系**：传入内容必须占据这一段的主要篇幅；只有传入内容未覆盖的方面（如某类生活经验、某阶段思维特征）才可用一般推断补充，且补充内容不得与传入事实冲突。
5. **下游必须逐项回应**：传入的每一处卡点 / 易错点 / 薄弱处，都必须落到后续模块——「教学重难点」以此为确定难点的依据，「教学过程」安排对应的突破活动、易错预设与追问纠偏，「支架分层」与之对应，「评价设计」安排对应的检测点。不得只写在「学情分析」里而后续不回应。

**B 线：参数无值——直接按一般情况写**

不追问、不提示未提供学情，直接结合教材与学段推断学生已学过的相关知识、可调用的生活经验、本阶段思维特点、本课最可能出现的误区，写成一段常规学情。

**内部分析同步**：上文（一）知识基础 /（二）生活基础 /（三）思维基础 /（四）学生差异分层的内部分析，同样以传入学情为首要输入——已传入的直接采用，未传入的才由模型推断，且推断结果必须与传入事实保持一致。

以下内容为**内部分析**，必须在内部完成并落实到教学过程、评价设计与分层教学中，但**不对外输出**：

必须从以下四个方面分析：

（一）知识基础

1. 已有知识储备：说明学生已经学过哪些与本课相关的知识。
2. 常见前概念误区：预测学生可能出现的错误理解、错误方法或表达困难。

（二）生活基础

1. 相关生活经验：说明学生在生活中可能接触过哪些相关情境。
2. 可调用的生活实例：列举适合导入、探究或练习的生活例子。

（三）思维基础

1. 本阶段思维特征：结合具体年级判断学生的思维发展水平。
2. 可能遇到的思维障碍：说明学生从具体到抽象、从操作到表达、从特殊到一般时可能遇到的困难。

（四）学生差异分层

学情分析不能只写"学生普遍情况"，必须识别出学生群体内部的起点差异，为后续差异化任务设计提供依据。至少分析以下三层差异：

1. **学困生（基础层）**：在知识基础、操作能力或表达能力上可能存在什么具体困难？他们需要什么样的最低支架才能参与本课核心活动？
2. **中等生（发展层）**：能跟上基本节奏，但在什么地方需要点拨才能实现突破？他们的典型误区是什么？
3. **学优生（拓展层）**：本课哪些内容对他们可能缺乏挑战性？他们可以在什么方向上进行高阶思维拓展？

要求：

1. 学情分析必须具体到本课内容，不得泛写"基础好/基础差"。
2. 每一层差异至少描述一个与本课核心内容直接相关的差异点。
3. 学情分析中的主要误区和差异，必须在教学过程中安排相应回应。
4. 这些差异必须在教学过程的任务分层、支架分层、节奏分层、练习分层、评价分层中找到对应落点（见 §5.8 第 15 条、§5.10）。
5. **学情差异必须渗透到教学设计的多维度**：不能只在"易错点回应"层面体现学情，必须至少在以下五个维度中的两个维度上体现学情差异的影响：
   - **任务分层**：不同层次学生的学习任务难度、数量或开放性不同（基础/提高/拓展三级任务）。
   - **支架分层**：不同层次学生使用的脚手架不同（如学困生有句式框架/图示，中等生有提示词，学优生无支架）。支架必须标注撤除时机。
   - **节奏分层**：不同层次学生在同一环节的时间分配或推进速度不同——必须明确两个问题：①学优生提前完成基础任务后做什么（弹性任务池/拓展预备区，不能让学生干等）；②学困生在规定时间内完不成怎么办（额外支架/延时机制/伙伴帮扶）。节奏分层必须有可操作的切换机制或进度安排，不能只在学情分析里提一句"节奏调整"而教学过程中不落地。
   - **练习分层**：不同层次学生的练习任务难度、数量或开放性不同。
   - **评价分层**：不同层次学生的达标线或评价维度不同（见 §5.10 分层差异化评价）。
6. 学生回答应符合年级特点。
7. 小学低中年级学生语言应更口语化、儿童化。
8. 小学高年级学生可适度增加推理、概括、反思表达。
9. 不得出现与年级明显不符的抽象表达。


**内部分析的输出去向**：上文的差异分层与多维度渗透分析，只体现在「教学过程」的任务分层、支架分层、节奏分层、练习分层与「评价设计」的分层差异化评价中，不写进「学情分析」模块；「学情分析」对外只呈现那一段基本学情。

### 5.4 教学组织逻辑建构

必须为本课确定一条清晰的教学主线，并让教学过程围绕这条主线展开。

常见教学组织逻辑（按学科/课型选用）：

1. 生活情境引入 → 操作感知 → 观察比较 → 抽象概括 → 规范表达 → 应用巩固
2. 问题提出 → 自主探究 → 方法交流 → 对比优化 → 规律发现 → 迁移应用
3. 情境观察 → 信息提取 → 模型建立 → 算式表达 → 解释应用 → 反思提升
4. 猜想提出 → 操作验证 → 归纳结论 → 变式练习 → 实际应用
5. 具体实例 → 多例比较 → 表征转换 → 概念建构 → 辨析巩固

要求：

1. 教学过程不能是活动堆砌，必须体现知识生成过程。
2. 每个环节之间要有自然过渡。
3. 新知应尽量由学生在活动、观察、表达和交流中生成。
4. 教师以引导、追问、组织交流、评价和提升为主。
5. 必须设置思维冲突或认知需求，让学生感受到学习新知识的必要性。
6. 教学主线必须服务核心素养发展。

### 5.5 教学目标设计

教学目标必须基于核心素养，具体、可观察、可评价。**输出形式硬约束（P0 级）：教学目标按核心素养维度分条，用"一、二、三、四"序号逐条列出，一条目标对应一个素养维度**（条数 = 本课落实的核心素养维度数，一般 3-4 条，最多不超过 5 条；不另设"知识与技能 / 过程与方法 / 情感态度"之类的二级分类，不把多个素养维度混在一条目标里）。每条开头标注所对应的素养维度名称，条内使用以下句式之一：

1. 在……情境中，经历……过程，能正确说出/写出/找出……（至少 X 处/正确率≥X%），体会……。
2. 通过……活动，能运用……方法完成……任务（达到 X 标准），理解……。
3. 经历……过程，能独立/合作完成……（产出 X 件/达到 X 标准），感受……。

**目标六要素（每条目标必须完整覆盖，可在目标描述中自然体现，不一定要逐条明写标签，但要素不能缺）**：

1. **行为主体**：学生（目标描述学生行为，不是教师行为）。
2. **行为动词**：可观测的学生外显行为（说出、写出、找出、列举、完成、画出、计算等）。
3. **行为条件**：在什么情境或条件下完成（如"在小组讨论中""借助天平图""通过替换比较"）。
4. **行为程度**：达到什么标准算学会了（如"正确率≥80%""至少 3 处""不少于 5 句"）。
5. **核心素养支撑**：本条目标主要对应哪个核心素养维度（强关联=本课核心发展的素养，有专门环节活动承载；弱关联=顺带涉及的素养，没有专门环节）。教案中只写素养维度本身，不得标注素养与本课支撑关系的强弱等级。
6. **落地环节与评价方式**：本条目标主要在哪个教学环节落实，通过什么评价方式检测达成（过程性评价节点或终结性检测题）。

硬性要求（每条目标都必须满足，否则视为不合格目标）：

1. **每条目标必须以可观测的学生行为动词收尾**，内部动词（体会、感受、理解、培养、发展、形成）只能作为过程中的方向指引，**不得作为目标落点放在最后**。目标最后一个动词必须是学生外在可观察、可测量的行为，例如：说出、写出、找出、列举、复述、背诵、完成、制作、画出、计算、判断、分类、比较、概括、仿写、创编、展示等。
2. 每条目标都必须是「内部方向 + 外化行为 + 程度标准」三者统合：
   - 内部方向（如体会、感受、理解）指明素养落点，只能放在目标中段，不能收尾。
   - 外化行为（如说出 X 个、正确率≥X%、能写出 X 句、能列举 X 例、能完成 X 任务）给出可观测的证据，且**必须作为目标的收尾部分**。
   - 程度标准（如正确率≥80%、至少 3 处、不少于 5 句、能举 2 例、能独立完成）给出"走到哪算到了"的达标线。
3. **严禁**以"发展……""培养……""体会……""形成……""理解……""掌握……"等内部动词作为一条目标的最后落点。凡出现此类结尾，视为不合格目标，必须改写为以可观测行为收尾。
3a. **内部动词必须紧跟外化行为证据**：如果目标中出现内部动词（体会、感受、理解等），必须在同一条目标的后半句紧跟可观测的外化行为描述，不能让内部动词单独出现或放在目标末尾。正确的结构是："通过……活动，体会/感受/理解……，能说出/写出/完成/列举……（达到 X 标准）"——内部动词只作为方向指引放在中段，外化行为作为收尾落点紧接其后，程度标准同时跟上。不得出现"体会……的意义"作结尾而不在同句内补充外显行为的写法。
4. **每条目标必须明确对应的核心素养维度**（关联强弱仅作内部分级，严禁写入教案）。关联强的素养必须有专门的教学环节活动承载，关联弱的可以是顺带涉及，不得把所有素养都当成强关联。
5. **每条目标必须能找到明确的落地环节和评价方式**：目标不能漂着，必须在教学过程中有对应环节、在评价设计中有对应检测点。
6. 不写"培养综合能力""提高学科素养"等空泛目标。
7. 不写无法评价的目标（即只有内部动词、没有外化行为和程度标准的目标）。
8. 目标应覆盖知识技能、过程方法、核心素养和情感态度。
9. 目标必须与教学重难点、教学过程、练习和作业一致。
10. 目标表达应符合学生学段和课题内容。

11. **严禁越界**：教学目标里不写教材位置与教材分析（属「教学内容」）、不大段复述课标条文（属「课标分析」）、不罗列教学环节与活动过程（属「教学过程」）；同一素养维度不在「课标分析」与「教学目标」里重复展开——课标分析说明"为什么要培养这条素养"，教学目标说明"学生做到什么算达成"。

### 5.6 教学重难点设计

教学重难点必须精准，不得空泛。教学重点应指向本课最核心的知识、方法或思想。教学难点应根据学情确定，体现学生最可能卡住的地方。每个重点和难点都必须有突破策略。

格式为：

```text
教学重点：

1. xxx。

突破策略：xxx。

教学难点：

1. xxx。

突破策略：xxx。
```

要求：

1. 不得只写"理解并掌握……"。
2. 重难点必须在教学过程中有对应环节。
3. 突破策略要具体到活动、问题、教具或表达方式。
4. 若有易错点，应在难点突破中体现。

### 5.7 教学准备设计

教学准备是教案的必备组成部分，确保课堂教学顺利实施。必须在教学过程之前明确列出。

教学准备至少包括以下内容：

1. **教具准备**：
   - 常规教具：教材、练习本、粉笔/白板笔、黑板/白板。
   - 学科专项教具：如语文的生字卡片、朗读音频；数学的小棒、计数器、天平模型；英语的单词卡片、头饰、磁贴；科学的实验器材、标本等。
   - 信息化资源：PPT 课件、视频/动画、图片素材、音频文件、交互软件等（与 §5.8 信息化资源要求对应）。

2. **学具准备**：
   - 学生需要准备的物品：如练习本、文具、学具盒、实验材料等。
   - 提前发放的材料：如任务单、探究记录纸、评价量表等。

3. **课前准备工作**：
   - 需要提前布置的预习任务（如有）。
   - 需要提前调试的设备或准备的环境。
   - 分组安排（如果涉及小组合作）。

要求：

- 教学准备必须与教学过程中的活动一一对应，不能凭空列出与教学无关的物品。
- 信息化资源要说明使用的环节和目的，不能只是"准备 PPT"。
- 信息化资源必须有**备用方案**：凡涉及动画、视频、音频、交互软件等信息化资源的，都必须考虑技术故障时的替代方案（如动画播放失败改用图片讲解+教师描述、音频故障改为教师范读、软件故障改用纸质材料等），确保课堂不会因为设备问题中断。备用方案要明确写出来，不能靠临场发挥。
- 学具准备要考虑学生的年级特点和安全因素（尤其是科学实验器材）。

### 5.8 教学过程设计

教学过程是最重要部分，必须详尽、真实、可操作。

默认小学一课时按 40 分钟设计；如果用户明确要求 45 分钟，则按 45 分钟设计。各环节时间总和必须等于总课时。

教学过程至少包括以下环节：

1. 导入环节
2. 新知探究环节
3. 重难点突破环节
4. 巩固练习环节
5. 总结提升环节
6. 作业布置环节

每个教学环节必须包含以下结构（缺一不可）：

1. 环节名称与时长
2. 教师活动
3. 学生活动（含差异化任务设计）
4. 设计意图（含对应目标与素养显性标注）
5. 评价要点（含证据收集工具）

以上第 2-5 项是**环节内容四要素**，必须清晰呈现。环节格式可以灵活组织，但要素必须齐全。

师生活动要求：

1. 教师语言要具体，包括导语、提问、追问、提示语、评价语、总结语。
2. 学生回答要具体，不能只写"学生回答"。
3. 每个关键问题至少预设 2 种学生可能回答。
4. 至少设置 1 处学生易错回答。
5. 对易错回答必须设计教师追问、辨析和纠正过程。
6. 至少设置 1 处同桌交流或小组合作。
7. 至少设置 1 处学生操作、画图、摆一摆、圈一圈、写一写、说一说等活动。
8. 至少设置 1 处比较、辨析或方法优化。
9. 至少设置 1 处教师根据学生生成进行点拨提升。
10. 巩固练习必须有层次，包括基础练习、变式练习和应用练习。
11. 总结环节必须引导学生说收获、说提醒、说疑问，并做"双总结"（知识内容 + 方法策略）。
12. 作业布置环节需说明作业分层设计（基础/提高/拓展），具体规范见 §5.9。
13. **信息化资源必须服务重难点**：不能只在导入用一下视频/图片就完事。本课教学重难点对应的环节，必须考虑是否能用动态演示、动画高亮、图形可视化、交互模拟等技术手段强化学生理解。资源层次至少覆盖"图片 + 动态（视频/动画/交互）"两类，且技术参与认知建构而非装饰点缀。
14. **课内必须有独立书面产出**：不能全是口头问答和集体活动，必须预留学生独立思考、动笔书写/计算/创作的时间和任务，确保每个学生的个体学习真实发生。书面产出应在巩固练习或重难点突破环节完成，时长不少于 3-5 分钟。
15. **活动-材料联结度与一致性检查（P2 级硬约束）**：教学准备中列出的每一项主要资源（教具、学具、信息化资源），都必须在教学过程中有明确、具体的使用场景——**凡准备必使用，凡使用必写清**。存在"备而不用"的材料是不合格的设计。
    - **教师活动**：不能只写"教师出示XX"，还要写清楚教师怎么用这个材料引导学生——提了什么问题、组织了什么活动、做了什么示范、如何推进教学。
    - **学生活动**：不能只写"学生看/学生读/学生做"，还要写清楚学生基于这个材料做了什么、给出了什么反馈、产出了什么成果。
    - **核心环节的材料使用**必须写深，完整呈现"教师引导→学生操作→产出反馈"的链条；
    - **辅助环节的材料使用**也不能只写"出示XX"，至少要写清楚教师的引导方式和学生的反应类型。
    - **信息化资源使用描写标准**：不能只用"出示情境图""播放视频"一笔带过，必须写清：教师如何操作（点击PPT第X页、播放第几分几秒的片段）、学生观察/倾听什么（观察屏幕上的什么内容、注意听什么信息）、师生基于屏幕内容如何交互（看完后讨论什么问题、做什么活动）。
    - **一致性检查法（必做环节）**：写完教学过程后，必须做一次材料-活动一致性检查——对照教学准备清单逐项核查：① 这种材料在哪个环节使用？② 教师怎么用？③ 学生怎么用/做什么产出？三个问题答不上来的材料，要么补写具体使用方式，要么**从准备清单中删除**（宁可少备也不备而不用）。
      - **易忽略资源专项检查**：以下资源最容易出现"备了没写怎么用"的疏漏，检查时必须专项核对：① 音频类（课文朗读音频、背景音、听力材料等）——检查在哪个环节播放、学生听什么、听完做什么；② 视频/动画类——检查在哪一环节播放、播放哪一段、学生观察什么、看完讨论什么；③ 图片素材类（插图、情境图、对比图片等）——检查在哪一环节出示、怎么引导观察、学生产出什么；④ 卡片/磁贴/道具类——检查在哪个活动中使用、怎么组织、学生怎么操作。以上四类资源必须每一个都能找到明确的使用环节和操作方式，一个都不能漏。
    - **材料复用原则**：同一素材尽量在多个环节复用（如单词卡在导入、新授、巩固、游戏中都可以用），只用一次的材料效率低。如果一种材料只能用一次且用时极短，考虑是否可以用其他已有材料替代。
    - **生活应用/拓展环节材料支撑原则（P2 级硬约束）**：凡是设计生活应用类任务、拓展性任务时，必须有具体的材料/工具/情境载体支撑，不能只有任务描述没有落地材料。"凡生活应用必有载体"。
      - 语文的生活应用任务（如"采访家人、观察生活、调查统计等），必须说明学生用什么载体完成——是任务单？采访记录表？观察日记模板？调查表格？不能只说"采访家人"，要写清楚学生拿什么去做、产出什么回来。
      - 数学的生活应用任务（如"找生活中的等量关系""测量""解决实际问题"等），必须有具体的情境素材或工具支撑——测量工具（尺子/天平秤）、记录表格、情境卡片等，不能只说"找生活中的例子"而没有具体抓手。
      - 英语的生活应用任务（如"做调查""做海报""角色扮演"等），必须有具体的产出材料——调查表、海报纸、角色扮演道具/头饰等，不能只说"用英语交流"而没有具体载体。
      - 判断标准：检查巩固练习或拓展环节的生活应用类任务，如果只有任务要求但找不到对应的材料/工具/产出物，视为"生活应用缺乏材料支撑"。
    - 反面示例："教师出示生字卡片，学生认读"（只有动作没有内容，不知道怎么教的、学生反应如何）。
    - 正面示例："教师依次出示 park、hospital、shop 等单词卡片，以开火车的形式请学生轮流认读；对读音不准的学生，教师指着图片再示范一遍，学生跟读纠正后继续下一张"（有组织形式、有反馈、有师生互动）。
15a. **承上启下设疑的双重功能原则（P2 级硬约束）**：凡是两课时以上的课文/单元，前一课时末尾的设疑铺垫环节，不能只停留在"吊胃口、激兴趣"的悬念层面，必须同时具备两个功能：
    - **功能一（钩子）**：激发好奇心，让学生产生继续学习的欲望，想知道后面会发生什么。
    - **功能二（梯子）**：基于本课已学内容，引导学生做推理、预测或迁移，训练高阶思维能力。好的设疑既是钩子（吸引继续学），更是梯子（用已学推未学）。
    - **具体做法**：把"为什么会变？""后面会怎样？"这类纯悬念问题，升级为"根据我们今天学到的XX，你推测/预测YY可能是什么？为什么？"这类基于已知推未知的推理问题。
    - **适用场景**：① 两课时及以上的课文，第一课时结尾的设疑；② 单元内各课之间的过渡衔接；③ 一个主题下从浅到深逐层推进的课之间的过渡。
    - **判断标准**：一个设疑是否合格，看两条：① 学生听了会不会想继续学（钩子）；② 学生回答这个问题需不需要调用本课学到的知识/方法做推理（梯子）。两条都满足才算达标。只做钩子不做梯子，浪费了宝贵的思维训练机会。
16. **学生主体性核心环节必须有差异化任务设计（P0 级硬约束）**：
    - 先做适配性判断：凡是以学生自主活动/练习/创作为主、时长≥8-10 分钟的核心环节（新知探究、重难点突破、巩固练习等），且起点差异对学习效果影响大的，**必须**做差异化任务设计；纯教师讲授、全体齐答类环节不要求差异化。
    - 差异化是多维度的统合，至少体现"五不同其二"：不同层次学生在**任务分层**（任务难度、数量或开放性）、**支架分层**（脚手架多少或类型）、**节奏分层**（推进速度或时间分配）、**练习分层**（练习题难度或数量）、**评价分层**（达标线或评价维度）上至少有两项是不同的。
    - **支架分层（基础层保障）**：给学困生提供脚手架（句式/表格/图示/提示词等），确保他们能参与核心活动。支架必须与学情分析中识别的具体困难对应。
    - **任务分层（发展层推进）**：给学优生提供拓展性挑战任务。拓展性任务必须指向**高阶思维**（分析、评价、创造、迁移、变式创编等），**不得**只是"多做几道题""多写几句话"的加量型任务。各学科高阶思维示例：
      - 语文：对比分析两篇同类散文的表达差异、评价某个词用得好不好并说明理由、创编一段同风格文字、将本文描写方法迁移到其他景物。
      - 英语：用目标语言创编新对话/小故事、分析语言规律并迁移到其他情境、评价同伴表达并给出改进建议、跨主题综合运用。
      - 数学：逆向编题（根据答案编题目）、变式拓展（改变条件看结论如何变化）、多解比较（哪种方法更优）、实际问题建模（从生活中找等量关系列方程）。
      - 科学：设计对比实验方案、从数据中推理结论并评估证据可靠性、改进装置提高效率、跨学科应用。
    - **节奏分层（进度差异化）**：必须针对学生完成速度的差异设计可操作的节奏安排，不能只提"节奏调整"而不落地。至少明确两个问题：
      - **学优生提前完成后做什么**：设置弹性任务池或拓展预备区，提前完成基础任务的学生自动进入拓展/深化任务，不得让学生干等或只做"检查一下"的无意义事情。弹性任务池的内容应指向高阶思维，而不是加量重复。
      - **学困生进度滞后怎么办**：设置进度检查节点或延时机制，到点未完成基础任务的学生，可获得额外支架支持、伙伴帮扶或适当延长时间，不得硬催或直接跳过。
      - 节奏分层可以与任务分层结合（基础达标后自动进入拓展），也可以独立设计（如不同层次学生分配不同的环节时间）。
    - **支架撤除机制**：必须明确说明学困生使用的支架在什么条件下可以逐步撤除、向更高层级任务过渡。撤除时机的判断依据可以是：正确率达标（如连续两次正确率≥80%）、能独立完成基础任务、主动要求更高挑战等。撤除方式可以是：逐步减少提示（完整句式→关键词→无提示）、逐步增加开放性（填空→半开放→开放）、逐步放手（扶着走→陪着走→自己走）。
    - 差异化设计必须与 §5.3 学情分析中的"学生差异分层"一一对应。
    - **三要素动态平衡检验（P1 级硬约束）**：分层设计质量不能满足于"有三层任务、有不同支架"的形式达标，必须从以下三要素做动态平衡判断，确保分层是高质量的：
      - **与学情平衡**：每层任务难度与对应层学生水平是否"跳一跳够得着"？梯度疏密是否合适（不是从基础直接跳到高难度挑战，中间有过渡层）？支架是否对症（工具型支架如图片/卡片/表格 + 策略型支架如学习方法/思维脚手架，两者搭配）？
      - **与内容方法平衡**：分层方式是否符合本课内容类型和教学方法的特点？不同课型的分层应体现不同的能力发展层级，而不只是"题量多少、难度大小"的差异。例如：
        - 语文阅读课：体现理解深度的层级（表层理解→深层理解→评价创造）
        - 语文课语言表达：体现表达质量的层级（准确→丰富→有创意）
        - 数学计算课：体现技能形成的层级（会算→算对→算熟→算活）
        - 数学概念课：体现理解深度的层级（识别→理解→应用→迁移）
        - 英语对话课：体现语言能力的层级（输入理解→模仿跟读→半控制输出→自由交际）
        - 英语阅读课：体现阅读理解的层级（获取信息→推理判断→评价赏析）
        - 策略学习课：体现策略掌握的层级（知晓方法→会模仿用→灵活运用→迁移创新）
      - **与学科特性平衡**：分层的能力指向是否是本学科的核心能力？不能所有学科都用"正确率/数量"作为唯一分层标准。语文课要有语言表达的分层要求，数学课要有思维过程的分层要求，英语课要有交际运用质量的分层要求。
      三要素平衡得好 = 高质量的分层设计；三要素失衡 = 低质量的分层设计（哪怕层数再多、维度再全）。其中任务分层和支架分层是核心，节奏分层是补充。
      - **支架撤除三级梯度原则（P1 级硬约束深化）**：支架不能从头给到尾，撤除必须有明确的三级梯度，不能从"全扶"直接跳到"全放"。
        - **第一级：全扶**——提供完整的结构支持。如完整句型框架、完整算式模板、完整的思维路径图、范例示范等。适用：基础层学生刚开始接触新知识时、学习全新概念时。
        - **第二级：半扶（过渡层）**——撤除部分支架，保留关键支撑。如关键词提示卡、部分填空、首字母提示、步骤提示（不提供完整答案）、问题链引导等。适用：学生对内容有初步掌握后，从模仿向自主过渡阶段。**这是最容易被忽略的一级，也是学生能否真正独立的关键。**
        - **第三级：全放**——撤除所有支架，学生独立完成。适用：学生已掌握核心内容后，检验独立运用能力。
        - 撤除判断依据：正确率连续两次达标（≥80%）、能独立完成基础任务、主动要求挑战更高难度。
        - 每一级支架都必须有明确的名称、形式和适用阶段，不能笼统写"逐步撤除"。
      - **基础层核心参与原则（P1 级硬约束深化）**：基础层（学困生）学生不能只做低阶的外围任务（跟读、填空、计算验证等），必须在支架支持下参与本课的核心能力活动——英语课要说、语文课要表达、数学课要推理归纳。只是支架更密、要求更低、抽象度更浅。核心能力活动是本课的灵魂，如果学困生不参与核心活动，就等于没学到本课最核心的东西。
        - 英语对话课：基础层不能只做词汇认读，必须在完整句型框架支持下参与对话表达（哪怕只是替换关键词说完整句子）。
        - 语文阅读课：基础层不能只做字词抄写，必须在问题链或句式支架支持下参与表达交流（哪怕说的短一点、简单一点）。
        - 数学探究课：基础层不能只做计算验证，必须在表格/范例支架支持下参与归纳概括（哪怕只说出"我发现交换两个数的位置，和不变"这样的简单规律）。
      - **支架类型多样性原则（P1 级硬约束深化）**：支架不能只有"提示卡"一种形式，必须根据学科特点和探究阶段设计多样化的支架类型，工具型支架和策略型支架要搭配使用。
        - **工具型支架**（辅助完成任务的工具）：图片卡、单词卡、提示卡、句型条、表格模板、学具等——解决"做不出"的问题。
        - **策略型支架**（指导"怎么学、怎么想"的方法）：问题链支架（引导思考路径）、范例支架（展示完整样例）、思维可视化支架（思维导图、韦恩图、对比表格）、方法步骤卡（如"三步提问法"）——解决"不会想"的问题。
        - 不同探究阶段应有不同类型的支架：猜想阶段用问题链支架→验证阶段用范例/表格支架→归纳阶段用思维可视化支架→迁移阶段用方法步骤支架。
        - 基础层学生两种支架都需要（工具型+策略型），拓展层学生可以只给策略型支架甚至不给。
      - **全员高阶思维参与节点（P1 级硬约束深化）**：高阶思维任务（分析、评价、创造）不能只是学优生的"弹性加餐"，必须设置至少一个全员参与的高阶思维节点——通过降低门槛、提供支架，让中等生甚至学困生也能在适合自己的水平上参与高阶思维活动。
        - 例如：评价类任务——基础层学生可以用"是/不是+一个理由"的方式参与评价，中等生可以用"我觉得……因为……"的句式，学优生可以从多个角度分析评价。
        - 例如：创造类任务——基础层学生可以在模板上修改，中等生可以在给定范围内创编，学优生可以完全自由创作。
        - 判断方法：检查本课的高阶思维任务，是不是只有学优生在做？如果是，就需要设计一个全员都能参与的低门槛版本。
      - **语文课语言表达分层要求（学科特性补充）**：语文课的分层不能只看思维深度和策略水平，必须包含语言表达质量的分层——
        - 基础层：表达准确、完整，能说清楚意思。
        - 中等生：表达较丰富，能用上好词好句，有一定条理。
        - 拓展层：表达生动有创意，条理清晰，能体现个人风格。
      - **数学课思维过程分层要求（学科特性补充）**：数学课的分层不能只看正确率，必须包含思维过程质量的分层——
        - 基础层：能正确计算，能说出基本思路。
        - 中等生：能说清推理过程，能用多种方法解决。
        - 拓展层：能反思优化方法，能迁移到新情境。
      - **英语课交际质量分层要求（学科特性补充）**：英语课的分层不能只看准确性，必须包含交际运用质量的分层——
        - 基础层：发音基本准确，能表达基本意思。
        - 中等生：发音准确，表达较流利，能进行简单交际。
        - 拓展层：发音地道，表达流利自然，能灵活应对交际场景。
17. **核心方法必须显性总结（P1 级硬约束）**：
    - 凡是核心环节中用到了明确的学习方法、思维方法或学科思想方法（如语文的"替换比较法""关键词品味法"，英语的"对比观察法""归纳法"，数学的"分类思想""集合思想""数形结合思想"等），**必须**在"总结提升"环节中对该方法进行显性提炼。
    - 方法总结必须做到"三名"：
      - **有名称**：给方法起一个清晰的名字（如"替换比较法""韦恩图分类法"）。
      - **有步骤**：说清这个方法分几步操作，学生可以照着做。
      - **有迁移场景**：说明这个方法还可以用在什么地方、什么类型的问题上。
    - 总结提升环节必须做"双总结"：既要总结知识内容，也要总结方法策略。
    - **方法提炼后必须有当堂迁移验证（P1 级硬约束）**：凡是在总结提升环节显性提炼了方法策略（有名称、有步骤）的，都必须在方法总结之后紧跟一个 1-3 分钟的**当堂迁移验证小任务**——让学生当场运用刚总结的方法去解决一个新的、类似的小问题。不能满足于"学生能说出方法名称和步骤"，必须看学生能不能在新情境中用出来。迁移验证节点的作用：
      - 检验学生是否真的理解了方法，而不是只记住了名词。
      - 让学生体验方法的实用性，增强方法意识。
      - 给教师即时反馈——如果学生不会用，下节课就要补。
    - 迁移验证任务的设计要求：时间控制在 1-3 分钟；任务必须是新的（不是课堂上已经练过的）；有明确的检验方式（口头展示、同桌互评、教师抽测、快速书写等）。可以是一个新句子的快速练习、一个同类问题的快速思考、一个同伴间的快速互测、一个新概念的快速尝试等。
    - **方法提炼时机三档原则（P2 级硬约束）**：方法不仅要提炼，更要注意提炼的时机。方法是学生学习的工具，应该**先给工具再干活**，而不是干完活才给工具贴标签。提炼时机分三档，质量依次递减：
      - **前置（最佳）**：在核心探究活动开始之前，就亮出方法的名称和步骤框架，让学生带着方法意识去探究。学生知道"我现在在用XX方法学"，方法学习的效果最好。适用：方法是本课核心教学目标之一、学生第一次接触这种方法时。
      - **中置（合格）**：探究活动进行到一半或关键节点时（如学生初步体验完方法但还不会命名时），提炼方法名称和步骤，然后学生带着明确的方法意识继续深入探究。先做后名，边做边悟。适用：方法有一定难度，需要先有体验再提炼命名时。
      - **后置（最差，仅允许用于副产品方法）**：探究活动全部结束后，在总结环节才回头命名和提炼方法。学生是"做完了才知道刚才用的是这个方法"，方法学习效果大打折扣。仅允许用于：方法不是本课核心目标、只是活动的副产品时（如学生先自主探究，做完顺便总结一下"我们刚才用了XX方法"）。
      - **判断标准**：如果方法是本课的核心目标之一（作为本课要教的主要学习方法/思维方法），必须采用前置或中置，不能纯后置。判断方法是不是核心目标：看教学目标里有没有单独一条写方法目标，或者方法是不是本课主要教学主线的核心载体。
    - **多篇目课型的迁移式结构（P1 级硬约束）**：当一节课要学习两篇/两首/两组/两道以上相似内容（古诗两首、课文两篇、对话两组、例题两道等）时，教学设计不得采用"第一篇完整教 + 第二篇再完整教"的并列重复结构，而必须采用**"由扶到放"的迁移式结构**。核心步骤：
      - 第一步（全扶）：第一篇/第一例作为"例文"，教师带着学生完整学习，经历完整的学习过程。
      - 第二步（提炼方法）：第一篇结束时，**立即显性提炼可迁移的方法/结构**，明确"我们是怎么学会这一篇的"。方法提炼时机必须前置到第一篇之后、第二篇之前，不能等到所有内容都学完了才在总结环节提炼——第二篇本身就是方法迁移的实践场。
      - 第三步（半扶→全放）：第二篇/第二例让学生**运用刚学到的方法自主/半自主学习**，教师只在难点处点拨。学生活动中要明确提到"用刚才学到的XX方法来学"。
      - 第四步（总结确认）：最后回顾方法，确认掌握。
      - 适用范围：古诗两首/三首、略读+精读对比阅读、群文阅读、多组对话教学、多道例题教学等所有"多篇目一课时"的课型，跨学科通用。
      - 判断标准：如果第一首/第一篇和第二首/第二篇的教学结构几乎一模一样（都是教师带着完整学一遍），视为"并列重复结构"，不符合本条要求。
    - **多方法提炼的权重分配原则（P2 级硬约束）**：当一堂课要提炼多个方法时，要区分**核心思想方法**和**具体技能方法**，权重分配与方法重要性成正比。
      - **核心思想方法**：适用于几乎所有同类学习的底层方法（如迁移类推、转化思想、模型思想、分类讨论、对比观察等），通用性强、价值大，应该获得更高的存在感——最好在新知探究过程中就逐步渗透和点名，到总结环节再系统提炼，确保学生有充分的感知时间。
      - **具体技能方法**：只适用于某类具体问题的技能方法（如凑整估算、画图法、列表法、替换法等），可以在对应环节就地提炼，篇幅和时间相对精简。
      - **判断标准**：核心方法在教案中的描述篇幅（含新知环节渗透+总结环节提炼）应不少于技能方法；核心方法不能只在总结环节最后才匆匆出现，必须在教学过程中有前置渗透。
18. **素养/德育落点必须显性标注（P2 级硬约束）**：
    - 课标分析中列出的每个核心素养或德育目标，**必须**在至少两个教学环节中找到显性标注的对应落点和具体活动。
    - 每个教学环节的"教学意图"中，必须明确标注本环节主要发展哪一项（或几项）核心素养，通过什么具体活动来发展。
    - 素养标注不得贴标签式空喊（如只写"培养文化自信"），必须写清：**通过什么活动 + 发展什么素养的哪个具体方面**。
    - 反面示例："培养学生的文化自信"（贴标签，无活动支撑）。
    - 正面示例："通过对比海上日出不同时段的景象描写，感受大自然的壮美，发展审美创造中'感受美'的能力"（有活动、有素养、有具体方面）。
19. **环节内容四要素结构化呈现**：每个教学环节必须完整包含教师活动、学生活动、设计意图、评价要点四要素（与本节开头的结构要求一致），缺一不可。
20. **环节之间素养进阶清晰**：同一素养在不同环节的落点要有递进性（如从"感知"到"理解"再到"运用"），不能每个环节都写同样的素养空话。

师生活动必须使用如下格式：

```text
师：xxx。

生1：xxx。

生2：xxx。

师：xxx。

生：xxx。
```

教师评价语言要具体积极，例如：

1. "你观察得很仔细。"
2. "你的想法很有道理，谁能补充一下？"
3. "这个错误很有价值，它提醒我们要注意……"
4. "你不仅说出了答案，还说清了理由。"
5. "这说明我们不能只看算式，还要回到情境里理解。"（数学学科保留"算式"原文；非数学学科可将"算式"替换为"表面"或其他学科贴切表述）

### 5.9 练习与作业设计

课堂练习应自然融入教学过程。课后作业应在作业布置环节中呈现，必须分层设计。

课后作业至少包括：

1. 基础题：巩固本课核心知识，面向全体学生。
2. 提高题：联系生活情境，强化应用。
3. 拓展题：具有开放性、探究性或创造性。

每类作业都要说明：

1. 题目内容。
2. 完成要求。
3. 预计完成时间。
4. 对应训练目标。

要求：

1. 作业语言符合学生年级特点。
2. 作业总量适中。
3. 作业必须对应教学目标和重难点。
4. 拓展题不能机械拔高，应体现开放表达、生活应用或探究发现。
5. 不得布置超出本课内容过多的题目。
6. **课内外分层必须递进衔接**：课内巩固练习的拓展题与课后作业的拓展题，难度必须有递进关系，不得同水平重复。课内拓展是课后拓展的脚手架——课内拓展侧重"在教师引导下尝试初步运用"（半扶半放），课后拓展侧重"独立完成、更大开放性、联系真实生活"（完全放手）。设计时要确保从课内到课外的拓展是逐层加深的，而不是同类任务的简单重复。

### 5.10 评价设计

评价设计是教案的必备组成部分，与教学目标一一对应，形成"目标—过程—评价"的闭环（UbD 逆向设计理念）。缺少评价设计的教案视为不合格教案。

评价设计至少包含两个层面：

（一）过程性评价

针对教学过程的每个核心环节，说明通过什么方式、观察什么行为、达到什么标准来判断学生当前的学习进展。要求：

1. 每个核心环节（新知探究、重难点突破、巩固练习）都要有对应的过程性评价方式。
2. **每个过程性评价节点必须配套至少一种具体的证据收集工具（P0 级硬约束）**，不得只写"教师巡视指导""观察学生正确率"这类空话。常用证据工具包括但不限于：
   - **观察记录表**：教师随堂记录关键行为、典型错误、参与度等（含记录维度和简单符号）。
   - **课堂检测单/任务单**：学生书面完成，教师可快速批阅或收集。
   - **量规卡/评价量表**：针对操作、表达、创作等任务的分级评价标准（含不同层级的具体描述）。
   - **自评表/互评表**：学生自我评估或同桌/小组互评的清单或等级表。
   - **手势反馈/拇指卡**：快速全员反馈工具（如拇指朝上/中/下表示理解程度）。
   - **错题收集卡**：学生记录自己的典型错误和订正。
2a. **核心评价工具必须有量规三要素（P1 级硬约束）**：如果评价工具已经设计了评价维度（如小组交流量规、任务单评价量规、结对互评价量表等），必须同时具备以下三要素，三者缺一不可，否则只是"检查清单"不是真正的量规：
   - **评价维度**：评哪几个方面（如发音、流利度、准确性）。
   - **等级描述**：每个维度分几个等级，每个等级的具体表现是什么（用描述性语言写出来，不是只给分数或星数）。等级用三级即可（合格/良好/优秀 或 基础/发展/拓展），每一级用一句话描述可观测的行为表现。例如：
     - 优秀（三星）：发音准确无误，语调自然。
     - 良好（二星）：有 1-2 处发音错误，但不影响理解。
     - 合格（一星）：多处发音错误，影响理解。
   - **评分标准**：各维度权重或总分换算方式（如三个维度各占三分之一，或核心维度权重更高）。
   等级描述是量规的灵魂——没有等级描述的维度只是评价项目清单。等级描述的作用：让评价者一看就知道"什么表现对应什么水平"，减少主观判断误差；同时让学生提前知道"做到什么程度算好"，起到目标导向作用。
2aa. **量规必须在课堂上"用起来"（P2 级硬约束）**：评价量规不能只是写在教案评价设计板块里的"说明文字"，必须设计**量规的实际使用环节**，让它在课堂教学中真实发挥评价导向作用。量规的使用至少体现在以下三个层面：
   - **任务前·亮出标准**：在学生开始表现性任务前（如结对对话、小组探究、写话创作、口语表达等），必须出示/发放量规，让学生明确"要从哪几个方面努力、做到什么程度算好"。不能等学生做完了才拿出量规评价。
   - **任务中·过程参照**：学生完成任务的过程中，量规作为自评/互评的工具被实际使用——学生对照量规检查自己的进度和质量、用统一标准评价同伴。教师在巡视指导时也用同一个量规做观察记录。
   - **任务后·反馈依据**：任务结束后的展示/交流环节，教师和学生对照量规进行评价反馈——优点说清是哪个维度的哪一级表现、改进建议说清指向哪个维度的哪个等级。不能量规是一套、口头评价是另一套。
   - 判断标准：检查教案中，如果设计了核心量规但在教学过程中找不到任何"学生使用量规"的具体环节（自评/互评/教师用其量规做记录），视为"量规没落地"，需要补充使用设计。
2b. **辅助评价工具也应有等级描述（P2 级硬约束）**：核心评价工具做细之后，观察记录表、练习评价、朗读评价、估算评价、游戏评价等**辅助评价工具**也应逐步补充等级描述，不能只有项目名称或一个达标线。辅助工具的等级描述不用像核心量规那么复杂，遵循"最简三级模板"即可：
   - **等级数**：2-3 级即可（达标/良好/优秀，或达标/待达标）。
   - **每级一句话**：每个等级用一句话描述可观测的行为表现，不用长篇大论。
   - 示例（观察记录表的"参与度"维度）：
     - 优秀：主动举手发言 3 次以上，积极参与小组讨论。
     - 良好：能举手发言 1-2 次，参与小组讨论。
     - 达标：在教师点名或同伴提醒下能参与。
   关键不是写多细，而是"有等级描述"——有了等级，评价就从"凭感觉"变成"看表现"，教师有了统一标尺，学生知道了努力方向。逐步实现所有评价工具的量规化。
2c. **评价工具精细化均衡原则（P2 级硬约束）**：一课之内的多个评价工具，精细化程度应基本均衡——不能核心环节用多维度加权量规、其他环节只有一句话等级描述，两者差距过大。**所有过程性评价工具（不止核心量规）至少应包含 2 个以上评价维度和对应的等级判断标准**。
   - **核心评价工具**（如对话表演量规、问题分类量规、简便计算量规等，对应本课最重要的教学目标）：必须有量规三要素（维度+等级描述+评分标准），维度 3-4 个，有加权评分。
   - **主要辅助工具**（如任务单评价、练习评价、探究记录评价等，对应重要的过程性目标）：至少有 2 个评价维度，每个维度有三级描述（优秀/良好/达标各一句话），可以不加权重但维度必须明确。
     - 示例（任务单评价）：
       - 维度一·正确率：优秀=全对，良好=错1-2题，达标=错3题以内
       - 维度二·完成速度：优秀=提前完成且进入拓展，良好=按时完成，达标=在帮助下完成
   - **一般辅助工具**（如观察记录表、游戏评价、拇指卡反馈等，对应课堂氛围和参与度）：至少有 2 个维度+简单等级描述，或单维度但有明确的行为判断标准（不能只有"好/不好"的主观判断）。
   - **均衡检查法**：设计完所有评价工具后，做一次整体检查——把所有工具的精细化程度排个队，最细的和最粗的之间差距不能超过一个层级（核心工具是"三维度加权量规"，其他工具至少要是"双维度+等级描述"，不能出现"一个是三维度量规，另一个只有一句话"的情况）。如果发现某个工具明显偏粗，就要补充维度和等级描述。
   - **辅助工具维度参考表（设计时直接选用）**：辅助工具常见维度拆解参考（2-3个维度即可，不用全列）：
     - 语文·朗读评价：正确性（读错字数）+ 流利度（停顿/回读次数）+ 感情表达（语气语调是否到位）
     - 语文·写话/小练笔评价：完整性（内容是否完整）+ 语言质量（好词好句/表达是否生动）+ 情感表达（是否有真情实感）
     - 语文·字词认读评价：准确度（读对字数）+ 流利度（反应速度）+ 运用（能否说一句话）
     - 数学·探究记录评价：正确率（结论是否正确）+ 过程完整性（步骤是否齐全）+ 思维清晰度（理由说不说得清）
     - 数学·练习评价：正确率 + 完成速度 + 方法多样性（是否有多种解法）
     - 英语·对话/表达评价：准确性（发音/语法错误数）+ 流利度（流畅程度）+ 交际性（是否有互动回应）
     - 英语·朗读评价：发音准确度 + 流利度 + 语调语感
     - 英语·词汇认读评价：准确度 + 反应速度 + 运用（能否放入句子）
     - 通用·课堂参与度观察：主动发言次数 + 小组参与程度 + 专注度
     - 通用·小组合作观察：参与度（是否每个人都发言）+ 合作性（是否倾听/互助）+ 产出质量（小组成果如何）
     - 通用·自评表：知识掌握度 + 参与度 + 进步感（觉得自己比之前好）
3. **学生主体性活动的过程性评价必须体现差异性（P0 级硬约束）**：
   - 针对不同层次的学生（与学情分析的"学生差异分层"对应），评价标准应有所不同。
   - 学困生的评价侧重"是否参与、是否达到基础要求、是否有进步"；中等生侧重"是否掌握核心内容、是否能独立完成"；学优生侧重"是否有创新、是否能迁移运用"。
   - 差异化评价要具体可操作，不得只写"分层评价"四个字。
4. 评价标准必须具体可观察（如"能正确说出 3 处变化""圈画正确率≥80%""小组全员参与对话"）。
5. 过程性评价服务于"及时调整教学"——哪里学生卡住了，就追问、补讲或放慢节奏。
6. **即时口头评价设计**：过程性评价不仅要有书面证据工具，还要有**即时口头评价**的设计。教师评价语不能只有"好""不错"这种空泛表扬，必须有层次、有针对性：
   - **针对学困生的评价**：侧重肯定参与、肯定进步、肯定具体努力（如"你能大胆站起来说，已经很棒了""你找到的这一处变化很准确"），评价语要具体、鼓励为主，帮助建立自信。
   - **针对中等生的评价**：侧重肯定正确性、引导再深入一步（如"你说得对，如果再说说理由就更好了""这个想法不错，还有没有其他角度？"），推动向更高水平发展。
   - **针对学优生的评价**：侧重肯定思维深度、引导创新和迁移（如"你这个发现很有价值，能不能推广到其他情况？""你的方法很独特，能不能解释一下你的思路？"），激发高阶思维。
   - **针对错误回答的评价**：先肯定思考价值，再引导辨析和纠正（如"这个想法很有代表性，我们一起来看看问题出在哪""你能想到这一点已经很不容易了，再仔细想想"），把错误转化为教学资源。
   - 评价语要避免空泛、避免等级标签（不说"你真棒""你真聪明"），要具体到学生的行为、方法或努力程度。

（二）终结性评价（当堂检测）

课的末尾必须设置一次当堂书面检测，用于判断本课目标是否真正达成。要求：

1. 检测任务必须是**学生独立书面完成**的（不能是口头齐答），确保能拿到每个学生的个体证据。
2. 检测内容必须直接对应本课教学目标（目标 1 对应检测题 1，目标 2 对应检测题 2……），一一映射。
3. 检测时长一般为 3-5 分钟，不超过 8 分钟，题目量少而精。
4. 必须给出**达标标准**（如"正确率≥80% 视为达标""能写出 3 句以上视为达标"），并说明达标率不达标的后续补救措施。
5. 检测结果的处理方式要明确（如同桌互批、教师快速抽批 5 份统计达标率、课代表收集下节课前置讲评等）。
6. **当堂检测可设置分层选做题**：基础题为必做，对应核心目标；拓展题为选做，供学优生挑战，指向高阶思维。达标标准以基础题为准。
7. **终结性检测必须与核心量规实现真实、全维度对接（P2 级硬约束）**：当堂检测的评价维度和评分标准，必须与本课**核心量规**的维度和等级保持一致，形成"过程性量规→终结性检测"的连贯评价链条，不能出现"过程量规评A/B/C三个维度，终结检测只看正确率一个维度"的脱节现象。
   - **真实对接原则**：维度对接必须是真正的能力维度对应，不能是形式主义的凑数标注。检测的是什么能力，就对应量规的什么维度。如果某个维度确实难以通过终结性检测衡量（如"参与度""合作态度"这类纯过程性维度），就诚实标注"本维度主要通过过程性评价衡量，终结性检测不覆盖"，**绝不**找一个不相关的维度硬凑上去（如用"完成速度"对应"参与度"）。
   - **全维度覆盖原则**：核心量规有几个维度，终结性检测就应该尽量覆盖几个维度，不能只测容易测的。难以通过常规书面检测完全衡量的维度，要用**替代题型**进行部分覆盖，哪怕只占少量分值也比完全缺失好。常见难测维度的替代方式：
     - 方法灵活性/策略多样性 → "用两种方法解答""写出你的思考过程"
     - 思维深度/推理能力 → "为什么？请说明理由""你发现了什么规律？"
     - 表达条理性/书面表达 → "把你的想法写清楚，让别人一看就懂"
     - 交际性/口语表达（英语） → 口头表达题、微型对话、情境问答
     - 联系生活/迁移应用 → 解决生活情境题、举生活中的例子
     - 创造性/开放性思维 → 开放性问题、创编题、设计题
   - 对接方式有两种：
     - **直接对接**：检测题直接测量量规的某个维度（如检测"理解深度"→量规"理解深度"）。
     - **替代对接**：用不同的题型/形式测量同一个能力维度（如书面说理题→量规"联系生活"维度）。
   - 判断标准：读完对接说明，让人觉得"对，这个题确实在测这个维度的能力"，而不是"这俩好像有点关系但又不太对得上"。两个真实对接的维度，胜过三个凑数的标注。
8. **最高权重维度效度校验规则（P2 级硬约束）**：设计终结性检测时，必须对核心量规的**最高权重维度**单独做一次"效度拷问"——这道题真的在测这个能力吗？还是在测别的更简单的能力？
   - **原则**：最高权重维度的检测题必须是该维度核心能力的**直接检测**，不能用低阶题型（记忆、背诵、机械模仿、简单回忆）替代或凑数。最高权重维度代表本课最核心的能力，如果检测的效度不够，整份检测就失去了主要意义。
   - **效度拷问三问**：设计完最高权重维度的对应题后，自问三个问题：
     1. 学生做这道题，调用的**主要能力**是什么？是不是这个维度要测的核心能力？
     2. 学生不用这个能力，靠更简单的能力（如记忆、蒙猜、照搬）能不能做出来？如果能，效度就不够。
     3. 这道题做得好的学生，是不是真的在这个维度上能力更强？还是只是记忆力好、做题熟练？
   - **反例（效度不足）**：
     - 量规维度是"信息提取能力"（40%），检测题却是"根据课文内容填空"——学生靠记忆回忆就能做，不需要回到文本中定位、筛选、提取。测的是记忆力，不是信息提取能力。
     - 量规维度是"思维深度"（40%），检测题却是"写出XX的定义"——学生靠背诵就能做，不需要深度思考。
   - **正例（效度充足）**：
     - 量规维度是"信息提取能力"，检测题是"读第X段，找出作者讨厌母鸡的三个理由，用原文中的话写出来"——学生必须回到文本中定位、筛选、提取，真实测信息提取能力。
     - 量规维度是"方法灵活性"，检测题是"用两种方法解答下面这道题，并说说你更喜欢哪种方法"——学生必须调用不同的方法并做比较，真实测方法灵活性。
   - **修正方法**：如果最高权重维度的检测效度不足，改成让学生必须调用该维度核心能力的题型。阅读课的信息提取题就应该"给文本+任务→从文本中找答案"，而不是"靠回忆填答案"。

（三）评价数据的汇总与反馈

各环节收集的评价数据不能是零散的、用完就扔的，必须有汇总和反馈机制，形成"收集—汇总—反馈—改进"的闭环。要求：

1. **数据汇总方式**：课后要将各环节的评价数据（观察记录、任务单完成情况、练习纸正确率、当堂检测结果等）进行汇总整理，形成对每个学生学习情况的整体判断。可以用简单的等级记录（如达标/待达标/需关注），也可以用关键行为清单的方式。
2. **反馈给学生的方式**：评价结果要及时反馈给学生，不能只有教师自己知道。反馈方式可以是：当堂口头反馈整体情况、下节课发回练习纸并针对性点评、个别学生课后单独沟通等。反馈要具体，不能只给分数或等级，要告诉学生"哪里做得好、哪里需要改进、怎么改进"。
3. **反馈给教学的方式**：评价数据要服务于教学改进——如果某个目标达标率低，下节课就要调整补救；如果某个环节学生普遍有困难，就要反思教学设计是否合理。评价数据是教学反思的重要依据，应与教学反思预设形成呼应。

### 5.11 板书设计

板书设计要简洁、清晰、有结构。

要求：

1. 体现本课知识主线。
2. 突出核心概念、关键方法和易错提醒。
3. 支撑学生课后回顾。
4. 可使用文字、箭头、表格、算式、图示等形式。
5. 不要过于繁杂。
6. 板书必须与教学过程呼应。
7. 严禁使用代码块包裹内容

### 5.12 教学反思预设

教学反思预设不是课后写的教学反思，而是备课时对"上完这节课后我要反思什么"的提前预设。体现教师的元认知意识和专业自觉。

教学反思预设至少包括以下三个维度：

1. **目标达成反思**：
   - 预设的教学目标是否达成？从哪些证据可以判断？
   - 如果未达成，可能的原因是什么？（是目标定高了、活动设计有问题、还是时间不够？）
   - 下节课可以如何调整补救？

2. **学生学习反思**：
   - 学生可能会在哪些地方遇到困难？这些困难是否在预设之中？
   - 哪些生成性的问题可能出现？如何应对？
   - 差异化设计是否真正照顾到了不同层次的学生？

3. **教学改进方向**：
   - 本节课的设计中，哪些环节可能需要再优化？（如导入是否够吸引人、探究时间是否充足、练习是否有层次等）
   - 如果再上这节课，你会在哪些地方做出调整？为什么？

要求：

- 教学反思预设必须具体到本课内容，不能写成通用的套话。
- 反思要有针对性，体现对教学的深度思考，而不是走过场。
- 反思预设可以结合学情分析中的预测困难来写。

### 5.13 输出前质量自检

正式输出前，必须在内部完成质量自检并自动修正，但不要输出自检表。

**有模版时，第 71–76 项（版式结构校验）与本清单内容项并行执行，且结论以结构校验为准**——当内容项要求改动结构（新增模块、改写表格、调整顺序）时，一律不改结构，改用不破坏版式的表达方式满足内容要求；完整校验口径见 `template-fidelity.md` §5 八查。

重点检查：

1. 是否基于用户提供的教材章节名称和教师用书内容。
2. 是否符合学段、年级、教材版本和课时安排。
3. 是否体现义务教育课程标准（2022 年版）理念。
4. 是否准确提炼学科核心素养。
5. 教学目标是否具体、可观察、可评价。
6. 教学重难点是否准确，并有突破策略。
7. 教学过程是否围绕清晰主线展开。
8. 导入、新授、练习、总结、作业是否完整。
9. 每个教学环节是否有教学意图和师生活动。
10. 师生对话是否真实、儿童化、符合年级特点。
11. 是否有操作活动、合作交流、比较辨析和生成性回答。
12. 是否有学生易错回答和教师纠偏过程。
13. 学情分析中的误区是否在教学过程中得到回应。
14. 是否避免教师直接灌输结论。
15. 是否避免内容超纲、偏难或不符合学生认知水平。
16. 作业是否分层且与目标一致。
17. 板书是否与教学过程呼应。
18. 学科表达是否准确；评价设计是否完整（含过程性评价与当堂终结性检测，且与教学目标一一对应，形成闭环）。
19. 公式书写是否规范（必须再次核对是否符合最高优先级公式规则：行内单 `$`，块级双 `$$`，严禁出现 `\(`、`\)`、`\[`、`\]`，严禁使用普通括号 `()` 包裹公式，严禁多重转义）。具体规则见 `math-spec.md` 第 1 节。**并按 SKILL.md 核心约束第 0.1 条，全文严禁出现 `$` / `$$` 定界符，公式改用反引号包裹的 LaTeX 源码或纯文本 / Unicode 书写。**
20. 各环节时间总和是否等于课时长度。
21. 最终输出格式是否完全符合要求（见 `output-format.md`）。
22. 板书设计及教案任何模块是否被代码块包裹（严禁出现 ```）。
23. **教学目标是否全部以可观测行为动词收尾**：逐条检查，不得出现"发展/培养/体会/形成/理解/掌握"等内部动词作为目标落点（P1 级）。
24. **学生主体性核心环节是否有差异化任务设计**：每个适配差异化的核心环节（时长≥8-10 分钟、以学生自主活动为主），是否在任务分层/支架分层/节奏分层/练习分层/评价分层上至少有两项不同；拓展性任务是否指向高阶思维而非加量（P0 级）。
25. **过程性评价是否有证据工具且体现差异性**：每个过程性评价节点是否配套至少一种具体证据收集工具（观察记录表/检测单/量规卡/自评表等）；学生主体性活动的评价是否体现分层差异（P0 级）。
26. **核心方法是否显性总结**：若核心环节用到了明确的学习方法/思维方法/学科思想方法，总结提升环节是否包含该方法的显性提炼（有名称、有步骤、有迁移场景）（P1 级）。
27. **素养/德育落点是否显性标注**：课标分析中列出的每个核心素养/德育目标，是否在至少两个教学环节中找到显性标注的对应落点和具体活动；环节设计意图中是否写清"通过什么活动+发展什么素养的哪个具体方面"，而非贴标签式空喊（P2 级）。
28. **目标六要素是否完整**：每条目标是否覆盖行为主体、行为动词、行为条件、行为程度、核心素养支撑、落地环节与评价方式六要素；教案中是否未出现素养支撑强弱等级之类的标注（P1 级）。
29. **学情差异是否渗透到多维度设计**：学情分析是否不仅回应易错点，还渗透到任务分层/支架分层/节奏分层/练习分层/评价分层中至少两个维度（P1 级）。
30. **支架是否标注撤除时机**：给学困生的支架是否明确了撤除条件和方式，不能让支架变成永久依赖（P1 级）。
31. **拓展层任务是否指向高阶思维**：拓展性任务是否体现分析/评价/创造层级，而非简单加量（多做几道、多写几句）（P0 级）。
32. **即时口头评价是否有层次性**：教师评价语是否针对不同层次学生有不同策略（学困生重鼓励、中等生促深入、学优生激创新、错误重价值），避免空泛表扬（P2 级）。
33. **素养/德育融合是否自然**：是否做到"从知识本身长出价值观/素养"，有无生硬贴标签现象；是否符合"三不原则"（不生硬、不占用主课时、不脱离学科知识点）（P2 级）。
34. **教学准备板块是否完整**：是否包含教具准备、学具准备、课前准备工作，且与教学过程活动对应。
35. **教学反思预设是否具体**：是否包含目标达成反思/学生学习反思/教学改进方向三个维度，且具体到本课内容而非套话。
36. **环节是否按四要素结构化呈现**：每个教学环节是否完整包含教师活动、学生活动、设计意图、评价要点四要素（P2 级）。
37. **核心环节是否有节奏分层设计**：学生主体性核心环节是否设计了节奏分层——即是否明确了学优生提前完成后的过渡任务（弹性任务池/拓展预备区）和学困生进度滞后的应对机制（额外支架/延时/伙伴帮扶），不能只有任务分层没有进度安排（P1 级）。
38. **核心评价工具是否有量规三要素**：至少有一个核心评价工具（如小组交流量规、任务单评价量规、结对互评价量表等）是否同时具备"评价维度+等级描述+评分标准"三要素，每个维度下有具体的行为描述而不只是维度名称或星数（P1 级）。
39. **方法显性总结后是否有当堂迁移验证**：若总结提升环节有显性方法提炼（有名称、有步骤），是否在方法总结后紧跟一个1-3分钟的当堂迁移验证小任务，让学生当场运用刚学到的方法解决新问题（P1 级）。
40. **目标中内部动词是否紧跟外显行为描述**：目标中如果出现"体会/感受/理解"等内部动词，是否在同句内紧跟可观测的外化行为描述作为收尾，不得让内部动词单独结尾或只有内部动词没有外显证据（P1 级）。
41. **课内外分层是否递进衔接**：课内拓展题与课后拓展题难度是否有递进关系（课内半扶半放、课后完全放手），是否存在同水平重复的情况（P2 级）。
42. **信息化资源是否有备用方案**：凡涉及动画、视频、音频等信息化资源的，是否明确写出了技术故障时的替代方案，确保课堂不因设备问题中断。
43. **评价数据是否有汇总与反馈机制**：各环节的评价数据是否有汇总整理方式和反馈给学生的方式，评价结果是否服务于教学改进，而不是零散用完即弃（P2 级）。
44. **分层设计是否通过三要素动态平衡检验**：分层设计是否不仅有形式（任务/支架/节奏/练习/评价），还与学情、内容方法、学科特性三要素动态平衡——梯度疏密合适、分层方式符合课型特点、能力指向符合学科核心能力（P1 级）。

45. **活动-材料联结度是否到位**：教学准备中的主要资源（教具/学具/信息化资源）是否都在教学过程中有具体的使用描写，能看到"教师引导→学生操作→产出反馈"的链条，而非只写"出示XX"一笔带过（P2 级）。
46. **辅助评价工具是否有等级描述**：除核心量规外，辅助评价工具（观察记录表、练习评价、朗读评价等）是否也有简单的等级描述（至少2-3级，每级一句话），而不只是一个达标线（P2 级）。
47. **素养表述是否准确自然**：文化自信/德育类素养表述是否与文本内容自然联结、准确对应，有无牵强附会、硬贴标签的现象——宁少勿滥，宁浅勿假（P2 级）。
48. **课时容量与单元定位是否准确**：一课时核心知识点/方法点是否不超过2个、核心环节时长占比是否充足、是否明确本课在单元中的进阶位置且与前后课不重复（P1 级）。
49. **支架撤除是否有三级梯度**：支架撤除是否设计了"全扶→半扶→全放"三级台阶，每级有明确的支架形式和适用阶段，而非从完整支持直接跳到完全自主（P1 级）。
50. **活动-材料一致性是否通过检查**：教学准备中列出的所有主要材料是否都在教学过程中有明确使用场景（无"备而不用"项），是否做了一致性检查并删除了用不上的材料（P2 级）。
51. **评价工具精细化是否均衡**：所有过程性评价工具是否都至少有2个评价维度+对应等级描述，核心工具与辅助工具的精细化程度差距不超过一个层级（P2 级）。
52. **英语词汇教学是否分批呈现+滚动复现**：英语课新词≥5个时是否分2-3批逐步呈现而非一次性抛出；后续操练和巩固环节是否滚动复现已学旧词，避免学新丢旧（P2 级，英语学科）。
53. **量规是否在课堂上真实使用**：核心量规是否不仅写在评价设计里，还在教学过程中有明确的使用环节——任务前出示标准、任务中学生自评/互评、任务后对照量规反馈（P2 级）。
54. **终结性检测是否对接核心量规维度**：当堂检测的评价维度和评分标准是否与本课核心量规的维度/等级保持一致，形成"过程量规→终结检测"的连贯链条，而非各说各话（P2 级）。
55. **生活应用/拓展环节是否有材料支撑**：生活应用类、拓展性任务是否有具体的材料/工具/情境载体（任务单、记录表、调查表、测量工具等），而非只有任务描述没有落地抓手（P2 级）。
56. **辅助评价工具是否有明确维度拆解**：所有辅助评价工具（朗读评价、写话评价、练习评价等）是否至少拆解为2个评价维度（参考维度表），而非只有笼统的"好不好"（P2 级）。
57. **易忽略资源是否通过材料一致性专项检查**：音频、视频、图片素材、卡片道具等易被忽略的资源，是否每一个都在教学过程中有明确的使用环节和操作方式，无"备而没写怎么用"的情况（P2 级）。
58. **多篇目课型是否采用迁移式结构**：一课时包含两首/两篇/两组/两道以上相似内容时，是否采用"第一例教方法→提炼方法→第二例用方法自主学"的由扶到放结构，而非两首/两篇并列重复教学（P1 级）。
59. **终结性检测维度对接是否真实全面**：终结性检测与核心量规的维度对接是否真实可信（无凑数标注、无牵强对应）；核心量规有N个维度，检测是否至少覆盖N-1个维度，难测维度是否有替代题型（P2 级）。
60. **多方法提炼是否有权重区分**：当一课提炼多个方法时，是否区分了核心思想方法与具体技能方法；核心方法是否在新知环节就有渗透且描述篇幅不少于技能方法（P2 级）。
61. **英语词汇分批是否有明确教学逻辑依据**：英语课词汇分批呈现时，每一批的分组是否有明确的教学逻辑（发音规律/词形结构/难易度/语义类别/语法属性），并在设计意图中说明，而非随机分组（P2 级，英语学科）。
62. **生成前设问信息是否落地**：生成前4问中老师回答了的内容，是否都在教案中找到了对应落点（课型方向→教学主线、学情卡点→突破环节、上课主线→环节顺序、评价方式→检测工具），没有"问了白问"的情况（P1 级）。
63. **核心方法提炼时机是否前置或中置**：如果方法是本课核心目标之一，方法名称和步骤的首次出现是否在核心探究环节之前或之中（前置/中置），而非只在总结环节才出现（纯后置）（P2 级）。
64. **最高权重维度检测是否通过效度校验**：核心量规最高权重维度对应的终结检测题，是否真实检测该维度的核心能力，而非用记忆、背诵等低阶题型替代；学生做这道题必须调用该维度的核心能力才能完成（P2 级）。
65. **承上启下设疑是否有双重功能**：两课时以上的课文，前一课时末尾的设疑是否同时具备"钩子（激兴趣）+梯子（练思维）"双重功能——不仅激发好奇心，还引导学生基于已学内容做推理预测，而非纯悬念式吊胃口（P2 级）。
66. **教学内容 / 课标分析 / 教学目标三模块是否串写**：教材位置是否只出现在「教学内容」；课标条文与素养分析是否只出现在「课标分析」；可观测行为目标是否只出现在「教学目标」；三模块句式是否混用；同一信息是否在两个模块重复出现（P0 级）。
67. **教学目标是否按素养维度分条**：是否用"一、二、三、四"逐条列出，一条对应一个素养维度（3-4 条，不超过 5 条），是否未把多维度混在一条里、未另设知识技能/过程方法二级分类（P0 级）。
68. **学情分析是否为单段**：输出的「学情分析」是否只有一段（不超过 300 字），未分点、未设（一）（二）（三）小标题、未展开差异分层与支架设计（P0 级）。
69. **学情分析是否按学情参数双线写作**：入参 `学生学情` 有值时，该段是否逐项填充了传入内容、点名的卡点 / 易错点 / 薄弱处是否原样出现、是否未被笼统套话覆盖或稀释、且在教学重难点与教学过程有对应回应；无值时是否按一般情况推断写成常规学情（P0 级）。
70. **是否出现删除线**：最终 Markdown 全文是否未出现 `~~文本~~` 删除线语法、也未出现任何会被渲染为删除线的写法（P0 级）。
71. **版式骨架是否逐字复刻**：入参模版／参考教案有效时，成品的模块名称（含标点括号）、模块数量、先后顺序、层级与编号样式，是否与骨架表逐项一致，有无被默认十模块名替换或"顺手规范化"（P0 级）。
72. **是否新增了模版以外的模块**：成品中有无出现骨架表之外的模块标题（尤其是"评价设计""板书设计""教学反思预设""教学准备"等默认模块名）；模版缺失的内容是否已就近并入已有模块而非另起标题（P0 级）。
73. **表格版式是否被破坏**：骨架标为表格的模块是否仍为表格；表头文字、列数、列顺序是否与模版一致；有无增删列、有无被改写成标题段落；单元格内容是否按列语义填写（P0 级）。
74. **开头基本信息表是否齐全**：模版的表头字段区（课题／年级／学科／册别／课时／课型／教师／时间等）是否全部保留并填写；无值字段是否留占位而非删除或编造（P0 级）。
75. **结构残留是否齐全**：模版的留白符、填写说明（如"（课后填写）""（可另附页）"）、页眉页脚落款是否保留；"（课后填写）"类模块是否写入了反思预设要点而非留空（P1 级）。
