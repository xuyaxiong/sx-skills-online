# 多学科适配指南（Subject Guides）

> 本文件使 skill 可跨学科复用。生成教案前，先按学科路由确定要加载的参考文件；学科核心素养、主要课型与教学设计注意点以本文件为准。任何学科凡涉及符号、公式、变量表达式、单位、上下标、算式时，均须加载 `math-spec.md`。

| 学科 | 必读参考文件 | 说明 |

## 2. 语文（2022 版课标）

### 核心素养
文化自信、语言运用、思维能力、审美创造。

### 主要课型与设计注意点

| 课型 | 教学设计要点 |
|------|-------------|
| 识字写字 | 关注音、形、义的结合；采用字理识字、情境识字、归类识字等方法；写字指导要范写、描红、临写分层落实；注重书写习惯与姿势 |
| 阅读 | 主线设计：初读感知 → 精读品悟 → 朗读表达 → 迁移运用；关键问题要有思考价值；朗读指导（正确、流利、有感情）贯穿始终 |
| 习作/写话 | 从生活素材出发；先说后写、由扶到放；提供支架（提纲、好词好句、范文片段）；当堂评改与展示 |
| 口语交际 | 创设真实交际情境；明确交际目标（倾听、表达、应对）；示范 + 练习 + 评价反馈 |
| 综合性学习 | 围绕主题开展活动；突出合作、探究、成果展示 |

### 注意点
1. 学情语言：低年级口语化、儿童化；中高年级可增加概括与表达要求。
2. 朗读、默读、浏览等阅读方法要根据学段确定。
3. 板书设计可体现生字、词句、文章结构（如思维导图式）。
4. 课时目标要围绕"识字与写字""阅读与鉴赏""表达与交流""梳理与探究"四个实践领域组织。
5. **文化自信必须从文本自然生长，禁止贴标签**：文化自信的培养不能从外部硬加，必须从课文的语言文字、内容主题、表达特点中自然挖掘。例如写景散文的文化自信应从"感受祖国山河之美""体会传统审美意象"中自然生长，而不是空喊"培养文化自信"。
6. **审美创造要有具体活动支撑**：不能只说"培养审美创造"，必须有具体的审美活动（如品味语言之美、感受意境之美、欣赏表达之美等）。

## 3. 英语（2022 版课标）

### 核心素养
语言能力、文化意识、思维品质、学习能力。

### 主要课型与设计注意点

| 课型 | 教学设计要点 |
|------|-------------|
| 词汇课 | 在语境中呈现与学习词汇，避免孤立背单词；词不离句、句不离境；游戏与活动巩固 |
| 对话课 | 主线设计：情境导入 → 呈现对话 → 操练（机械-意义-交际）→ 输出运用；重视听说先行 |
| 阅读课 | Pre-reading → While-reading → Post-reading 三阶段；任务驱动；读后活动联系生活 |
| 语音课 | 感知-模仿-归纳-运用的流程；结合 Phonics；多听多模仿 |
| 写作课 | 范文引路 → 结构分析 → 仿写 → 自由写；评价标准清晰 |

### 注意点
1. 学生语言以目标语为主，指令语可适度使用母语辅助。
2. 小学英语课堂要保证学生开口率，活动设计要全员参与。
3. 文化意识渗透要自然，避免生硬说教。
4. 板书设计常用词块、句型框架、思维导图形式；教案正文中出现的英语例句直接用正体书写，不需要公式包裹。
5. **思维品质要有足够活动支撑**：不能只关注语言知识，必须设计足够的思维活动（观察比较、归纳推理、分析评价、创造表达等），让学生在学语言的同时发展思维。思维品质要在多个环节中有显性体现，不能只有一处。
6. **学习策略要显性提炼**：英语学科的学习策略（对比观察法、归纳法、联想记忆法、构词法等）要有意识地显性总结，做到"有名称、有步骤、有迁移"。
7. **词汇教学分批呈现+滚动复现原则（P2 级硬约束）**：
   - **分批呈现**：一课时内新词汇数量较多时（≥5个），不能一次性全部呈现，要分2-3批逐步呈现。每批呈现2-3个词，学完一批练一批、练会一批再进下一批，避免学生认知过载。
   - **分批必须有明确的教学逻辑依据**：词汇分组不能是随机的、为分批而分批的，每一批的词汇之间要有教学逻辑上的关联，让"分组"本身也成为学习资源。常见的分组依据：
     - **发音规律**：按相同的元音/辅音组合分组（如含 /e/ 音的词一批、含 /əʊ/ 音的词一批），让学生在同一批中感知相同的发音模式。
     - **词形结构**：按相同的前缀、后缀或词根分组（如 -er 结尾的一批、-ing 形式一批），帮助学生感知构词规律。
     - **难易度梯度**：先易后难（先学短词、常用词，再学长词、生僻词），建立学习信心。
     - **语义类别**：同类词汇放在一组（如衣物类一批、食物类一批），形成词汇语义网络。
     - **语法属性**：按语法特点分组（如单数名词一批、复数名词一批；及物动词一批、不及物动词一批）。
     分批依据必须在设计意图中明确说明。
   - **滚动复现**：每学一批新词，都要在后续环节中滚动复现之前学过的旧词（包括本课之前批次的词和之前课时学过的相关词），不能学了新的就丢了旧的。复现方式包括：闪卡快速认读、替换练习中嵌入旧词、对话创编中鼓励使用已学词、游戏中混合新旧词等。
   - **分批+滚动的组合节奏**（以8个新词为例）：第一批呈现3个→跟读操练→快速巩固；第二批呈现3个→跟读操练→混合前3个滚动复现；第三批呈现2个→跟读操练→混合全部滚动复现。每一批之间不超过5分钟就要有一次复现接触。
   - 判断标准：检查新授环节，如果一课时新词超过5个且一次性全部呈现，视为不合格；检查后续操练和巩固环节，如果只有新词操练没有旧词复现，视为不合格；词汇分批但分组依据不明确的，视为"为分批而分批"，需优化。

## 4. 科学（2022 版课标）

### 核心素养
科学观念、科学思维、探究实践、态度责任。

### 主要课型与设计注意点

| 课型 | 教学设计要点 |
|------|-------------|
| 实验探究课 | 主线：提出问题 → 作出假设 → 制定计划 → 实验验证 → 得出结论 → 表达交流；强调控制变量 |
| 观察课 | 明确观察目的与顺序；多种感官 + 工具观察；记录（画图、表格、文字）；描述交流 |
| 工程设计课 | 明确任务 → 设计 → 制作 → 测试 → 改进；强调迭代与团队协作 |
| 科学阅读课 | 资料搜集、信息提取、科学史渗透 |

### 注意点
1. 实验安全第一：涉及器材、材料、药品的实验，教案中须写明安全注意事项。
2. 预测与实证并重，鼓励学生用证据说话。
3. 探究活动要给学生充分的时间和空间，避免教师包办。
4. 板书设计可体现"问题—猜想—证据—结论"的探究结构。

## 5. 道德与法治（2022 版课标）

### 核心素养
政治认同、道德修养、法治观念、健全人格、责任意识。

### 设计注意点
1. 以学生生活为基础，创设真实生活情境，避免空洞说教。
2. 课型以主题学习为主：生活导入 → 情境体验 → 辨析讨论 → 行为引导 → 实践延伸。
3. 价值引领要自然渗透，学生主体参与，让学生自己得出价值判断。
4. 可融入班队活动、社会实践活动等资源。
5. 板书设计简洁，体现道理、方法或行为要求。

## 6. 音乐 / 美术（2022 版课标）

### 核心素养
审美感知、艺术表现、创意实践、文化理解。

### 设计注意点
1. 音乐：以聆听、演唱、演奏、律动、创编等实践活动为主线；重视音乐要素感知。
2. 美术：欣赏 → 表现 → 创造 → 联系生活；强调动手实践与个性表达。
3. 评价以鼓励与展示为主，注重过程性表现。

## 7. 新增学科扩展指南

当用户需要本表未收录的学科教案时：

1. 先向用户确认该学科义务教育课程标准（2022 年版）的学科核心素养表述。
2. 询问该学科典型课型（如历史：史料研读课；地理：区域认知课等）。
3. 将确认后的核心素养与课型要点补入本文件对应学科段落（或新建 `references/<subject>-spec.md`）。
4. 补入后按常规流程生成教案。

## 8. 学科通用要点（所有学科）

1. 核心素养分析必须与本课内容真实关联，不得空泛罗列。
2. 学生语言、活动方式、思维深度必须与年级匹配。
3. 教学目标 3 条句式、重难点突破策略格式、教学过程六环节、作业三层四要素等通用规范（见 `core-design.md` 第 5 节）对所有学科同等适用，仅将学科内容对应替换。
4. 学科术语表述要准确（如语文"语文要素"、英语"语篇"、科学"探究实践"等），不得混用。
