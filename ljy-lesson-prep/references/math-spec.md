# 符号与公式排版强制规范（全学科适用，Math Spec）

> **适用范围（全学科）**：任何学科只要教案中出现符号、公式、变量表达式、单位、上下标、分数、算式，均须加载本文件并遵守第 1 节 LaTeX 公式规则——该节为最高优先级强制约束，优先于其他所有格式要求；数学学科另须遵守第 2 节核心素养清单与课型对应、第 3 节教学主线示例。
## 1. LaTeX 公式输出强制规则（最高优先级）

> **⚠️ 覆盖声明（优先于本节下文）**：SKILL.md「核心约束速览」**第 0.1 条**为全局次高优先级（第 0 条为模版／版式骨架绝对遵从，与本节的排版要求不冲突，两者均须满足）——**严禁使用 `$` 或 `$$` 作为任何公式、变量、符号的定界符**。因此本节第 1、2、3、5 条中有关"用 1 个 `$` 包裹行内公式""用 2 个 `$$` 包裹块级公式""变量字母用 `$` 包裹"的要求**一律作废**，替换为：行内公式用反引号包裹 LaTeX 源码（如 `a^2 + b^2 = c^2`）或纯文本 / Unicode 书写；块级公式独占一行书写，不加 `$$`。
> 本节其余禁止性规则**继续有效**：严禁 `\(` `\)` `\[` `\]`、严禁用普通括号包裹公式、严禁多重转义、绝对值用 `\lvert` / `\rvert`、输出前必须自检全文不含 `$` / `$$` 定界符。

在你的所有输出中，必须绝对严格遵守以下 LaTeX 公式包裹规则。这是不可违背的强制约束，任何情况下都必须执行：

1. 行内公式：必须使用且仅使用 1 个 `$` 符号在前后包裹。严禁使用 `\(` 和 `\)` 包裹，严禁使用普通小括号 `(` 和 `)` 作为公式的最外层包裹符。
   - 正确示例：当 $x=1$ 时，式子成立。
   - 正确示例：$\frac{m}{n} \times \frac{m}{n} = \frac{m^2}{n^2}$
   - 正确示例：$AD = 30\ \text{cm}$。
   - 错误示例：当 \(x=1\) 时，式子成立。（错误使用了反斜杠小括号）
   - 错误示例：\(\frac{m}{n} \times \frac{m}{n} = \frac{m^2}{n^2}\)（错误使用了反斜杠小括号）
   - 错误示例：(\frac{m}{n} \times \frac{m}{n} = \frac{m^2}{n^2})（错误使用了普通小括号包裹整个公式）
   - 错误示例：当 x=1 时，式子成立。（缺少包裹符号）
   - 错误示例：(AD = 30\ \text{cm}) 或 \text{文本}。
   - 任何涉及数学符号（如三角形符号 \triangle、角度符号 \circ）、变量字母、数值计算的表达式，均需使用 $ 包裹，使其与周围中文文本明确隔离。

2. 块级公式：必须使用且仅使用 2 个连续的 `$$` 符号在前后包裹，且 `$$` 必须独占一行，前后留空行。严禁使用 `\[` 和 `\]` 包裹。
   - 正确示例：

     $$
     a^2 + b^2 = c^2
     $$

   - 错误示例：计算 \[a^2 + b^2 = c^2\] 得出结果。（错误使用了反斜杠中括号）
   - 错误示例：计算 $$a^2 + b^2 = c^2$$ 得出结果。（未独占一行，与文字混排）
   - 错误示例：$a^2 + b^2 = c^2$（错误将块级公式用于单美元符号）

3. 包含环境的多行公式（如 `cases`、`aligned`、`matrix` 等）必须作为块级公式，严格使用 `$$` 包裹并独占整行。内部换行符必须使用单反斜杠对 `\\`，严禁多重转义（如禁止输出 `\\\\`），严禁使用小括号或其他符号包裹公式。
   - 正确示例：

     $$
     \begin{cases} y = x + 2 \\ x + y = 12 \end{cases}
     $$

   - 错误示例：`(\\\\begin{cases} y = x + 2 \\\\ x + y = 12 \\\\end{cases})`（严重错误：未使用包裹符、括号包裹、多重转义）

4. 严禁缺少包裹标记、标记数量错误、行内与块级包裹格式混用。每次生成完整教案前，必须内部强制自检所有公式是否符合上述规则，确保全文不出现 `\(`、`\)`、`\[`、`\]` 符号。

5. 变量字母强制包裹：凡是在句中出现的表示物理量、几何点、线段的单字母或字母组合（如 AD、E、x），必须使用 $ 包裹为斜体数学变量（即写成 $AD$、$E$、$x$）。严禁使用中文括号包裹变量（如 (AD)），严禁将变量直接写成正体文本。

6. 公式内所有绝对值竖线统一替换为标准 LaTeX 命令：左竖线使用\lvert，右竖线使用\rvert，禁止使用原生裸写 | 竖线，规避表格分隔符冲突。

7. 仅表格分隔线可使用裸 | 竖线，表格单元格数学内容统一使用 \lvert、\rvert，单元格内禁止裸写绝对值竖线。

8. **初高中数学适用范围**：若课题涉及初中或高中数学，可参照本规范执行，但需要相应调整学生语言、思维水平、知识深度和教学活动方式。

9. 输出的md文档下划线，强制使用反引号包裹，比如：`______`

10. 但如果是公式内的下划线需使用标准的形式\underline{\quad}进行替换

## 2. 数学核心素养与课型对应

结合义务教育数学课程标准（2022 年版）的理念，分析本课主要落实哪些数学核心素养。

小学数学常见核心素养：

1. 数感
2. 量感
3. 符号意识
4. 运算能力
5. 几何直观
6. 空间观念
7. 推理意识
8. 数据意识
9. 模型意识
10. 应用意识
11. 创新意识

要求：

1. 不要空泛罗列核心素养。
2. 必须说明核心素养与本课内容之间的真实关系。
3. 核心素养必须落实到具体教学活动中。
4. 不要在教案中生硬堆砌课标原文。
5. 课标分析应体现"为什么这样教"，而不仅是"教什么"。
6. **应用意识必须有深度，不能浅尝辄止**：涉及应用意识时，不能只停留在"做几道生活应用题"的浅层面，必须让学生真正体会数学是刻画现实世界的模型。要体现完整的建模路径：从现实情境中抽象出数学问题 → 用数学方法解决 → 回到现实中检验和解释。生活情境要真实、有意义，不能是虚假的"应用题"。
7. **数学思想方法必须显性提炼**：凡是课中用到了典型的数学思想方法（如分类思想、集合思想、数形结合思想、转化思想、模型思想、对应思想等），总结提升环节必须显性提炼（有名称、有步骤、有迁移场景）。

不同课型可重点关注：

1. 代数启蒙类，如"用字母表示数""认识方程"：重点关注符号意识、抽象意识、模型意识、推理意识、应用意识。
2. 数与运算类：重点关注数感、运算能力、推理意识、应用意识。
3. 图形与几何类：重点关注几何直观、空间观念、量感、推理意识。
4. 统计与概率类：重点关注数据意识、模型意识、推理意识、应用意识。
5. 综合实践类：重点关注应用意识、创新意识、模型意识和合作交流能力。

## 3. 数学教学主线示例

如果课题为"用字母表示数"，教学主线可为：

为什么需要用字母表示数 → 字母可以表示不确定的数 → 含有字母的式子可以表示数量关系 → 含字母式子的书写有规范 → 代入具体数可以求值 → 用字母表达生活中的规律。

如果课题为"认识乘法"，教学主线可为：

相同数量重复出现 → 连加表达 → 连加不够简便 → 创造简便表示 → 认识乘法 → 理解几个几 → 应用乘法模型。

如果课题为"长方形和正方形的面积"，教学主线可为：

面积比较需求 → 单位面积铺摆 → 观察长宽与面积关系 → 归纳公式 → 应用公式解决问题。
