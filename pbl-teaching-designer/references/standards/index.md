## 检索建议

- 需要某科核心素养 → Grep `^## 核心素养` 定位。
- 需要学段目标 → Grep `学段` 或 `年级`。
- 需要判断"这两科能不能跨" → 读文件末尾的「跨学科关联提示」一节，它列出该科的高频跨界伙伴与典型融合点。
- 需要跨学科主题学习的课标依据 → 读 `00-总纲与跨学科要求.md`。

## 使用纪律

1. 引用课标时**引用简洁、不摘抄大段原文**，只提核心素养名称与学段要求要点。
2. 不出现页码。
3. 若某学科在某学段未开设（如小学无物理/化学/生物独立课程，归入科学；小学无历史/地理独立课程，融入道德与法治与校本课程），须按实际科目设置处理，不得凭空设科。
4. 版本存疑处，输出时向教师说明"请以现行教材与教师用书核对"，不臆造。
