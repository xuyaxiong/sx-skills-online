# 历史课程标准要点

## 核心素养

**义务段（初中，五项）与高中段（五项）一致**：唯物史观、时空观念、史料实证、历史解释、家国情怀。

- **唯物史观**：认识人类历史发展的客观规律，理解生产力与生产关系、经济基础与上层建筑。
- **时空观念**：在特定时间联系和空间联系中对事物进行观察、分析的意识与思维方式。
- **史料实证**：搜集、辨析、运用可信史料，努力重现历史真实的态度与方法。
- **历史解释**：以史料为依据，客观地认识和评判历史的态度与方法。
- **家国情怀**：对国家的高度认同感、归属感、责任感和使命感（义务段表述为"涵养家国情怀"）。

## 学段设置

- **义务教育阶段历史为初中课程（7–9 年级）**，小学不开设独立历史课，相关内容融入道德与法治与校本课程。
- 初中按**通史**体例：中国古代史 → 中国近代史 → 中国现代史 → 世界古代史 → 世界近代史 → 世界现代史。
- 高中：《中外历史纲要》（必修）+ 选择性必修（国家制度与社会治理、经济与社会生活、文化交流与传播）+ 选修。

## 2025 修订版关键变化（设计时必须对齐）

1. 课程性质新增"**坚定历史自信**"，"培养家国情怀"改为"**涵养**家国情怀"。
2. 课程目标新增"认识中华文明突出的**连续性、创新性、统一性、包容性、和平性**"，并联系"建设中华民族现代文明的历史使命"。
3. 中国古代史：夏朝"带有奴隶制特征"→"**进入奴隶社会**"；考古内容新增"郧县人""二里头"；清朝表述删除"入关后"限定。
4. 中国近现代史：新增"**中华民族发展史**"（与党史、新中国史、改革开放史、社会主义发展史构成"五史"）；强调"特别是（中共）十八大以来"；表述更新为"马克思主义中国化**时代化**新的飞跃""以中国式现代化全面推进中华民族伟大复兴"。
5. 世界史：近代史起点调整为"约 15 世纪末 16 世纪初"；现代史明确"中国倡导推动构建人类命运共同体，提供中国智慧、中国方案、中国力量"。
6. 资源利用：优先"乡土历史资源"，网络资源须"**合理利用**"。
7. 学业质量与评价**完全转向核心素养本位**：明确要求在唯物史观指导下、依靠可信史料、有理有据地解释历史。

## 课程内容结构

初中按**历史时序 + 专题**组织，每个时期下设"内容要求 / 学业要求 / 教学提示"。
教学提示强调：史料研习、情境创设、问题探究、项目学习（如"寻找身边的历史""家乡史调查"）。

## 跨学科关联提示

历史在跨学科方案中的典型角色：**时间维度的证据链 / 变迁与因果分析 / 文化认同与价值涵养 / 史料实证方法**。

高频跨界组合：
- 历史 + 语文：史料阅读、历史题材文本与戏剧创编、人物评说（史料实证 + 语言运用）。
- 历史 + 道德与法治：红色研学、革命传统、中华文明探源、国情教育（家国情怀 + 政治认同，最稳的一对）。
- 历史 + 地理：文明与地理环境、丝绸之路、都城选址、人口迁移（时空观念 + 区域认知）。
- 历史 + 美术/劳动：文物仿制、传统工艺复原、博物馆策展（历史解释 + 艺术表现/劳动能力）。
- 历史 + 信息科技：虚拟展览设计、数字文物、时间轴可视化（史料实证 + 数字化学习与创新）。

**注意**：
- 跨学科主题若涉及史实，必须**严格依据教材与博物馆/考古官方资料**，不臆造、不戏说。
- 有争议的史实与复杂考据，提示学生咨询教师，不展开辩论。

## 教师用书解读常用侧重

- 单元主旨：明确本单元的核心时空与核心问题。
- 史料使用：区分一手/二手史料，注意史料出处标注规范。
- 概念教学：如"封建社会""半殖民地半封建社会"等，须按教材表述界定。
- 时间与空间：强调用时间轴与地图构建时空框架。
- 评价：以核心素养为唯一标尺，避免纯记忆性考查。
