# 数学课程标准要点

## 核心素养

**义务段总表述（"三会"）**：
1. 会用数学的眼光观察现实世界
2. 会用数学的思维思考现实世界
3. 会用数学的语言表达现实世界

**小学阶段主要表现（11项）**：数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识。
**初中阶段主要表现（9项）**：抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识。

进阶逻辑（2025修订版明确）：小学侧重**对经验的感悟**（"意识"），初中侧重**对概念的理解**（"能力/观念"）。如"数学思维"在小学侧重推理意识（具体情境中的简单归纳），初中侧重推理能力（符号化论证与演绎推理）。

**高中段核心素养（6项）**：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析。

## 学段目标要点

| 学段 | 关键内容领域 | 典型要求 |
|---|---|---|
| 1–2 年级 | 数与运算、数量关系、图形的认识与测量 | 20以内加减法、100以内数的认识；认识长方体等立体图形；分类与整理 |
| 3–4 年级 | 数与运算、数量关系、图形的认识与测量、图形的位置与运动、数据收集整理 | 万以内数的认识、两位数乘除、分数初步认识；周长面积；简单数据统计 |
| 5–6 年级 | 数的认识与运算、数量关系、图形的认识与测量、图形的位置与运动、数据的收集整理与表达 | 小数与分数四则运算、比和比例、百分数；圆与圆柱圆锥；折线统计图 |
| 7–9 年级 | 数与式、方程与不等式、函数、图形的性质、图形的变化、图形与坐标、抽样与数据分析、事件的概率 | 有理数实数、代数式、一次/二次/反比例函数、三角形与四边形、圆、统计与概率 |

高中：主题为主线（函数、几何与代数、概率与统计、数学建模与探究）；必修 8 学分。

## 课程内容结构（义务段四大领域）

1. **数与代数**
2. **图形与几何**
3. **统计与概率**
4. **综合与实践**（跨学科主阵地）

**综合与实践**领域要求：小学以主题式学习为主，第三学段新增项目学习（如"营养午餐""水是生命之源"）；初中强化**跨学科项目式学习**，新增"体育运动与心率""绘制公园平面地图""GDP调研"等案例，明确"数学+体育/地理/经济"融合路径。

## 跨学科关联提示

数学在跨学科方案中的典型角色：**量化工具 / 数据建模 / 逻辑论证 / 测量与制图**。

高频跨界组合：
- 数学 + 科学/生物：实验数据记录与分析、生长曲线、心率与运动（数据观念 + 科学探究）。
- 数学 + 地理：统计图表的地域解读、人口/气候数据、地图比例尺与坐标（数据观念 + 区域认知）。
- 数学 + 美术：黄金比例、对称与图案设计、透视与几何作图（空间观念 + 艺术表现）。
- 数学 + 语文：文本信息的数据整理与统计、说明文中的数量表达（应用意识 + 语言运用）。
- 数学 + 体育与健康：运动心率、体能数据统计、跳绳成绩的统计分析。
- 数学 + 劳动/信息技术：预算与成本核算、数字化数据处理。

**注意**：跨科的前提是存在**真实的量化需求**。若主题本身没有测量、统计、建模的必要，不要硬跨数学。

## 教师用书解读常用侧重

- 数与运算：算理理解优先于算法熟练，注意进位退位、小数点位置等易错点。
- 图形与几何：从直观辨认到特征描述，注意周长与面积、表面积与体积的混淆。
- 统计与概率：数据收集的真实性与样本意识，条形图/折线图/扇形图的适用情境区分。
- 综合与实践：真实问题提出、方案设计、数据解释、反思改进四环节。
