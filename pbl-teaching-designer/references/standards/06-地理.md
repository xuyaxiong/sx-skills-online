# 地理课程标准要点

## 核心素养

**义务段（初中）与高中段一致（四项）**：人地协调观、综合思维、区域认知、地理实践力。

- **人地协调观**：正确认识人类活动与地理环境的关系，形成尊重自然、和谐共生的态度（含生态文明、可持续发展）。
- **综合思维**：从要素综合、时空综合、地方综合的角度认识地理环境及其与人类活动的相互作用。
- **区域认知**：运用空间—区域观点认识地理环境，采用区域比较、区域分析方法。
- **地理实践力**：在地理实验、社会调查、野外考察等实践中的行动能力与品质。

## 学段设置

- **义务教育阶段地理为初中课程（7–8 年级为主）**，小学不开设独立地理课，相关内容融入科学、道德与法治。
- 初中结构：地球与地图 → 世界地理（认识全球、认识区域）→ 中国地理（认识全球、认识区域、乡土地理）。
- 高中：必修 2 模块（自然地理、人文地理）+ 选择性必修（自然地理基础、区域发展、资源环境与国家安全）+ 选修。

## 课程内容结构（初中）

1. **地球的宇宙环境与地球运动**
2. **地图**（比例尺、方向、图例、等高线、地图阅读与绘制）
3. **世界地理**：海陆分布、气候、居民与聚落、区域差异
4. **中国地理**：疆域与人口、自然环境与自然资源、经济与文化、区域差异、乡土地理

## 跨学科关联提示

地理在跨学科方案中的典型角色：**空间与区域视角 / 人地关系分析 / 地图与数据可视化 / 乡土调查方法**。

高频跨界组合：
- 地理 + 生物/科学：生态系统、农作物分布与气候、乡土物种调查（人地协调观 + 生命观念）。
- 地理 + 历史：文明与地理环境、丝绸之路、都城选址、人口迁移（区域认知 + 时空观念）。
- 地理 + 数学：气候数据统计、人口统计图、地图比例尺与坐标（地理实践力 + 数据观念）。
- 地理 + 语文：游记、乡土调查报告、地域文化说明文（区域认知 + 语言运用）。
- 地理 + 道德与法治：生态文明、区域协调发展、国情教育（人地协调观 + 责任意识）。
- 地理 + 劳动/信息技术：乡土农业实践、GIS 与数字地图、遥感影像阅读。

**注意**：以地理为主学科时，应保留**地图工具与区域比较方法**这一学科内核，避免把课上成常识课。

## 教师用书解读常用侧重

- 区域学习方法：位置—特征—差异—联系—发展。
- 图表判读：等高线、气候直方图、人口金字塔等读图技能是重点与易错点。
- 乡土地理：必须落到本地（如四川：盆地地形、亚热带季风气候、紫色土、都江堰、长江上游生态屏障）。
- 实践：野外考察与地理实验，注意安全与可行性。
- 评价：读图分析题、区域比较题、实践报告。
