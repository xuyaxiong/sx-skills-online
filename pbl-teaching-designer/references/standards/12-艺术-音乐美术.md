# 艺术（音乐、美术）课程标准要点

## 核心素养

**义务段（艺术，四项）**：审美感知、艺术表现、创意实践、文化理解。

分科口径：
- **音乐（高中段）**：审美感知、艺术表现、文化理解。
- **美术（高中段，五项）**：图像识读、美术表现、审美判断、创意实践、文化理解。

- **审美感知**：感受、欣赏与评价自然美、艺术美、生活美，形成审美趣味。
- **艺术表现 / 美术表现**：运用媒介、技法与语言进行创作与表演。
- **创意实践**：联想与想象、构思与表达、合作与探究（美术另有"审美判断"）。
- **文化理解**：理解艺术与文化、生活、时代的关系，尊重文化多样性，增强文化自信。

## 学段设置与内容

**课程设置**：一至七年级以**音乐、美术**为主线，融入舞蹈、戏剧（含戏曲）、影视（含数字媒体艺术）内容；**八至九年级分项选择开设**。

**音乐**学习领域：感受与欣赏、表现、创造、音乐与相关文化。
**美术**学习领域：欣赏·评述、造型·表现、设计·应用、综合·探索。
其中"综合·探索"是美术课标明列的**跨学科融合领域**。

**高中**：音乐必修（音乐鉴赏 + 歌唱/演奏/创作等模块）；美术必修 3 学分（美术鉴赏 1 学分 + 选择性必修 2 学分）。

## 2025 修订版相关提示

艺术课程强调**基于核心素养的、具体可操作的过程性评价**，注重评价主体多元化（自评、互评、师评）、评价过程多样化，强调中华优秀传统文化、革命文化、社会主义先进文化在艺术中的体现。

## 跨学科关联提示

艺术在跨学科方案中的典型角色：**成果的视觉化与表现 / 审美与文化理解 / 创意转化与传播**。

高频跨界组合：
- 美术 + 语文：诗配画、绘本创作、课本剧海报与道具（创意实践 + 语言运用）。
- 美术 + 数学：对称与图案、黄金比例、透视与几何作图（审美判断 + 空间观念）。
- 音乐 + 语文：诗歌吟诵、为古诗词谱曲、戏剧配乐（艺术表现 + 文化自信）。
- 美术 + 历史/道法：文物仿制、红色主题创作、乡土文化绘本（文化理解 + 家国情怀/政治认同）。
- 音乐 + 体育：律动与形体、民族民间舞蹈（艺术表现 + 运动能力）。
- 美术/音乐 + 信息科技：数字绘画、虚拟展览、音频剪辑、AI 辅助创作（创意实践 + 数字化学习与创新）。
- 美术 + 科学/生物：自然笔记、科学绘图、生态装置（创意实践 + 生命观念）。

**注意**：
- 艺术作为跨学科伙伴时，其贡献必须是**表现方式与审美判断**，而不只是"把作业画漂亮"。
- 若缺乏器材与场地，优先选择纸本绘画、拼贴、废旧材料装置、身体打击乐等低成本形式。

## 教师用书解读常用侧重

- 欣赏·评述：从描述→分析→解释→评价四步（费德曼方法）引导。
- 造型·表现：材料与技法的安全使用，过程性草图与修改。
- 综合·探索：主题—调研—构思—制作—展示—反思。
- 评价：作品档案袋、过程记录、展示与互评，避免只以"像不像"评判。
