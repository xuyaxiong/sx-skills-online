# 生物学课程标准要点（初中—高中）

## 核心素养

**义务段（初中，四项）**：生命观念、科学思维、探究实践、态度责任。
**高中段（四项）**：生命观念、科学思维、科学探究、社会责任。

- **生命观念**：结构与功能观、物质与能量观、演化与适应观、生态观、稳态与平衡观。
- **科学思维**：归纳概括、演绎推理、模型与建模、批判性思维、创造性思维。
- **探究实践 / 科学探究**：观察、实验、调查、资料分析、设计与实施。
- **态度责任 / 社会责任**：健康生活、生态保护、科学实践参与、生物技术伦理判断。

## 学段设置与内容

**初中（7–8 年级）** 六大学习主题：
1. 生物体的结构层次
2. 生物的多样性
3. 生物与环境
4. 植物的生活（绿色开花植物的一生、光合作用与呼吸作用、蒸腾作用）
5. 人体生理与健康（消化、循环、呼吸、排泄、神经与激素调节、免疫、生殖与发育、青春期）
6. 遗传与进化

**高中**：必修 2 模块（分子与细胞、遗传与进化）+ 选择性必修（稳态与调节、生物与环境、生物技术与工程）。

## 2025 修订版相关提示

生物学与科学、物理、化学同属科学领域，2025 修订版强调科学领域课程**纵向衔接与横向配合**，加强对共通性素养的培育；强调数字化工具处理实验数据、模型与建模。

## 跨学科关联提示

生物学在跨学科方案中的典型角色：**生命系统视角 / 观察与饲养栽培实践 / 生态与可持续发展议题 / 健康生活落点**。

高频跨界组合：
- 生物 + 地理：农作物与气候土壤、生态系统与区域、乡土物种调查（生态观 + 人地协调观，最稳的一对）。
- 生物 + 化学：光合作用与呼吸作用、营养与消化、土壤养分（物质与能量观 + 变化观念）。
- 生物 + 劳动：种植与养殖、校园农场、堆肥与生态循环（探究实践 + 劳动能力）。
- 生物 + 美术：自然笔记、科学绘图、生态海报（生命观念 + 艺术表现）。
- 生物 + 数学：种群数据调查、生长曲线、遗传比例统计（科学思维 + 数据观念）。
- 生物 + 语文/信息科技：观察日记、科普写作、数字化记录（态度责任 + 语言运用）。
- 生物 + 道德与法治：生命教育、生态保护责任、生物技术伦理（态度责任 + 责任意识）。

**注意**：
- 初中生物 7–8 年级开设，9 年级无生物课（部分地区安排不同），跨学科设计的年级适配需核实。
- 涉及活体实验、解剖、户外采集，须符合动物福利与安全规范，优先选择观察、模型、模拟替代。

## 教师用书解读常用侧重

- 结构与功能观贯穿始终，是生物学科最核心的思想主线。
- 实验：显微镜使用、临时装片制作、对照实验设计（变量与对照）。
- 易错点：光合作用与呼吸作用的条件与场所混淆；动脉/静脉与动脉血/静脉血混淆；遗传图解书写。
- 评价：实验观察记录、模型制作、调查报告与情境化解释。
