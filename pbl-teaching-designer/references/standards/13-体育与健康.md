# 体育与健康课程标准要点

## 核心素养

**义务段与高中段一致（三项）**：运动能力、健康行为、体育品德。

- **运动能力**：体能、技能、心理能力，能掌握并运用运动项目技能，参与展示与比赛。
- **健康行为**：锻炼习惯、健康知识与技能、情绪调控、文明健康的生活方式、安全防护。
- **体育品德**：体育精神、体育道德、体育品格（自尊自信、文明礼貌、责任意识、遵守规则、尊重对手）。

## 学段设置与内容

**水平划分**：
- 水平一：1–2 年级
- 水平二：3–4 年级
- 水平三：5–6 年级
- 水平四：7–9 年级

**课程内容**（五个方面）：
1. 基本运动技能（移动性、非移动性、操控性技能）
2. 体能（力量、速度、耐力、柔韧、灵敏、协调）
3. 健康教育（健康行为与生活方式、生长发育与青春期保健、心理健康、疾病预防与突发公共卫生事件应对、安全应急与避险）
4. 专项运动技能（球类、田径、体操、水上或冰雪、中华传统体育类、新兴体育类六类）
5. 跨学科主题学习

**高中**：必修全修全学（体能 + 健康教育 + 运动技能系列）。

## 2025 修订版关键变化

- 课程性质更新为"以**中国式现代化**全面推进中华民族伟大复兴"，健康行为目标由"形成健康的生活方式"改为"形成**文明健康**的生活方式"。
- 课程理念新增与**社会主义先进文化、革命文化、中华优秀传统文化**的融合要求。
- 中华传统体育类运动：新增"尤其要重视具有**对抗性**的中华传统体育类运动项目，减少花拳绣腿式的比画动作教学，培养学生的尚武精神和阳刚之气"。
- 跨学科主题学习课时占比要求同其他学科。

## 跨学科主题学习（课标明列）

典型方向：
- 体育 + 数学：运动心率与数据统计、跳绳/跑步成绩的统计与分析、投掷角度与距离
- 体育 + 科学/生物：运动中的呼吸与循环、肌肉与骨骼、能量消耗
- 体育 + 语文/英语：赛事报道、运动解说词、体育精神演讲
- 体育 + 道德与法治：规则意识、公平竞争、团队协作、体育精神
- 体育 + 音乐：律动与节奏、民族民间体育与音乐

## 跨学科关联提示

体育与健康在跨学科方案中的典型角色：**身体实践与体验 / 健康数据 / 规则与团队品格 / 传统体育文化**。

**注意**：
- 以体育为主学科时，跨学科**不得挤占必要的运动负荷**，体育课的学科本体是身体练习，跨学科内容控制在课的部分环节（如数据分析 10 分钟）。
- 体育运动存在安全风险，任何跨学科设计必须写明**场地、器材、着装、热身与安全预案**，特殊体质学生的替代活动安排。
- 不宜在烈日、湿滑场地或高强度运动后安排长时间静态数据记录，须符合运动生理学常识。

## 教师用书解读常用侧重

- 课的结构：开始部分（热身）— 基本部分（学练与比赛）— 结束部分（放松与小结），运动密度与平均心率有基本要求。
- 学练赛一体化：在比赛情境中检验技能。
- 健康教育：结合学生生活实际，避免说教。
- 评价：体能测试 + 技能表现 + 参与态度与情意表现，过程性评价为主。
