# 综合实践活动与通用技术课程要点

## 综合实践活动

### 定位与设置

- 自**一年级**起开设，与学科课程并列，是必修课程。
- 2022 方案已将**劳动、信息科技**从综合实践活动中独立出来，综合实践活动现以**跨学科研究性学习、社会实践**为主干。

### 主要内容

1. **考察探究**：提出并聚焦问题—设计方案—获取与分析资料—得出结论—交流反思（与 PBL 流程高度同构）。
2. **社会服务**：社区服务、志愿服务、公益劳动。
3. **设计制作**：创意设计、手工与数字作品、装置制作。
4. **职业体验**：职业认知、模拟与实习体验（7–9 年级与高中为重点）。

### 与 PBL 的关系

综合实践活动的考察探究流程本身就是项目式学习的标准骨架。设计跨学科主题时，可将其作为**流程模板**：

```
发现问题 → 提出假设/确定课题 → 制定方案 → 实施探究（查阅、调查、实验、访谈）
→ 形成成果（报告/作品/展演） → 交流评价 → 反思改进
```

## 通用技术（高中）

### 核心素养（五项）

技术意识、工程思维、创新设计、图样表达、物化能力。

- **技术意识**：技术的目的性、创新性、综合性、两面性，技术与自然社会的关系。
- **工程思维**：系统分析、权衡优化、约束条件下的问题解决。
- **创新设计**：需求发现、方案构思、人机关系、迭代优化。
- **图样表达**：识图与绘图，三视图、草图、技术语言交流。
- **物化能力**：材料选择、工具使用、工艺实施、装配与测试。

### 课程内容

必修：技术与设计1、技术与设计2；选择性必修：技术与生活、技术与工程、技术与职业、技术与创造。

## 跨学科关联提示

综合实践活动与通用技术在跨学科方案中的典型角色：**真实项目的流程骨架 / 工程设计与物化 / 社会实践与职业体验 / 公开成果与答辩**。

高频跨界组合：
- 综合实践 + 任意学科：作为流程载体，把学科项目落到"考察探究"标准流程。
- 通用技术 + 物理：装置制作、结构与力学测试（工程思维 + 物理观念）。
- 通用技术 + 数学：尺寸与比例、三视图、成本与优化计算（图样表达 + 空间观念）。
- 通用技术 + 信息科技：智能装置、编程控制（物化能力 + 计算思维）。
- 通用技术 + 美术：产品造型与外观设计（创新设计 + 创意实践）。
- 通用技术 + 劳动：工艺制作、工具使用（物化能力 + 劳动能力）。

**注意**：
- 综合实践活动是**跨学科主题学习最天然的落地通道**，若学校对课时与场地支持有限，可优先走此通道。
- 工程类项目必须明确**约束条件**（材料、成本、时间、安全）与**迭代次数**，避免做成"无限开放式"的空项目。

## 教师用书解读常用侧重

- 选题指导：小切口、可操作、有真实价值、与学段匹配。
- 方法指导：问卷设计、访谈提纲、观察记录表、资料引用规范。
- 成果形式：研究报告、模型实物、展演、倡议书、数字作品。
- 评价：过程档案 + 成果评价 + 反思报告，强调自评互评与改进。
