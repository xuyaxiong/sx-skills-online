# 劳动课程标准要点

## 核心素养

**义务段（四项）**：劳动观念、劳动能力、劳动习惯和品质、劳动精神。

- **劳动观念**：尊重劳动、热爱劳动、劳动创造价值、劳动者平等光荣。
- **劳动能力**：生活与生产劳动的基本技能，设计与制作、动手操作与问题解决能力。
- **劳动习惯和品质**：自觉劳动、安全规范、吃苦耐劳、有始有终、珍惜劳动成果。
- **劳动精神**：勤俭、奋斗、创新、奉献，劳模精神与工匠精神。

**高中**：劳动为必修课程，与综合实践活动统筹，强调职业体验与生产劳动。

## 学段设置与内容

劳动自**一年级**起开设（2022 方案已将劳动从综合实践活动中独立出来）。

**十大任务群**（按学段螺旋安排，不同学段要求不同项目）：
1. 整理与收纳
2. 烹饪与营养
3. 家用电器使用与维护
4. 农业生产劳动
5. 传统工艺制作
6. 工业生产劳动
7. 新技术体验与应用
8. 现代服务业劳动
9. 公益劳动与志愿服务
10. 日常生活劳动（含清洁与卫生）

**学段侧重**：
- 1–2 年级：个人生活自理、班级值日、简单手工
- 3–4 年级：家庭餐食简单制作、种植饲养起步、传统工艺启蒙
- 5–6 年级：家常餐制作、家用电器使用、校园种植、志愿服务
- 7–9 年级：营养与膳食设计、生产劳动体验、新技术应用、职业启蒙

## 跨学科关联提示

劳动在跨学科方案中的典型角色：**动手实践与物化产出 / 真实劳动情境 / 劳动价值与品质养成 / 成果可食可用的真实反馈**。

高频跨界组合：
- 劳动 + 科学/生物：种植与堆肥、发酵食品、生态循环（劳动能力 + 探究实践/生命观念）。
- 劳动 + 数学：预算与成本核算、尺寸测量、产量统计（劳动能力 + 应用意识）。
- 劳动 + 语文：劳动过程记录、劳动报告、劳动故事（劳动精神 + 语言运用）。
- 劳动 + 美术：传统工艺制作、手作设计（劳动能力 + 创意实践）。
- 劳动 + 道德与法治：劳动价值观、志愿服务与公益（劳动精神 + 责任意识）。
- 劳动 + 地理/化学：乡土农产、土壤与水质检测（劳动能力 + 区域认知/科学探究与实践）。

**注意**：
- 劳动课的核心是**出力流汗、动手实践**，跨学科设计不能以"研究/报告"替代实际劳动。
- 涉及刀具、火源、电器、农具、化学清洁剂的任务，必须写明安全规范与教师/家长监护要求。
- 场地与材料受限时，优先选择纸艺、布艺、编织、种植（芽苗菜/多肉）、废旧材料改造等低成本项目。

## 教师用书解读常用侧重

- 任务群设计：任务驱动、做中学，明确劳动步骤与关键动作要领。
- 过程指导：示范—模仿—练习—纠错—独立操作。
- 安全：工具使用规范、场地与卫生要求、应急处理。
- 评价：劳动态度、过程表现、成果质量与习惯养成，倡导劳动档案袋与家校协同评价。
