# 化学课程标准要点（初中—高中）

## 核心素养

**义务段（初中，四项）**：化学观念、科学思维、科学探究与实践、科学态度与责任。
**高中段（五项）**：宏观辨识与微观探析、变化观念与平衡思想、证据推理与模型认知、科学探究与创新意识、科学态度与社会责任。

## 学段设置与内容

**初中（9 年级）** 五大学习主题：
1. 科学探究与化学实验（8 个必做实验）
2. 物质的性质与应用（空气、氧气、水、碳和碳的氧化物、金属与金属矿物、常见的酸碱盐）
3. 物质的组成与结构（微粒、元素、化学式与化合价、质量守恒定律）
4. 物质的化学变化（化学变化与物理变化、质量守恒、化学方程式、燃烧与灭火）
5. 化学与社会·跨学科实践（化学与资源、能源、材料、环境、健康）

**高中**：必修 2 模块（化学科学与实验探究、常见无机物及其应用、物质结构基础与化学反应规律、简单的有机化合物）+ 选择性必修（化学反应原理、物质结构与性质、有机化学基础）。

## 化学与社会·跨学科实践（初中）

该主题是化学课标明列的跨学科主阵地，要求围绕真实问题开展：
- 水资源与净化、空气质量与雾霾
- 金属资源利用与回收、垃圾分类
- 化肥与农药的合理使用、土壤酸化
- 碳中和与低碳生活、新能源材料
- 食品与健康、药物与化学品安全

## 跨学科关联提示

化学在跨学科方案中的典型角色：**物质变化与转化的解释 / 实验与检测手段 / 宏观—微观联结 / 环境与资源议题**。

高频跨界组合：
- 化学 + 生物：光合作用与呼吸作用、营养与健康、土壤与微生物（变化观念 + 生命观念）。
- 化学 + 地理：岩石与土壤、水质与流域、矿产资源分布（物质观念 + 区域认知）。
- 化学 + 道德与法治/科学：生态文明、碳中和、化学品安全与社会责任（科学态度与责任 + 责任意识）。
- 化学 + 数学：化学方程式配平与定量计算、实验数据处理（证据推理 + 数据观念）。
- 化学 + 劳动/技术：手工皂制作、土壤改良、发酵食品（科学探究与实践 + 劳动能力）。
- 化学 + 语文：科普说明文、化学史与科学家精神（科学态度与责任 + 语言运用）。

**注意**：
- 初中化学仅在 9 年级开设，**前置知识有限**，跨学科任务不宜要求超出初中范围的反应原理。
- 涉及试剂的实验，必须写明安全与废弃物处理要求；小学段不适用化学独立课程，相关内容归入科学。

## 教师用书解读常用侧重

- 微粒观建构：从宏观现象到微观解释是初中化学最大难点。
- 化学方程式：配平、反应条件与状态符号是高频易错点。
- 实验：装置选择、气密性检查、检验与验满、除杂与干燥。
- 易错概念：物理变化/化学变化、纯净物/混合物、溶解度与溶质质量分数。
- 评价：实验操作 + 情境化解释题（用微观模型解释宏观现象）。
