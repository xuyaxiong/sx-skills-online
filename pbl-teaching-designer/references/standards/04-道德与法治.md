# 道德与法治 / 思想政治课程标准要点

## 核心素养

**义务段（道德与法治，五项）**：政治认同、道德修养、法治观念、健全人格、责任意识。
**高中段（思想政治，四项）**：政治认同、科学精神、法治意识、公共参与。

义务段五项内涵要点：
- **政治认同**：拥护党的领导，热爱祖国与人民，认同中华文化与社会主义核心价值观。
- **道德修养**：个人品德、家庭美德、社会公德、职业道德的雏形，明大德守公德严私德。
- **法治观念**：宪法法律至上、法律面前人人平等、权利义务相统一、守法用法意识。
- **健全人格**：自尊自信、理性平和、积极向上、友爱互助、坚韧乐观。
- **责任意识**：对自己、家庭、集体、社会、国家、人类负责，担当精神与参与能力。

## 学段目标要点

| 学段 | 课程主线 | 典型主题 |
|---|---|---|
| 1–2 年级 | 入学适应、习惯养成、我与家庭与学校 | 我是小学生、我的家庭、班级规则、礼貌与友善 |
| 3–4 年级 | 我与集体、社区与公共生活 | 班级与学校规则、社区服务、公共安全、勤俭节约 |
| 5–6 年级 | 我与国家、法律初步、责任担当 | 宪法常识、未成年人保护、民族团结、家乡与国家发展 |
| 7–9 年级 | 成长中的我、我与他人和集体、我与国家和社会 | 生命安全与健康教育、法治教育、中华优秀传统文化教育、国情教育、社会主义核心价值观 |

**重要**：道德与法治是九年一体化设计，整合了原小学"品德与生活""品德与社会"与初中"思想品德"。小学阶段历史、地理内容**不单独设科**，相关内容融入道德与法治（国情教育、中华优秀传统文化、中华民族发展史等）。

高中思想政治：必修 4 模块（中国特色社会主义、经济与社会、政治与法治、哲学与文化）+ 选择性必修（当代国际政治与经济、法律与生活、逻辑与思维）。

## 课程内容结构（义务段）

按**学习主题**组织，按学段螺旋上升：
1. 入学教育 / 道德教育 / 生命安全与健康教育 / 法治教育 / 中华优秀传统文化与革命传统教育 / 国情教育 等。
2. 2025 修订版强化：中华文明五大突出特性（连续性、创新性、统一性、包容性、和平性）、"五史"教育（党史、新中国史、改革开放史、社会主义发展史、中华民族发展史）、总体国家安全观、中国式现代化。

## 跨学科关联提示

道德与法治在跨学科方案中的典型角色：**价值引领 / 规则与公共性 / 社会责任落点 / 真实社会议题入口**。

高频跨界组合：
- 道法 + 语文：革命文化文本、家国主题阅读与演讲、乡土文化调查（政治认同 + 文化自信）。
- 道法 + 历史：中华文明探源、红色研学、中华民族发展史（最自然的一对）。
- 道法 + 地理：区域发展、生态文明、乡土国情（责任意识 + 人地协调观）。
- 道法 + 科学/生物：生态保护、生命教育、科技伦理与科学家精神（态度责任 + 责任意识）。
- 道法 + 信息科技：网络素养、信息社会责任、数字公民（法治观念 + 信息社会责任）。
- 道法 + 劳动：劳动价值观、劳动精神（责任意识 + 劳动精神）。

**注意**：道法的价值引领要**融入活动而非贴标签**，避免在每个环节都生硬加一句"培养家国情怀"。

## 教师用书解读常用侧重

- 单元立意：从"知道—认同—践行"三层递进设计。
- 情境创设：用真实生活情境（校园、社区、网络）引发道德冲突与判断。
- 法治内容：以案例为载体，明确法律条文的生活化解释，注意未成年人保护法等相关条款。
- 评价：表现性评价为主，重视行为改进与日常观察，不主张纸笔考试排名。
