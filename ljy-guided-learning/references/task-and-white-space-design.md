# 学习任务与留白分层设计

> 所属知识库：导学单生成技能 > 任务库
> 对应步骤：提问四（任务形态、分层、留白）、生成阶段

## 本文件目的

同样一个教学环节，写成"体会作者情感"还是"用波浪线画出最打动你的一句，在旁边写下你想到的一个画面"，学生的完成率天差地别。本文件规定学习任务怎么写、填写形态怎么选、分层怎么才算真分层、留白留多少。

---

## 一、任务指令的写法

### 三条硬规则

1. **动词开头、第二人称、可执行**：每条指令必须以学生的具体动作开头。
   - ✅「读第 2 段，圈出三个描写颜色的词」
   - ❌「引导学生品读第 2 段，体会语言的生动性」（教师视角）
   - ❌「感受作者的语言美」（不可执行，学生不知道手上要干什么）
2. **一条指令一件事**：复合指令拆成①②③，学生按序完成。
3. **给出完成标准**：写几条、几个字、几分钟，让学生知道做到什么算完成。

### 任务动词按认知层级选（对齐教案目标）

| 认知层级 | 可用动词 | 适配的填写形态 |
|---|---|---|
| 记忆/理解 | 圈出、填、连线、标注、读、找出、补全 | 填空、连线、勾选 |
| 应用 | 算出、仿写、画出、演示、按步骤完成 | 计算区、格线、步骤条 |
| 分析 | 比较、分类、找异同、拆解、推理 | 对比表格、维恩图、流程图 |
| 评价 | 判断、评价、选择并说明理由、指出问题 | 观点+理由两栏、评分条 |
| 创造 | 设计、改编、提出方案、举反例、创作 | 大留白区、方案卡 |

**对齐要求**：任务动词的层级不得低于教案对应目标的层级。教案目标写"能举例说明"，导学单只让学生填空，就是降级，必须调整。

## 二、填写形态选择

| 形态 | 适用 | 优点 | 注意 |
|---|---|---|---|
| **填空补白** | 概念记忆、结构梳理、低年级 | 门槛低、易批改、省版面 | 空太多变机械抄写；关键处才留空 |
| **表格记录** | 对比、分类、多轮观察、实验数据 | 思维结构外显、便于交流 | 表头必须写清每列要填什么 |
| **图示/思维导图** | 知识结构、关系梳理、总结环节 | 整体感强、适合小结 | 给出部分节点做支架，不给全空白圈 |
| **自由书写** | 感悟、疑问、开放性问题、创造层任务 | 空间大、能出真思维 | 必须配提示语或句式支架，否则空白交卷 |
| **勾选/评分条** | 自评、互评、达标检测 | 快速、无书写负担 | 选项要具体可判断，不写"很好/一般" |
| **混合** | 多数真实课堂 | 节奏有变化，不枯燥 | 一栏内不超过两种形态，避免版面碎裂 |

选择依据：**课中单偏表格与填空**（书写时间紧）、**课前课后单可用自由书写与图示**（有时间思考）、**总结环节优先图示**。

## 三、分层设计：三档必须实质不同

分层最常见的假动作是"基础题 3 道、提升题 3 道，其实一模一样"。真分层至少在以下**一个维度**上实质变化：

| 分层维度 | 基础层 | 提升层 | 挑战层 |
|---|---|---|---|
| **支架强度** | 给示例+步骤条 | 给关键提示 | 无支架 |
| **条件完备度** | 条件全给 | 需自己提取条件 | 条件不全需假设 |
| **认知层级** | 理解/应用 | 分析 | 评价/创造 |
| **答案开放度** | 唯一答案 | 多解 | 开放无标准答案 |
| **迁移距离** | 同情境 | 近迁移 | 远迁移/跨学科 |

### 两种分层方式（提问四中让教师选）

- **必做 + 选做两档**：操作简单，适合常规课时；标注清楚「★必做」「☆选做」。
- **基础·提升·挑战三档**：适合班级差异大、教案已有三层支架设计；用图标或色块区分，**不用"差生/优生"式标签**。
- **不分层全员统一**：适合全新概念第一课时、或教师明确不分层。

### 分层纪律

- 分层任务全部锚定同一学习目标，只是路径不同，不能变成"基础层学不到目标"。
- 每档任务量匹配：挑战层不是"基础层做完再加做"，避免变相惩罚快的学生。
- 标记方式对学生友好：用「★ 稳扎稳打 / ★★ 更进一步 / ★★★ 挑战自己」这类中性表述。

## 四、支架设计与撤除

支架放在难点处，与教案的难点突破方式保持一致。四类常用支架：

1. **示例支架**：给一个做好的样例（"像这样：……"）；
2. **句式支架**：给半截句子（"我发现______，因为______"）；
3. **步骤支架**：拆成①②③步骤条；
4. **提示卡**：折角小贴士（"想不出来？试试从……角度看"）。

**撤除规则**：同类任务连续出现时，第一题给满支架，第二题减半，第三题撤除。在导学单上体现为提示逐渐变短。教案里若标注了支架撤除时机，严格照做。

## 五、留白量

留白不够学生没处写，留白过多显得任务没做完、还浪费纸。按形态定量：

| 任务类型 | 建议留白 |
|---|---|
| 词语/数字填空 | 下划线长度约为答案字数的 1.5 倍 |
| 一句话回答 | 1 行（约 20-25 字） |
| 简答（2-3 句） | 3 行 |
| 段落书写/感悟 | 5-6 行，或标注"约 80 字" |
| 计算/推导 | 方框区，高度约 4-6 行 |
| 图示/思维导图 | 半页方框，预印部分节点 |
| 表格 | 每行高度不小于 1.5 倍行距 |

三档留白强度（提问四中让教师选）：
- **紧凑**：上表基准 × 0.8，适合课中单、省纸；
- **适中**：按上表基准；
- **宽松**：× 1.3，适合低年级（字大）、课前独立完成、需要画图。

**低年级特别提醒**：小学低段书写占位大，留白至少按宽松档，且填空处建议给田字格或四线三格。

## 常见失败

- 指令用教师语言，学生读不懂要干什么。
- 一栏塞五条任务，学生做不完，课堂节奏被拖垮。
- 分层只改数字不改思维层级，三档等于一档。
- 开放题不给句式支架，收上来一片空白。
- 留白只有半行，学生字挤成一团。
- 支架全程不撤，学生始终没有独立完成的机会。
- 自评栏写"很好/一般/较差"，学生无法判断自己属于哪档。

## 同步教研引导话术

「探究栏我打算用表格让学生记两组发现，课中书写时间紧，表格比自由书写快；难点那一处我加了句式支架『我发现______，因为______』，不然学生容易写不出来。分层我建议做必做加选做两档就够了，选做那题让学生自己举一个反例，跟必做的认知层级实质不一样，不是多做两道。您班孩子写字占位大不大？留白要不要放宽一点？」
