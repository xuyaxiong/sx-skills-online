# 引导提问话术库

> 所属知识库：导学单生成技能 > 交互库
> 对应步骤：四问引导流程全程

## 本文件目的

教师时间稀缺，问多了是打扰，问浅了等于没问。本文件规定 4 个提问的完整话术模板、收敛技巧与反例。核心原则：**带着做完的分析去问，给候选与推荐，由教师决定，不空手提问、也不渲染流程感**。

---

## 提问总纪律

1. **硬上限 4 问**：3 个核心决策问 + 1 个交付确认问。教师后续主动追加的讨论不计入。
2. **一次一问（铁律）**：每次提问**只发出一个问题**的题干、候选与【推荐】项；**严禁在同一次提问里把提问一~四一并列出或预览后续问题**。抛出当前问后等待教师回答，不连珠炮、不剧透后续。
3. **三段式结构**：每个提问都按「我做了什么分析 → 我推荐什么及为什么 → 请您定哪一项」组织。
4. **候选不超 4 个**，且必须标【推荐】并给出理由，理由要指明**来自教案的哪一处**。
5. **永远留自定义出口**：结尾加一句"或者您有别的想法，直接说"。
6. **教师说"你看着办"时**：走默认推荐，但生成后必须列出「我替您做的默认选择」清单请其复核。
7. **不问已知的事**：教案里写了的、教师前面答过的，不重复问。

## 提问一话术模板：定位与骨架

```
您这节课我看了一遍——探究环节 22 分钟，占了总时长快一半，学生要边做边记；
前置知识那块教案里也没安排专门铺垫，说明您判断学生底子够。

基于这个，我推荐做【课中探究单】，栏目顺着您的四个环节走，学生跟着单子就能跟上课堂节奏。
备选是课前预习单，但那样课堂得腾出时间对预习答案，会挤压您的探究时间。

一件事请您定一下：
1. 做课中探究单，还是课前预习单？（或者您想要全程单也行，就是篇幅会长）

（篇幅我按推荐直接定，不再另问您。）
```

## 提问二话术模板：环节映射与详略

```
我把您教案的 6 个环节逐条对到导学单上了，先给您看这张对照表：

（对齐表已写在回复正文里，提问不重复）

我的建议是：保留 4 栏、合并 1 栏、略写 1 栏——
· "巩固练习"和"变式训练"学生动作是同质的，建议合并成一栏"练一练"；
· "教师归纳"学生没有书面产出，建议略成一句提示语，不占填写区；
· 重点是"探究发现"这一栏，命中您教案的难点，我准备写详一点，加支架和示例。

还有一个提醒：您教案第 3 条目标"能举例说明"，现在没有栏目能产出这个证据，
建议在探究栏后面加一个"我来举个例子"的小格。

这个删减和加详的方案，您要改哪里？
```

## 提问三话术模板：任务形态、分层、留白

```
任务怎么写我有个方案：

· 形态：探究栏用表格（课中书写时间紧，表格比自由书写快），
  小结栏用半成品思维导图（预印两个节点做支架），
  疑问栏留自由书写但配句式"我还想问______"。
· 分层：建议必做+选做两档就够。选做那题让学生自己举一个反例，
  跟必做的认知层级实质不同，不是多做两道题——这个对应您教案里给拓展层留的口子。
· 留白：课中单我按紧凑档排，一页能装下。

三件事：形态这样配行吗？分层要两档还是三档？
您班孩子写字占位大不大，留白要不要放宽？
```

## 提问四话术模板：交付确认

```
最后确认一件事，定完我就出稿：
1. 要不要加自评栏？我建议加三行勾选式的，学生 30 秒能填完。
```

## 收敛技巧

**教师回答含糊时**（"都行""你决定"）：
不要追加提问耗额度。直接说明将采用哪个推荐方案及理由，一句话带过，继续推进，生成后统一列默认选择清单请其复核。

**教师提出新需求时**（"能不能加个小组互评"）：
即时接纳并说明它会影响什么（篇幅、栏目顺序），不新增提问，在下一个既定提问中一并确认。

**教师一次答了多个问题时**：
后续提问中已被回答的部分直接跳过，剩余问题合并，可以少于 4 问——**问得少是好事，不是缺陷**。

**信息确实不足时**（如完全不知道学情、不知道教材版本）：
优先用 `query_knowledge` 自查，查不到再问，且把它并进最近的一个既定提问，不单独起一问。

## 反例：这些问题不许问

| 反例 | 问题所在 | 改法 |
|---|---|---|
| 「您觉得呢？」「还有什么补充？」 | 零信息量，把思考负担丢回教师 | 给出具体方案让其确认或修改 |
| 「您想要什么样的导学单？」 | 开放到无从答起 | 先判断课型，给 2-3 个带理由的候选 |
| 「这一栏您想放什么材料？」 | 教师要从零想 | 锚点确认单已列每栏素材，直接让其确认或提出替换 |
| 「学情怎么样？」（教案里已写） | 重复索取已有信息 | 直接复用教案学情，必要时只做确认 |
| 「要不要分层？要不要自评？」分两次问 | 碎问耗额度 | 合并进提问三、四一次问清 |
| 「教材是什么版本？第几页？插图是什么？」 | 应自查的事实性问题 | 先 query_knowledge |

## 语气要求

- 平等、专业的合作口吻，不是客服口吻：说「我建议」「您要改哪里」，不说「请问您需要……吗」。
- 不铺垫、不寒暄、不夸奖，直接进入内容。
- 判断要有依据且说出来：「探究占了 22 分钟」比「这节课探究比较多」有说服力。
- 敢于指出问题：目标没落点、分层是假分层、篇幅要超，都要直说并给解法。
