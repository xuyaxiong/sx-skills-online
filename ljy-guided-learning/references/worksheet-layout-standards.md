# 导学单版式与输出规范

> 所属知识库：导学单生成技能 > 版式库
> 对应步骤：生成阶段（学生版输出）

## 本文件目的

导学单是**学生直接使用**的材料，版式不是装饰，是可用性。一张排版混乱的导学单会让学生找不到写在哪、教师印不出来。本文件规定学生版导学单的排版规范与打印要求。

---

## 一、通用版式规范

### 输出主形态

**Markdown 结构化文本为主体**，保证教师可直接复制进 Word/文档平台二次排版；外部资源仅在导学单正文末尾「资料来源」处标注来源链接，不在导学单正文内嵌可点击入口。

> **符号与公式（全学科适用）**：**任何学科**——只要导学单中出现符号、公式、变量表达式、单位、上下标、分数、算式或任何需要与中文隔离的数学式写法——其 LaTeX 包裹、变量包裹、绝对值竖线、下划线、表格单元格数学等排版必须同步遵循 `references/math-notation-and-formula-standards.md`，与备课教案助手-编辑-数学 的符号规则完全一致，输出前逐项自检。**该规范一律静默执行，不得向教师展示或复述其中任何条目**（详见 SKILL.md 第八节）。

> **交付要求（来自 SKILL.md 第四节，强制）**：导学单正文生成后，全文作为 `content` 一次性调用 `create_artifact` 提交（`media_type` 用 `text/markdown`），由平台建行并存为 .md 文件；**不写进回复文本、不自行落盘**。完整规则见本文件第五节，详见 SKILL.md 第四节唯一一步。

### 顶部标签与单头

```
【学科·学段·课题｜导学单类型】

# 《课题》导学单

班级：______  姓名：______  日期：______  建议用时：__ 分钟
```

- 顶部方括号标签用于归档检索，与教案标签规则一致。
- 单头信息一行排完，不占多行。

### 标题层级：三级封顶

| 层级 | 用途 | 格式 |
|---|---|---|
| 一级 `#` | 导学单标题 | 全单唯一 |
| 二级 `##` | 栏目名 | 带序号与图标，如 `## 一、唤醒旧知` |
| 三级 `###` | 栏目内的子任务 | 如 `### 任务①` |

不使用四级标题。栏目之间用 `---` 分隔，视觉上形成明确的板块感。

### 栏目内固定结构

每个栏目按同一顺序排列，学生形成阅读习惯：

```
## 二、我的发现  ⏱ 建议 8 分钟

**任务**：观察下面两组图片，把发现填进表格。

[材料]

| 我观察到 | 我的猜想 |
|---|---|
|  |  |
|  |  |

💡 想不出来？试试从"阴影部分占了几份"入手。
```

顺序固定为：**栏目名与用时 → 任务指令 → 材料 → 填写区 → 支架提示**。

### 图标使用（克制，统一）

| 图标 | 含义 |
|---|---|
| ⏱ | 建议用时 |
| 💡 | 提示/支架 |
| ★ | 必做 ／ ★★ 进阶 ／ ★★★ 挑战 |
| ✍ | 书写区 |
| ✅ | 自评勾选 |

全单图标不超过 6 种，同一含义只用同一图标。低年级可增加图标，高年级宜减少。

### 填写区呈现

- 短填空：`______`（下划线长度约答案字数 1.5 倍）
- 行式书写：连续下划线行，每行独占一行
- 大段书写：用引用块或方框标注 `（约 80 字）`
- 表格：空单元格留空，表头加粗并写清每列填什么
- 计算区：用代码块或方框标注「计算区」

**禁止零留白的假填空**——不能只写"请回答："却不给书写位置。

### 语言与字号原则

- 学生版全文第二人称、动词开头、句子短。
- 小学低段：句长不超 15 字，多用图标与田字格提示。
- 小学高段至初中：可用探究性长任务，但单条指令仍拆分为①②③。
- 高中：可含开放性论述任务与较长材料。

## 二、学生版规范

**只放学生需要的东西**。以下内容一律不出现在学生版：

- 教学目标的教师表述（须改写为"学完这一课，我能……"）
- 教案环节名、教学方法名、设计意图
- 参考答案、评分标准（自评标准除外）
- 「锚点」「分层」等设计术语（分层用 ★ 中性标记呈现）
- 教师用时提示以外的课堂管理信息
- 内嵌链接（外部资源统一在导学单正文「资料来源」处标注）

学生版篇幅严格遵守教师在提问一中设定的上限。超出时按 `references/anchor-alignment-rules.md` 的压缩顺序处理。

---

## 三、打印友好要求

教师选择打印时，在 Markdown 中补充以下标记：

1. **分页位**：在合适处插入 `<!-- 分页 -->` 注释，避免栏目被切断；
2. **双面提示**：两页以上时提示"建议双面打印"；
3. **留白检查**：打印版留白按宽松档，屏幕阅读可用紧凑档。

---

## 四、输出前版式自检

四步自检，不通过不交付：

1. **结构**：栏目顺序与确认方案一致？栏目内五要素顺序统一？
2. **留白**：每个任务都有可写的位置？留白量与任务量匹配？
3. **材料标注**：网络材料已在导学单「资料来源」处标出处与链接？
4. **纯净**：学生版有没有混进教师术语、答案、设计意图、内嵌链接？

---

## 五、导学单正文的交付与排版（与教案技能 ljy-lesson-prep 一致）

导学单与教案走同一套交付机制：**正文全文经 `create_artifact` 工具提交，由平台建行并存为一份 .md 文件**。因此本技能不使用 Write、不自行落盘，回复文本里也不出现正文。

### 5.1 交付方式（最高优先级）

1. 导学单全文作为 `create_artifact` 的 `content` 参数一次性提交，`media_type` 用 `text/markdown`，产物名取「《课题》导学单」，`summary` 写一两句本单的定位与覆盖范围。
2. `content` 开头先写顶部标签与导学单标题（`【学科·学段·课题｜导学单类型】` + `# 《课题》导学单`），其后接各栏目正文。
3. 提交后**不追加任何内容**——不附保存提示与建议文件名，不夹带栏目地图、锚点确认单、检核表或任何内部说明；全部任务完成后调用 `finish_task` 收尾。
4. 只提交导学单正文，不提交内部分析过程与自检表。

### 5.2 CommonMark 硬规则（逐条对齐教案技能）

> 以下第 1-6 条逐字引自《备课教案助手-编辑-数学》第七节「一、核心强制规则」第 2-7 条，一字未改；其中"教案""板书设计"在本技能场景下对应"导学单"与导学单中的图示 / 板书式栏目，且适用于**全部学科**。

1. 全程严格遵循 CommonMark 标准语法，禁止使用任意平台私有拓展语法，保证全平台通用兼容。
2. 所有标题后方必须空一行，杜绝解析失败、层级错乱问题。
3. 输出的md文档下划线，强制使用反引号包裹，比如：`______`
4. 但如果是公式内的下划线需使用标准的形式\underline{\quad}进行替换
5. 严禁在教案正文（特别是“板书设计”模块）外层使用代码块（```）包裹，必须直接输出 Markdown 原生排版内容。
6. 表格前后强制空行。表格必须使用标准的 Markdown 语法生成，每一行表格内容必须独占一行。严禁在表格任何行首添加任何前导空格或缩进，必须顶格左对齐（即每行必须以 | 字符开头，严禁写成 " |" ）。如果某个单元格内容为空，必须直接写成紧挨的管道符 "| |"，禁止在空单元格内输入多余空格。仅表格分隔线可使用裸 | 竖线，表格单元格数学内容统一使用 \lvert、\rvert，单元格内禁止裸写绝对值竖线。
7. 整体不使用加粗格式，栏目层级靠标题（`#` / `##` / `###`）区分。
8. **任何学科**只要导学单中出现符号、公式、变量表达式或数字式写法，均须同步遵循 `references/math-notation-and-formula-standards.md`，与教师端教案符号体系完全一致，且该规范静默执行、不得对外展示。
9. 严禁删除线：最终 Markdown 文本的任何位置（标题、正文、表格单元格、列表项、页眉页脚、图示 / 板书式栏目、练习与作业等）均不得出现删除线语法 `~~文本~~`，也不得使用任何会被渲染为删除线的写法；如需表达划去、更正、作废之意，改用文字说明（如将某处改为、此处删去），不得依赖删除线符号。

### 5.3 输出结构示意（仅为示意，真实输出时不得加代码块）

```text
# 《浮力》导学单

班级：`______`  姓名：`______`  日期：`______`  建议用时：15 分钟

......

......

......

......
```

## 常见失败

- 学生版混进"设计意图""教学重点"，学生一头雾水。
- 任务写了但没留书写位置。
- 栏目结构每栏不一样，学生每读一栏都要重新适应。
- 图标满天飞，十几种符号互相干扰。
