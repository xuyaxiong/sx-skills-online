# 教案锚点对齐规则

> 所属知识库：导学单生成技能 > 核心规则
> 对应步骤：前置阶段（锚点抽取）、第二章（锚点确认单）、提问二（映射决策）、输出后检核

## 本文件目的

解决导学单最容易出的病：看起来像那么回事，但和教案两张皮，课堂上老师讲的和学生手里写的对不上。本文件规定如何把教案拆成可映射的锚点、如何把锚点转成导学单栏目、以及如何验证对齐是否真的成立。

---

## 一、锚点抽取：从教案里取什么

从教案中抽取五类锚点，缺一类就补问或补检索，不带着残缺锚点往下走。

| 锚点类型 | 抽取内容 | 在导学单中的去向 |
|---|---|---|
| **目标锚点** | 每条学习目标及其行为动词、达成标准 | 决定每栏任务的认知层级与产出证据 |
| **环节锚点** | 环节名称、序号、时长、核心任务、教师活动与学生活动 | 决定导学单栏目序列与详略 |
| **重难点锚点** | 教学重点、难点及其突破方式 | 决定哪栏加详、哪栏加支架 |
| **素材锚点** | 教案用到的课文段落、例题、图表、教具、情境 | 决定每栏摆什么材料 |
| **评价锚点** | 教案中的评价要点、观察点、作业与检测 | 决定学生产出证据与自评栏 |

**抽取纪律**：
- 逐环节顺序抽取，不跳读、不概括合并，避免遗漏教案里"一句话带过但很关键"的活动。
- 教案里的学生活动是最高价值锚点——导学单本质是学生活动的书面载体，凡教案写了学生活动的地方，导学单原则上都应有对应落点。
- 教案未写、但学生独立完成必需的过渡（如"读题圈条件"），可作为**新增栏目候选**，但须在对齐表中标注「教案未含·建议新增」并说明理由，交教师决定。

## 二、映射规则：锚点怎么变成栏目

### 规则1：一环节一栏目为默认，四种例外

| 情形 | 映射方式 | 判断依据 |
|---|---|---|
| 默认 | 一个教案环节 → 一个导学单栏目 | 环节有独立的学生产出 |
| **合并** | 多个教案环节 → 一栏 | 相邻环节学生动作同质（如"巩固练习"与"变式训练"） |
| **拆分** | 一个教案环节 → 多栏 | 环节内含多个独立思维步骤（如"探究"含观察、猜想、验证） |
| **略写** | 环节 → 一句提示语，不设填写区 | 纯教师讲授、无学生书面产出（如"教师归纳"） |
| **不进单** | 环节不出现在导学单 | 纯组织性环节（如课堂纪律整顿、点名） |

### 规则2：视角必须翻转

教案是教师视角，导学单是学生视角。每个锚点转成栏目时，执行**四层转化**：

```
教案表述（教师做什么） → 学生要做什么 → 用什么材料/资源做 → 写下什么（产出证据）
```

示例：
- 教案："教师出示两组图片，引导学生发现比较的方法"
- 转化后栏目：任务「观察下面两组图片，把你发现的不同写在右栏；再想一想，你是按什么标准比较的？」+ 两栏表格填写区。

**反例**（未翻转，必须避免）：把"引导学生发现比较的方法"原样抄进导学单。

### 规则3：详略由三因素定

- **重难点权重**：命中教案重难点的栏目必详（含支架、示例、分步指令）。
- **学生独立度**：教案中标注学生独立完成或小组合作的环节必详；教师主导的可略。
- **篇幅约束**：教师在提问一中设定的篇幅是硬约束。超篇幅时按"略写→合并→删除"顺序压缩，**先压材料摘录与留白，最后才动核心任务**。

### 规则4：目标覆盖不留空

映射完成后反查：教案的每条学习目标，至少有一个导学单栏目能产出对应证据。若某目标无落点，必须向教师指出并给出补栏建议——这是对齐检核里最常出问题的一项。

## 三、对齐表填法（锚点确认单）

表头七列，逐行对应教案环节顺序：

| 教案环节 | 环节核心任务 | 对应学习目标 | 教案所用素材/资源 | 建议导学单栏目 | 学生产出证据 | 详略建议 |
|---|---|---|---|---|---|---|

填写要求：
1. **教案环节**列写教案原环节名与序号、时长，不改名，便于教师对照。
2. **建议导学单栏目**列写学生视角的栏目名（如"我的发现""挑战一下"），并在推荐方案后标【推荐】；若建议合并/略写/不进单，直接写「建议并入栏目X」「建议略」「建议不进单」+ 一句理由。
3. **学生产出证据**列写学生在这一栏会留下的可见痕迹（圈画/表格/一段话/一个算式/一张图），写不出证据的栏目要重新审视是否该留。
4. **篇幅估算**单独成表输出（模板见「二、篇幅估算」），逐栏预估行数与页数，超出教师在提问一设定的上限时按「略写 → 合并 → 删除」顺序压缩。目标覆盖检查不再作为确认单表格输出，仍按第二节规则 4 在内部反查（每条目标至少一栏产出证据），发现缺口时直接向教师指出并建议补栏，不另立表。

---

## 四、对齐自检（输出前必做）

四问自检，任一不过关就返工，不带着对齐问题交付：

1. **可追溯**：随机抽 3 个栏目，能否一句话说清它来自教案哪个环节、服务哪条目标？
2. **无孤岛**：有没有哪一栏在教案里找不到出处，且未经教师同意新增？
3. **无遗漏**：教案里有学生活动的环节，是否都有落点或已标明"经教师决定略去"？
4. **序一致**：导学单栏目顺序与课堂推进顺序一致吗？不一致是否有教师确认的理由（如课前单打乱顺序）？

## 常见失败

- 只抄教案标题当栏目名，学生看不懂"新知探究"要自己干什么。
- 导学单栏目比教案环节还多，塞进大量教案没有的内容，课堂上根本用不完。
- 教案里的重难点在导学单上一笔带过，反而在导入环节做了大量填空。
- 教案改了但导学单没同步，两份文件版本错位。
- 对齐表做了但只作摆设，生成正文时又凭感觉写。

## 同步教研引导话术

「我把您教案的 6 个环节逐条对到导学单上了，其中『教师归纳』这一环学生没有书面产出，我建议略成一句提示；『变式训练』和『巩固练习』学生动作差不多，建议合并成一栏。您看这样删减合不合您的课堂节奏？」

「有个地方要提醒您：教案第 3 条目标『能举例说明』，现在导学单上没有栏目能产出这个证据。要不要在探究栏后面加一个『我来举个例子』的小格？」
