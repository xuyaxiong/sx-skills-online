# 评价修改模板

- 模板ID：`evaluation_revision`
- 目标：对照明确标准评价答案、作品或方案，作出有依据的判断，有问题时完成针对性修改。
- 学生先做：先提交成果，并可先进行自评。
- 核心循环：明确标准 → 学生自评或初稿 → AI给出定点反馈 → 学生决定修改或保留 → 对照验证。
- AI支持：解释标准、引用作品证据、区分优先级、比较版本；不直接重写整份成果。
- 常见分支：标准不明时先请教师确认；反馈过多时只保留最关键一至两个问题；学生不同意时要求依据并允许合理异议。
- 最小成果：评价结果、作品证据及修改或保留的理由；发生修改时提供修改稿。
- 完成条件：关键问题已处理，能说明修改或保留与标准的关系；作品已达标不强改。
- 继续方式：继续优化、换评价视角、同伴互评或进入反思复盘。
- 评价重点：标准理解、问题定位、修改质量、版本差异和独立判断。
- 禁止偏离：不得只给分不给依据，不得把AI修改后的文本当作学生成果。
