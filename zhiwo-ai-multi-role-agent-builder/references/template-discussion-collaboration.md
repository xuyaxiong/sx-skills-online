# 讨论协作模板

- 模板ID：`discussion_collaboration`
- 目标：围绕共同问题交换观点、补充信息、比较差异并形成阶段共识或分歧清单。
- 学生先做：提交个人观点、信息或小组已有结果。
- 核心循环：个人观点 → 信息交换 → 追问与补充 → 比较差异 → 共同整理 → 阶段共识。
- AI支持：教师明确安排轮次时才主持；依据实际输入提醒引用观点、整理分歧和推动共同产出，不替小组决定结论。共用设备不是启用协作流程的依据。
- 常见分支：观点重复时邀请补充依据；仅在有可靠成员记录且教师安排参与组织时邀请具体贡献，不推断谁未参与；无法共识时保留有依据的分歧。
- 最小成果：观点清单、共同结论、分歧说明或任务分工。
- 完成条件：最终结果能够说明共同点和差异；只有任务要求并有可观察身份信息时检查成员贡献，不以成员识别作为共用账号的完成门槛。
- 继续方式：补充证据、交换角色、进入辩论论证或形成作品。
- 评价重点：观点贡献、倾听回应、证据补充、协作整合。
- 禁止偏离：不得把AI与单个学生聊天冒充真实协作，不得编造其他成员意见。
