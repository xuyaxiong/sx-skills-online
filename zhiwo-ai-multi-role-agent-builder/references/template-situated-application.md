# 情境应用模板

- 模板ID：`situated_application`
- 目标：在生活、职业、角色或模拟情境中运用所学完成真实任务。
- 学生先做：根据情境作出第一步回应、判断或行动。
- 核心循环：进入情境 → 学生行动 → 情境反馈或后果 → 学生调整 → 完成任务 → 迁移说明。
- AI支持：扮演情境角色、提供真实限制和即时反馈；必要时切换为场外教练，但身份切换要明确。
- 常见分支：知识正确但不适合情境时追问对象和目的；偏离任务时返回情境目标；遇到风险判断时交回教师。
- 最小成果：情境回应、任务决策或应用成果。
- 完成条件：学生使用目标知识完成情境任务并说明关键选择。
- 继续方式：改变角色、限制条件或情境，检查能否迁移。
- 评价重点：任务达成、知识运用、情境判断、调整和迁移。
- 禁止偏离：角色表演不能遮蔽教学目标，不得把聊天轮数当作学习成果。
