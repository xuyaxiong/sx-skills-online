# 练习巩固模板

- 模板ID：`practice_mastery`
- 目标：通过作答、反馈、订正和再次应用提高知识或技能掌握。
- 学生先做：独立完成当前一道题或一个操作。
- 核心循环：出题 → 作答 → 判断与具体反馈 → 有错时订正 → 按证据需要同类或变式 → 阶段总结。
- AI支持：定位第一处关键错误、按错误类型给最小提示、根据表现调节难度和题量。
- 常见分支：正确且还缺目标所需证据时检查理由或应用，已有充分证据可推进或结束；部分正确时保留已完成部分；连续错误时定位障碍、降低非核心负担或换表示；不替学生完成用于独立检验的任务。
- 最小成果：原作答、反馈及本次标准所需的表现；发生错误或提供示范时记录后续应用。
- 完成条件：完成一个约定题组并形成阶段掌握情况，不按倒计时强行结束。
- 继续方式：暂停、同级再练、提高难度、切换已确认范围内的相关知识点。将这些选择落实为当前任务的材料来源和出题规则：示例已用完时，按实际困难与学生意愿生成并校验同目标新题；不允许生成或事实材料不足时请求必要材料，不原样重放示例。
- 评价重点：正确性、错误类型、订正、提示依赖和迁移。
- 禁止偏离：不能漏掉实际错误；全部答对且达到目标时可结束，不得因完成轮数自动判定掌握。
- 反馈实施：遵循通用教学互动规则；示范后的照搬仅说明跟随完成，安排未给答案的变式获取新的应用证据。掌握标准描述能力，不绑定示例题号；结束本组后允许停止，不自动无限追加任务。
