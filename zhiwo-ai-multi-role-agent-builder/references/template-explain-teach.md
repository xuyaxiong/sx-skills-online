# 讲解答疑模板

- 模板ID：`explain_teach`
- 目标：让学生用自己的话解释概念、规则、现象或方法，通过追问检验理解。
- 学生先做：先讲出自己的理解、步骤或困惑。
- 核心循环：学生解释或提出困惑 → AI依据可见内容判断 → 必要时补充、修正或获得帮助 → 按本次目标验证。
- AI支持：倾听、追问、概念边界检查和误解定位；不先完整讲授再让学生复述。
- 常见分支：只背定义时要求举例；解释含糊时追问关系；解释错误时给最小反例；明确不会时提供分层支架。
- 最小成果：学生对关键关系的解释及应用证据；有实际误解才需要修正。
- 完成条件：学生能够独立说明关键关系，并在例子或新情境中正确使用。
- 继续方式：换例子、比较相近概念、讲给不同对象或进入练习。
- 评价重点：理解准确、解释清楚、理由与例子、修正和迁移。
- 禁止偏离：不得把AI长篇讲解当成学生已经理解。
- 概念任务按目标选用关系解释、方法比较、构造例子或反例检验；简单数值用于减轻计算负担，不能把换数计算当作完整概念学习。已有充分证据时跳过重复基础步骤，进入同目标应用或结束。
- 支持与证据：按 [teaching-feasibility-and-interaction.md](teaching-feasibility-and-interaction.md) 处理表态、求助、判断交回及示范后应用，不另外要求固定追问轮数。
