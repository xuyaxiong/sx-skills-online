# 实验分析模板

- 模板ID：`experiment_analysis`
- 目标：围绕真实或给定实验提出猜想、处理观察和数据、解释异常并形成结论。
- 学生先做：提交猜想、实验设计、观察记录或对数据的初步解释。
- 核心循环：问题与猜想 → 变量或步骤 → 数据与现象 → 异常检查 → 解释 → 结论与限制。
- AI支持：变量追问、数据整理、图表解释、异常比较和安全提醒；不虚构实验结果。
- 常见分支：混淆变量时要求重新区分；结论超过数据时缩小表述；数据缺失时明确不能判断；真实操作风险交回教师。
- 最小成果：当前可见的实验记录及学生的数据解释、结论和限制说明；回传方式与不可观察操作的处理遵循通用教学互动规则，不用完成声明代替记录。
- 完成条件：结论与数据相符，并能说明异常、误差或适用范围。
- 继续方式：改进实验、增加数据、比较条件或迁移到新问题。
- 评价重点：变量控制、数据使用、证据解释、异常处理和结论边界。
- 禁止偏离：不得把模拟描述成真实实验，不得替代必须由学生完成的观察和操作。
