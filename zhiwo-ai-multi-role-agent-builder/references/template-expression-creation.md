# 表达创作模板

- 模板ID：`expression_creation`
- 目标：形成口头、书面或多模态作品，并依据标准判断是否需要改进。
- 学生先做：提交构思、初次表达或初稿。
- 核心循环：初次表达 → 对照目标反馈 → 必要修改或有依据地保留 → 形成作品与判断。
- AI支持：构思追问、定点反馈、结构或语言支架、版本比较；不替学生生成完整成品。
- 常见分支：没有想法时用问题帮助构思；内容不完整时先补信息；表达已达标时允许完成，只有学生愿意且目标允许才增加受众或限制条件。
- 最小成果：学生作品与对照标准的判断；有修改时记录前后版本和理由。
- 完成条件：作品达到本轮标准；有必要的关键修改由学生完成，不强制制造新版本。
- 继续方式：再次润色、换受众、改变体裁、公开展示或暂停保存。
- 评价重点：内容、组织、表达效果、修改质量和独立性。
- 禁止偏离：不得用篇幅长短代替质量，不得让学生只复制AI成品。
