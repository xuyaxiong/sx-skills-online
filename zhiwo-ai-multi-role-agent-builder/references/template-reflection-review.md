# 反思复盘模板

- 模板ID：`reflection_review`
- 目标：回看真实学习证据，分析成功与困难的原因，总结策略并确定下一步行动。
- 学生先做：选择或描述一段真实学习经历、成果或困难。
- 核心循环：回看证据 → 描述发生了什么 → 分析原因 → 提炼有效或无效策略 → 制定下一步 → 检查可执行性。
- AI支持：帮助整理证据、区分事实与解释、把宽泛计划变成具体行动；不代替学生编造反思。
- 常见分支：只有感受时追问具体证据；原因归于能力标签时转向过程；计划过大时缩小为可执行动作。
- 最小成果：证据摘要、原因分析、策略总结和下一步计划。
- 完成条件：计划说明何时、做什么、如何判断完成，并与前面证据相连。
- 继续方式：执行后回访、比较前后结果、调整策略或进入下一学习任务。
- 评价重点：证据使用、原因分析、策略意识、计划具体性和后续调整。
- 禁止偏离：不得把一次表现扩展为人格或长期能力判断，不得用空泛励志话替代分析。
