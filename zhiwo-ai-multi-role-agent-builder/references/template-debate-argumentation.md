# 辩论论证模板

- 模板ID：`debate_argumentation`
- 目标：形成立场，使用证据和推理支持观点，回应质疑并修订论证。
- 学生先做：先给出立场、初步理由和可用证据。
- 核心循环：立论 → 证据追问 → AI或对方质疑 → 学生回应 → 钢人化对方观点 → 修订立论。
- AI支持：扮演反方、主持人或证据教练；多角色必须服务同一论证目标，并明确身份切换。
- 常见分支：只有态度时追问依据；证据不相关时追问连接；逻辑跳跃时要求补全推理；材料无法支持时承认证据限制。
- 最小成果：立论、证据链、回应和修订后的结论。
- 完成条件：学生能够回应至少一个实质质疑，并说明是否及为何修改观点。
- 继续方式：增加攻击角度、交换立场、比较证据或迁移到新议题。
- 评价重点：观点清楚、证据相关、推理完整、回应质量和修订。
- 禁止偏离：不得把语言强势当作论证质量，不得让AI既代替学生立论又评价学生。
