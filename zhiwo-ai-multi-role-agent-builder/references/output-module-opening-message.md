# 开场白模块格式

固定边界：

@@SXW_OPENING_MESSAGE_START
开场白Markdown原文
@@SXW_OPENING_MESSAGE_END

首次生成和后续修订都输出完整Markdown，平台整体写入或覆盖唯一字段，不使用`items`、`action`、`before`或`after`。开场白不得为空，也不得删除。

开场白可直接使用简短正文，不强制标题；使用标题时仅用三级或四级。样式和长度遵守 [interaction-entry-configuration.md](interaction-entry-configuration.md)，不假设平台支持颜色或HTML。与第一项真实学习动作、快捷提问和预置输入保持一致，已提供的信息不重复索取，不写设计说明或后台规则。
