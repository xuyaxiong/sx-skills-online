# 所选时间段内多次表现的评价来源

## 一、使用原则

这类指标用于老师选择的连续一至七天内，比较学生在多次课堂、任务或自主学习中的同口径表现。它不能从一次短对话直接判定，也不能被写成学生的长期稳定能力。

指标来源按以下优先级选择：

1. 当前学段学科的国家课程标准及学业质量要求；
2. 老师上传或平台已经配置的教材、教师用书、单元目标和评价建议；
3. 学校、课程或项目已经采用的评价量规；
4. 老师明确确认的培养目标。

缺少可核对来源时，不生成正式的多次表现指标。可以提出建议观察方向，但必须由老师确认，不能写成课程标准要求。

课程标准中的核心素养只能用于确定观察方向，不能原样作为AI评分指标。每个指标仍需转成当前任务中可观察的学生行为、最低证据要求和明确的汇总口径。

## 二、平台时间边界

- 单次分析可以选择本次课堂、本次任务，或连续一至七天；
- 智能体可以开放使用一个月或更久，但一次数据查看最多分析连续七天；
- 一次对话只产生本次观察事件；
- 只有所选时间段内存在至少两次有效、同口径证据时，才能描述“多次出现”或“在该时间段内发生变化”；
- 不得把七天内的表现写成学期结论、长期能力、稳定性格或固定类型。

## 三、正式来源范围

### 义务教育

小学和初中可以使用教育部《义务教育课程方案和课程标准（2022年版）》中的课程目标、内容要求、学业要求、学业质量和评价建议作为方向来源，再结合具体任务转成可观察表现。

语文、数学、英语、科学、历史、地理、信息科技、艺术、体育与健康和劳动等学科，都必须回到当前任务实际产生的回答、解释、作品、数据、修改或行动记录，不能只根据素养名称评价。

### 高中、中职和大学及以上

- 高中读取当前学科课程标准、教材、教师用书或老师确认的量规；
- 中职读取专业教学标准、课程标准、岗位任务和实训评价要求，高风险技能保留教师或专业人员判断；
- 大学及以上读取课程大纲、培养方案、认证标准、课程量规或教师提供的专业标准。

平台没有对应来源时，询问老师是否提供材料，或者只生成当次任务指标。

## 四、生成规则

每个所选时间段指标必须记录：

1. 指标名称和来源；
2. 适用学段、学科和任务范围；
3. 单次任务中可以观察的学生行为；
4. 最低有效证据要求；
5. 所选连续一至七天的数据范围；
6. 同口径观察怎样汇总；
7. 哪些情况返回“未观察到”；
8. 哪些判断需要教师复核。

新对话中的学生智能体不能自动读取上一轮错题、进度或成果。跨次证据由平台在评价分析环节按选定时间范围汇总，不能由学生智能体在系统提示词中承诺跨会话记忆。

## 五、与当次任务指标的关系

当次任务指标回答“这一次表现怎样，老师现在可以怎么干预”；所选时间段指标回答“连续一至七天内，同一表现出现了几次、发生了什么变化”。

- 当次指标直接给出本次结果；
- 所选时间段指标先生成每次观察，再由平台按时间范围汇总；
- 两者都不满足最低证据要求时返回“未观察到”；
- 汇总结果必须说明有效记录数、缺失记录和时间范围。
