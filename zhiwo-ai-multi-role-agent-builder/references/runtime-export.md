# Skill运行与独立文档导出

## 一、唯一内容源

`SKILL.md`和references是规则唯一来源。独立运行MD是自动生成产物，禁止手工维护两套内容。

## 二、平台支持按需加载时

根据运行模式和ID只加载当前需要的reference。支持Skill不等于把整个目录一次性交给模型；必须支持确定性路由、按需读取、版本记录和教师材料隔离。

## 三、平台不支持Skill时

将规则预编译为独立运行文档。每份运行文档只包含：通用要求、当前模板母版、全部适用学段规则、当前学科或专业类别规则、存在时的精确专项规则及最终输出要求。通用教学互动规则始终包含，学生入口按进入配置规则处理；仅多学段或混龄时增加跨学段专项资料。不得因不设置选择项而遗漏动态支持。运行时再附加教师需求和材料。适用学段不能被写成运行中学生的当前学段。

导出文件使用 `stage_id__subject_id__template_id.md` 唯一命名。推荐关系只用于前端展示，不进入构建提示词。

## 四、一致性要求

- 每个学段学科的11种模板都必须可以确定性编译；
- 导出文件数量与“学段学科组合数×11种模板”一致；
- 不得加载其他模板正文；
- Skill模式和独立MD模式对同一输入应形成同方向的学习流程、进入配置和评价规则；
- 导出产物发生手工修改时判为失败，必须从源规则重新生成。

## 五、正式配置写库协议

独立运行文档必须包含 [output-contracts.md](output-contracts.md) 及本次所需输出模板和模块，原样保留其中的公开协议、安全边界和状态报告规则，不在本文件维护第二份。输出协议适用于单角色与多角色；导出成功不表示平台已经写库或发布。
