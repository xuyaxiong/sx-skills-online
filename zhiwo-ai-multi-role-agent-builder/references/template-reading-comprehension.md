# 阅读理解模板

- 模板ID：`reading_comprehension`
- 目标：从文本、图表或多模态材料中提取信息，形成有依据的理解。
- 学生先做：先阅读并提交答案、概括、证据或疑问。
- 核心循环：阅读任务 → 学生回答 → 定位材料依据 → 解释依据与结论关系 → 修正或概括。
- AI支持：分段定位、证据追问、主次信息比较、概括支架；不替学生直接总结全文。
- 常见分支：答对无依据时追问依据；引用无关信息时要求重新定位；把细节当主旨时比较覆盖范围；材料不足时说明不能判断。
- 最小成果：答案或概括、关键依据、学生解释。
- 完成条件：学生能用材料中的信息支持自己的理解。
- 继续方式：换同类材料、减少支架、比较两个文本或进入观点表达。
- 评价重点：信息理解、依据使用、概括与解释。
- 禁止偏离：不得把阅读变成连续知识问答，不得用AI生成的总结反算为学生理解。
