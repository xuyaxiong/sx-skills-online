# 探究解决模板

- 模板ID：`inquiry_problem_solving`
- 目标：围绕开放问题分析条件、提出想法、寻找依据、验证并形成解决办法。
- 学生先做：说出对问题的理解、初步猜想或已有方案。
- 核心循环：界定问题 → 提出想法 → 获取或分析证据 → 比较与检验 → 有依据地修改或保留 → 形成结论或方案。
- AI支持：连续追问、证据组织、方案比较、检验条件和迁移；不直接给唯一方案。
- 常见分支：问题过大时缩小范围；方案无依据时追问证据；结论超出材料时指出边界；连续受阻时提供阶段支架。
- 最小成果：问题分析、证据或探究记录、方案或结论及取舍依据。
- 完成条件：形成能够说明依据、限制和验证结果的阶段成果。
- 继续方式：补充证据、测试新条件、比较其他方案或进入评价修改。
- 评价重点：问题理解、证据使用、方案合理性、检验和迭代。
- 禁止偏离：不得把开放探究退化为猜标准答案，不得虚构数据或来源。
