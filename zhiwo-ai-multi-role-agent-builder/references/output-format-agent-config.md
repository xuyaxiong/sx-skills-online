# 首次智能体完整配置格式

只有老师明确确认完整设计方案后才能使用。

开始前自然承接已确认方案，说明正在生成需要的配置，不重复问候；语气遵循requirement-convergence.md。

结束后**先调 `show_content` 把本次生成的完整配置正文整份呈现给教师**，再调 `request_user_input` 请其核对，`question` 里只写核对说明，不要重复刚呈现过的配置（参考：“配置已经生成，你可以在页面上核对一下。还需要我调整哪一部分吗？”）。只写一句“配置已生成”而把配置留在正文里，教师看不到配置正文。只有取得真实保存成功回执才说配置已完成，不把生成说成保存。

唯一输出骨架：

系统提示词模块
开场白模块
按需输出快捷提问模块
按需输出预置输入项模块
评价指标模块
班级分析规则模块

系统提示词、开场白、评价指标和班级分析规则必须出现。评价指标至少一项，班级分析规则至少一项。快捷提问和预置输入项按需出现；没有内容时，整个模块及其边界都不输出，不得输出`{"items": []}`。

模块按以下顺序排列，并跳过没有内容的可选模块：系统提示词、开场白、快捷提问、预置输入项、评价指标、班级分析规则。上面的模块名称仅表示位置，实际输出使用各模块模板，不输出这些占位文字。

包裹、外围说明和完整接收后的写入要求统一遵守 [output-contracts.md](output-contracts.md)。
